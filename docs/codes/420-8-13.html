[[420,8,13]] — weight-5 bivariate bicycle code from arXiv:2610.06623v1 Table 3

Direction & hypothesis

Target: the unrestricted x weight-6 CSS cell. arXiv:2610.06623v1 (Cruz-Benito, "Large Language Model-Guided Discovery of Weight-Five Bivariate Bicycle Codes") catalogues 1,142 weight-five BB presentations in 630 colored-BLISS classes. This row, the paper's class CL-4a95cc39, originally carried a decisive upper endpoint supported only by a stored BP-OSD-family scalar (no persisted witness) — the single most failure-prone evidence tier the author's own prior tracking has seen on this catalogue (most audited rows of that tier lost 30-60% of their claimed distance once an independent search was run against them). A prior, private hardening pass already replaced that scalar with an explicit, independently reconstructed and re-verified weight-13 logical operator on each side. This submission carries that already-hardened result to the board, re-deriving the check matrices from scratch in this PR rather than reusing anything not committed here.

What was searched

No fresh search for this PR. Direct re-verification of one already-hardened, already-published presentation: l = 15, m = 14, A = 1 + y^3, B = 1 + x y^3 + x^4, so n = 2*15*14 = 420.

The check matrices were rebuilt from these polynomials with research/kit/bb.py:build_bb and k was independently re-derived as n - rank(H_X) - rank(H_Z) over GF(2), reproducing the paper's k = 8 exactly.

Dead ends

None for this row directly in this PR — the hardening work (collapsing the raw decoder scalar to a verified witness) was done in a prior private pass, not here. That pass's own history is worth recording: an early version of the same search combined two logical-flagged rows from the same coset without re-checking that their XOR was still outside the stabilizer row space, which can produce a spuriously light invalid candidate when the two rows are representatives of the same logical coset. The version that produced this witness re-verifies every combined candidate before accepting it, and this PR re-verifies the final result again from scratch.

Tools

Human-directed agent work (Claude Code, Claude Opus/Sonnet 5) rebuilding and re-verifying an already-hardened, published construction, using research/kit/bb.py for construction and verify/qldpc_verify.py for the local gate. The witness itself was produced in an earlier, private pass by the randomized kernel/permutation method described above; the method is specified in full so it can be rewritten directly against research/kit/bb.py's matrices.
