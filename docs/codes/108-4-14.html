[[108,4,14]] — abelian 2BGA code on Z_9 x Z_3 x Z_2, a = [0, 7, 50], b = [0, 6, 19, 47]

Direction & hypothesis

Track cell: unrestricted x weight-8 (max check weight 7). Target: a point with n' <= 108, k' >= 4, d' >= 14 at check weight <= 7 that no board entry occupies. This code gains on the cell frontier against the entries nearest to it. Nearest board points at n' <= 108: [[108,4,15]] (w=8), [[100,2,15]] (w=8), [[106,2,15]] (w=8), [[104,6,14]] (w=8).

Hypothesis: below n = 110 the board's weight-6 two-block entries are close to exhaustive, but abelian two-block group-algebra (2BGA) codes with larger or unequal supports (|a|, |b| in {3, 4, 5}, check weight 7 to 10) are sampled far more thinly, and every abelian group of a given order (not only cyclic groups and two-factor tori) is a separate family. Two earlier independent seeds over equal 4+4 and 5+5 supports kept producing non-dominated points, so this run used fresh seeds and added the unequal 3+4, 3+5 and 4+5 shapes. Board-relative novelty is from verify/validate_candidate.py; literature novelty is unverified (Lin-Pryadko's 2BGA tables, arXiv:2306.16400, and the bivariate-bicycle literature cover many small abelian groups, and this instance may be in them).

What was searched

H_X = [L(a) | R(b)], H_Z = [R(b)^T | L(a)^T] over F_2[G] with G = Z_9 x Z_3 x Z_2 (|G| = 54) built as group_algebra.cyclic_product(9, 3, 2): elements are the tuples in itertools.product order, index = position in that order (identity = 0). a = [0, 7, 50] and b = [0, 6, 19, 47] are lists of element indices (|a| = 3, |b| = 4, check weight 7). G is abelian, so L(a) and R(b) are commuting multivariate circulants (a bivariate-bicycle-type code when G has two factors).

Sweep (research/kit group_algebra.build_2bga, css.compute_k, surrogate.distance_rand with backend gf2_fast, one thread per candidate, 10-18 worker processes):

  • every abelian group of order 14..55 (n = 2|G| <= 110), supports 4+4 (100,000 random pairs per group), 5+5 (30,000 random pairs per group), identity in both a and b, seed 4021: 9,880,000 candidates built, 3,006,860 with k >= 3, each read at 40 gf2_fast RIS trials against the board's best d at that (n, k, weight) (our own open PRs counted as board entries); 2,095 survivors re-read at 400 trials, 752 unique non-dominated records; refinement (at most 3 per distinct (n, k, d, w)) 20,000 trials: 10 of 10 still advancing, 200,000 trials: 10 of 10 still advancing, 2,000,000 trials: 10 of 10 still advancing.
  • every abelian group of order 14..55 (n = 2|G| <= 110), supports 3+5 (60,000 random pairs per group), 4+5 (60,000 random pairs per group), 3+4 (60,000 random pairs per group), identity in both a and b, seed 6007: 13,680,000 candidates built, 783,190 with k >= 3, each read at 40 gf2_fast RIS trials against the board's best d at that (n, k, weight) (our own open PRs counted as board entries); 216 survivors re-read at 400 trials, 91 unique non-dominated records; refinement (at most 3 per distinct (n, k, d, w)) 20,000 trials: 15 of 15 still advancing, 200,000 trials: 15 of 15 still advancing, 2,000,000 trials: 15 of 15 still advancing.

Left or right translation of a or b is a qubit relabelling, so fixing the identity in both loses nothing. Every screening reading is an upper bound on d, so the funnel can only discard a candidate whose true distance is also non-advancing.
