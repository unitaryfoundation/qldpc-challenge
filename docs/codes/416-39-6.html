Direction & hypothesis

The target is the CSS frontier at low check weight. At board commit c2ebca1713c89277dbd6ddf3ee587cbf7f1a9d23, no entry with n <= 416, k >= 39 and w <= 5 has d >= 4. The submitted code has d = 6 under a local run of the repository's unchanged SAT certifier. It also improves our initial [[455,39,6]] construction by saving 39 physical qubits while preserving capacity, distance and check weight.

This is an established lifted-product construction, not a claim of a new code family or an exhaustive literature record.

What was searched

The improvement campaign allowed either normalized 2-by-3 seed to generate a proper subgroup, while requiring the two subgroup indices to be coprime. For cyclic order N and indices gA,gB, the dimension is k=N+gA+gB+2 gcd(gA,gB). This makes a smaller block with the same dimension possible. Generation seed: 20261002. The selected recipe is

A = [[1, 1, 1], [1, x^4, x^24]]
B = [[1, 1, 1], [1, x^9, x^11]],  x^32 = 1.

Here gA=4 and gB=1. Both full-code connectivity checks pass. The code has 416 physical qubits, 39 logical qubits, and maximum check weight 5.

Reproduction

With qLDPC 0.4.0, this constructs the submitted check ordering exactly:

import numpy as np
from qldpc import abstract, codes

m = 32
table = (np.arange(m)[:, None] + np.arange(m)[None, :]) % m
group = abstract.Group.from_table(table)
g = list(group.generate())
ring = abstract.GroupRing(group, field=2)
A = abstract.RingArray.build(
    [[g[0], g[0], g[0]], [g[0], g[4], g[24]]], ring=ring)
B = abstract.RingArray.build(
    [[g[0], g[0], g[0]], [g[0], g[9], g[11]]], ring=ring)
code = codes.LPCode(A, B, set_logicals=False)
HX = np.asarray(code.matrix_x, dtype=np.uint8)
HZ = np.asarray(code.matrix_z, dtype=np.uint8)
