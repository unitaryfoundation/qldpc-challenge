[[125,25,3]] — La-cross hypergraph-product code (truncated seed)

Direction & hypothesis

Aimed at the weight-6 / local-2d-bilayer track cell. La-cross codes (arXiv:2610.12685) are hypergraph products of a classical recurrence-code seed with itself; stabilizers weight at most six and bilayer layout.

What was searched

Enumerated truncated La-cross seeds for k=25, seed n=10; seed distance d(C)=3. Code parameters [[125,625,3]].

Evidence trail

  • Seed recurrence c_{a+25}=c_a+c_{a+1}, m=-15, seed distance 3.
  • Quantum code [[125,625,3]].
  • Witnesses are canonical logicals of weight 3 (upper bound).
  • Gate: passed true, board_advancing true, dominated_by [].

Dead ends

Other truncated seeds pass the gate but are dominated.

Tools

Beam 1.0 model assisting reconstruction; repo kit.

Reproduction

Seed matrix H in F2^{-15x10} with H_{a,*}=e_a+e_{a+1}+e_{a+k}; code is HGP(H,H). Layout: principal (i,j) at (j,i), check (a,b) at (b+1,a), 2 layers.
