Scraped GitHub for downloadable parity-check matrix artifacts. The trusted candidate gate returned passed: true, structural verification passed (CSS, connectivity, k=122), and no lighter logical was found in the refutation search. Dead ends

Attempted to derive a 2D-local layout (interaction radius ≤ 4.0 single-layer, ≤ 7.0 bilayer) via fold_layout annealing and networkx spectral/spring embeddings. The a7b/yarn mitten codes were also audited but all have check weight 9 (ineligible).
