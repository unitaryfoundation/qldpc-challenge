Direction & hypothesis

Metacyclic groups C_n x| C_k give non-abelian two-block codes whose block size is a product n k rather than a square; the direction tests whether this reaches distances the abelian weight-8 codes of the same n do not.

What was searched

Direction metacyclic-w4 of the loop samples two-block group-algebra codes on metacyclic groups C_n x| C_k of order 60 to 160 and four group elements per block (check weight 8). Each iteration draws fresh candidates, screens them at 400 and then 20,000 RIS trials (gf2_fast), keeps the twelve best by kd^2/n that no board entry or earlier staged document dominates, and gates them with research/kit/submit.make_submission at 8,000 NumPy trials per side plus verify/validate_candidate.py. This code is iteration 696 (seed 20261713). By 29 October the direction had run 323 iterations over 38,760 candidates and staged 181; across all five directions the loop staged 1,383 documents in 390.6 CPU hours. The 26 October review kept 49 staged codes that neither the board nor another staged code dominated, and each of the 49 was re-searched on OLCF Lux (10,000,000 gf2_fast trials, two seeds) and on Perlmutter A100s (300,000,000 RIS trials per side, two seeds).
