[[870,6,13]] — multi-band dense-packed surface code

Direction & hypothesis

Multi-band dense-packed surface code family (generalization of arXiv:2511.06758), aiming at the weight-4 local-2d-single track cell. Parameters chosen so that (n,k,d) is Pareto-nondominated against the existing board entries.

What was searched

Enumerated (d, rows, m, pitch) points of research/multiband_surface.py at the measured pitch floor pitch = 2*floor(3d/4), filtered to CSS, single connected component, max check weight 4, n <= 1000. Survivors with zero dominators in the weight-4 local-2d-single cell were packaged.

Evidence trail

Distance is a witness-backed upper bound. Fast-backend search (5000 trials per side, pair_depth 16) found no logical below weight 13 on either side; submitted witness weight 13.

Dead ends

Even patch sizes (d even) are not CSS in this family. Degenerate low-pitch packings collapse the distance. Higher pitches only increase n at fixed k and are dominated.

Tools

Beam 1.0, OpenCode harness, research/kit/surrogate.py (gf2_fast backend), research/multiband_surface.py.

Reproduction
