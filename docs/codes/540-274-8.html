Direction & hypothesis

Target: the weight-9plus x unrestricted cell on the CSS board (checks of weight 12, no 2D-local layout). The Cornucopia architecture paper (arXiv:2610.19073) closes by saying its construction "carries over to other codes of the family", and the family (Lu, Li & Deng, arXiv:2608.02773) is n = 36q, k = 18q + 4 with weight-12 checks - but the paper publishes instances only at q = 7, 16, 25, 29, 49, 64, 79, of which only q=7 and q=16 fit this board's n <= 700 cap and both are already board entries. So the unpublished block sizes under the cap, q = 4..19, were the opening: every one of them is a rate-1/2 point no CSS board entry can dominate (an entry dominating [[540,274,d]] would need n <= 540 and k >= 274, i.e. rate at least 0.507 at that size, and the board has none).

What was searched

The family's only free parameters are its 12 column shifts: check matrices HX = [A_(j-i) | B_(j-i)], HZ = [B^-1_(i-j) | A^-1_(i-j)] over Z_3 x Z_q coordinate permutations (row maps r+1 for A0 and B2, 2r+2 for A1 and B3, identity otherwise). CSS commutation holds for *every* shift choice: the only noncommuting row-map pairs, (A0,B3) and (A1,B2), enter block-row differences i'-i = 3 (mod 6), which never occur for i,i' in {0,1,2}; so the search is over shifts alone, with k recomputed exactly on every draw.

At q=15: 1200 uniformly random shift pairs, screened at 100 RIS trials each (accelerated backend); the top 24 re-measured at 4000; the top 4 re-measured at 100000; then the packaged candidate re-verified by submit.make_submission (3000 numpy trials/side) and by the submission CLI (800 python RIS + 300000 accelerated trials/side). Stage-1 reads at q=15: 2 -> 102, 4 -> 412, 6 -> 678, 8 -> 8. Seed 17 throughout the sweep, 0 for the CLI witness search. One design fact from the sweep: a read is the lightest logical *found*, so it is always >= the true d - stage-1 ranking cannot discard a better code, only fail to see how good it is.

Dead ends

  • ~0.0% of random shift sets drop rank (k < 18q+4): the two

    • redundancies per check type are not always the only ones. Rejected on an exact GF(2) rank, not a heuristic. At q=15: 0 of 1200 draws.

  • At q=7 and q=16 the best random-shift reads (6 and 8) only *equal* the

    • published-instance board entries [[252,130,6]] and [[576,292,8]], so nothing was staged there: a tie is not a submission.
