[[320,64,3]] — La-cross hypergraph-product code (truncated seed)

Direction & hypothesis

Aimed at the weight-6 / unrestricted track cell. La-cross codes (arXiv:2610.12685) with k=8 truncated seed; layout radius exceeds 7, so classified unrestricted.

What was searched

Enumerated truncated La-cross seeds for k=8, seed n=16; seed distance d(C)=3. Code parameters [[320,64,3]].

Evidence trail

  • Seed recurrence c_{a+8}=c_a+c_{a+1}, m=8, seed distance 3.
  • Quantum code [[320,64,3]].
  • Witnesses are canonical logicals of weight 3 (upper bound).
  • Gate: passed true, board_advancing true, dominated_by [].

Dead ends

Other seeds pass the gate but are dominated.

Tools

Beam 1.0 model assisting reconstruction; repo kit.

Reproduction

Seed matrix H in F2^{8x16} with H_{a,*}=e_a+e_{a+1}+e_{a+k}; code is HGP(H,H).
