Direction & hypothesis

Issue #2992 asks for the halved CPM pair-partition codes of arXiv:2609.30069 (Definition 1 with the reversing fold of Proposition 4). The paper's (4,10) family lists [[90,21,11]], [[140,31,15]], and [[200,43,20]] with exact distances but publishes no generators, and its data repository (ultra-high-rate-qec/design-principles-data) was empty on 2026-10-11. The construction is fixed up to an exponent array E, so the family can be searched directly: n = 5P and k = P + 3 for every accepted template, and the distance is whatever the search finds. Nothing on the board sat near these (n, k) at these distances, so an instance with a verified bound close to the paper's value is a board entry even where it falls short of the paper's claim.

The construction

The parent is a pair-partition CPM code with J = 4 check blocks and L = 10 qubit blocks of size P. X checks come from E: row (j, s) has a 1 at qubit (l, s - E[j][l] mod P) for each l. Z checks come from D[j][l] = -E[j][l xor 1] mod P in the same way. E must satisfy the paper's pair-partition rule: each off-diagonal cell (i < j) carries a perfect matching M on the L block columns, edge-disjoint from the matchings already placed in its row and column, and E[i,u] + E[j,u xor 1] = E[i,v] + E[j,v xor 1] mod P for every matched pair {u, v}. The search draws M at random, solves the resulting homogeneous integer system for E with sympy, and reduces a random integer combination of the kernel basis mod P.

The reversing fold identifies qubit t of block l with qubit -t mod P of block l xor 1. Each parent X check then becomes one stabilizer generator on the 5P surviving qubits (blocks 0, 2, 4, 6, 8): an X leg on each surviving block's position and a Z leg on each partner position, with coinciding legs merging to Y. Every generator has weight at most 10. The 4P generators span a group of rank 4P - 3, hence k = P + 3.

import numpy as np

def halved_checks(P, E):
    J, L = len(E), len(E[0])
    HX = np.zeros((J * P, L * P), dtype=np.int8)
    for j in range(J):
        for l in range(L):
            for s in range(P):
                HX[j * P + s, l * P + (s - E[j][l]) % P] = 1
    checks = []
    for h in HX:
        x, z = [], []
        for ri, l in enumerate(range(0, L, 2)):
            for t in range(P):
                if h[l * P + t]:
                    x.append(ri * P + t)
                if h[(l ^ 1) * P + (-t) % P]:
                    z.append(ri * P + t)
        checks.append({"X": x, "Z": z})
    return checks
