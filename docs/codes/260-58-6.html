[[260,58,6]] — weight-6 cyclic lifted product

Direction & hypothesis

The target was a higher-rate point on the CSS weight-6 frontier. At board commit c2ebca1713c89277dbd6ddf3ee587cbf7f1a9d23, entries with n <= 260, k >= 58 and w <= 6 had distance at most 4. The submitted code has distance 6 under the repository's unchanged SAT certifier. It also saves 24 physical qubits compared with the existing [[284,58,6]] entry, preserving k, d and w.

This is an established lifted-product construction. The claim is a new parameter point relative to this board; wider literature novelty is unverified.

What was searched

The campaign widened normalized monomial bases from 2-by-3 to 2-by-4 and 2-by-5. The first 2-by-4 profile used cyclic order 13 and generation seed 20261002. Its independently sampled, square-free seed shifts are

A = [[1,1,1,1], [1,x,x^3,x^9]]
B = [[1,1,1,1], [1,x,x^4,x^6]],  x^13 = 1.

Both seeds generate C13. The result has n=260, k=58 and maximum check weight 6. The companion 2-by-5 profile is a separate candidate and is not included here.

import numpy as np
from qldpc import abstract, codes

m = 13
table = (np.arange(m)[:, None] + np.arange(m)[None, :]) % m
group = abstract.Group.from_table(table)
g = list(group.generate())
ring = abstract.GroupRing(group, field=2)
A = abstract.RingArray.build(
    [[g[0]] * 4, [g[0], g[1], g[3], g[9]]], ring=ring)
B = abstract.RingArray.build(
    [[g[0]] * 4, [g[0], g[1], g[4], g[6]]], ring=ring)
code = codes.LPCode(A, B, set_logicals=False)
HX = np.asarray(code.matrix_x, dtype=np.uint8)
HZ = np.asarray(code.matrix_z, dtype=np.uint8)
