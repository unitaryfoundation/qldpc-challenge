[[39,23,2]] — C-ADD-CHECK strict improvement of 39-25-1

Direction & hypothesis

Convert the parent (codes/39-25-1.json, d=2) by C-ADD-CHECK strict improvement (Proposition 18.3, code calculus v0.2rc): every minimum-weight logical class of the parent is killed by the added checks, so the child's distance is at least d+1.

What was searched

For d=1 parents: the minimum-weight classes are the bare (weight-1) logicals, enumerated in O(n); the added check supports are their union (plus a GF(2)-solved parity correction when the bare set alone is inadmissible). For d=2 parents: the weight-2 logical classes are enumerated (O(n^2)) and a greedy set-cover over admissible checks kills them within the check budget.

Evidence trail

  • Parent: codes/39-25-1.json.
  • Child witnesses: inherited from the parent where still valid, plus

    • fresh witnesses at the child's distance found by bounded scan.

  • Verified by verify/validate_candidate.py (passed: true), including the

    • random-seed refutation pass.

Dead ends

Parents whose bare-logical set gave an inadmissible check support were fixed by a parity correction solved over GF(2); parents whose system is inconsistent have no single-check fix and were skipped. Multi-check greedy at d=2 succeeds on only a minority of parents (the weight-2 class count grows quickly with n).
