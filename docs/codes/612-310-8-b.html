[[612,310,8]] — Cornucopia q=17 with searched column shifts

Direction & hypothesis

Target cell: weight-9plus × unrestricted on the CSS board (weight-12 checks, no layout), family other. The Cornucopia construction (Lu, Li, Ma et al., "A modular quantum computer based on Cornucopia codes", arXiv:2610.19073v2) fixes only the row maps; its twelve column shifts are free parameters. The hypothesis: at this admissible q (n = 36q ≤ 700) an unexplored shift tuple would produce a code that is not dominated by the Cornucopia instance of the same (n, k) already on the board.

What was searched

200-tuple random column-shift tuples at q=17 (sA, sB ∈ Z_17^6 each), every code screened with the gf2_fast randomized logical search at 500 trials, seeds from the sweep's own RNG stream. The best tuple, sA=[0, 10, 11, 8, 3, 14], sB=[3, 16, 12, 3, 10, 3], was then confirmed at 10,000 accelerator trials plus a 1,000-trial-per-side RIS pass.

Evidence trail

Ladder for the submitted code: 500-trial screen → d<=8; 10,000-trial accelerator pass → d<=8 (witnesses embedded in the entry); the gate's own refutation on a fresh seed found nothing lighter. The claim is a witness-backed upper bound, not an exact distance.

Dead ends

The same sweep at q=13 produced nothing above d ≤ 6 while the board already holds q=13 at d=8, so q=13 was dropped. Within this sweep, tuples screened at 500 trials routinely collapsed to d ≤ 4 at smaller q; none of the confirmed readings moved below the submitted bound.
