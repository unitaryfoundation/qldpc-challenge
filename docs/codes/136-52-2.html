Reproduction

The published nonidentity supports are a=[2, 3, 5], b=[2, 4, 9] in GAP's one-based indexing. Add identity and convert to zero-based. Build HX=[L(a)|R(b)], HZ=[R(b)^T|L(a)^T] with left/right regular representations. Verify CSS; k = 136 - rank(HX) - rank(HZ) = 52. Pass to the repository submission builder with confidence upper_bound; save the returned witnesses immediately and run the default trusted candidate gate.
