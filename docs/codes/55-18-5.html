Weight-10 unrestricted CSS cell. Transform a connected CSS parent (56-18-6.json, a board entry) with the priced construction calculus to obtain a connected child that is not dominated by any existing entry in its track cell.

Witness search at 1000 RIS trials per side (research/kit/surrogate.lightest_logical, seeds 0/1), then verify/validate_candidate.py with full refutation.
