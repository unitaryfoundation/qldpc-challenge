The construction

The parent is a pair-partition CPM code with J = 4 check blocks and L = 10 qubit blocks of size P = 20. X checks come from an exponent array E: row (j, s) has a 1 at qubit (l, s - E[j][l] mod P) for each l. Z checks come from D[j][l] = -E[j][l xor 1] mod P in the same way. E must satisfy the paper's pair-partition rule: each off-diagonal cell (i < j) carries a perfect matching M on the L block columns, edge-disjoint from the matchings already placed in its row and column, and E[i,u] + E[j,u xor 1] = E[i,v] + E[j,v xor 1] mod P for every matched pair {u, v}. The search draws M at random, solves the resulting homogeneous integer system for E with sympy, and reduces a random integer combination of the kernel basis mod P.

The reversing fold identifies qubit t of block l with qubit -t mod P of block l xor 1. Each parent X check then becomes one stabilizer generator on the 5P = 100 surviving qubits (blocks 0, 2, 4, 6, 8): an X leg on each surviving block's position and a Z leg on each partner position, with coinciding legs merging to Y. Every generator has weight at most 10. The 4P = 80 generators span a group of rank 4P - 3 = 77, hence k = 100 - 77 = 23.

import numpy as np

def halved_checks(P, E):
    J, L = len(E), len(E[0])
    HX = np.zeros((J * P, L * P), dtype=np.int8)
    for j in range(J):
        for l in range(L):
            for s in range(P):
                HX[j * P + s, l * P + (s - E[j][l]) % P] = 1
    checks = []
    for h in HX:
        x, z = [], []
        for ri, l in enumerate(range(0, L, 2)):
            for t in range(P):
                if h[l * P + t]:
                    x.append(ri * P + t)
                if h[(l ^ 1) * P + (-t) % P]:
                    z.append(ri * P + t)
        checks.append({"X": x, "Z": z})
    return checks
