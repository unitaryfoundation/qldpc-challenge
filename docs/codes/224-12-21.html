[[224,12,21]] CLP code, check weight 9

Primary reference: arXiv:2610.12782, *Coset Lifted Product Codes*, Rajpurohit, Lalitha, Garani, Table II. Data and scripts: https://github.com/rajendrarajpurohit/CLP_QLDPC.

Direction and hypothesis

Part of the paper's search over 14,843 pairs (G,H), 30 <= m <= 100, at check weights 7 to 10, for codes with kd^2/n above the published bar at each weight. This code is one of the paper's Table II candidates, whose distances are upper bounds only; the paper's integer program certification does not reach d > 20.

This code

G = SmallGroup(224,169), H = <f2, f6> = C4, m = 56, n = 4m, check weight 9. Protographs a and B in the entry's construction field.

Evidence trail

| stage | rounds / trials | result | |---|---|---| | search log | 2 x 10^5 QDistRnd per side | d <= 21 | | rescreen | 10^6 QDistRnd per side, both sides | d <= 21 | | this tool | 20,000 RIS trials per side | X <= 21, Z <= 21 |

Not certified exact. The witnesses in the entry are the ones this tool found, checked by the verifier.

Dead ends

In the paper's screen, six of seven candidates with bounds at or above 25 lost weight between 2 x 10^5 and 10^6 rounds; this one held. Non square layouts and 3x3 shapes with single element entries were closed as negative results in the paper.

Tools

GAP 4.15.1 with SmallGroups and QDistRnd, the construction and driver scripts of the repository above, no LLM in the search loop. Witness and verification: this repository's qldpc submit.

Reproduction

gap/rebuild.g in the repository above, with G, H, a, B as given, rebuilds HX and HZ.
