[[39,23,1]] — priced-calculus deletion/peel chain from a high-rate CSS parent

Direction & hypothesis

Weight-6/8/9plus local-2d board cell; aim at a board-advancing point by deforming a high-rate CSS parent with the priced construction calculus. Hypothesis: a single C-DELETE-CHECK move on a high-rate parent (k/n>=0.15, n~40) lands a d>=1 survivor at n=39.

What was searched

Parents: CSS entries with 40<=n<=80, d>=3, k/n>=0.15. Moves: C-DELETE-CHECK (depth 1) via planner.plan with structural screening. Witness search up to weight 4 per side; full validate_candidate gating.

Evidence trail

Witness-backed upper bound: d = 1 (upper bound). Full distance d = 1. Confidence: upper_bound.

Dead ends

Depth-2/3 chains on small parents yielded 11-3-3, 11-8-1, 10-7-1, 10-8-1, 9-7-1. E-EXTEND produced no survivors.

Tools

Model: Beam 1.0. Harness: research/kit, machine/priced_calculus.py and machine/planner.py from github.com/MathysRennela/code-calculus-dev. Gate: verify/validate_candidate.py.

Reproduction

Parent: a high-rate CSS entry (n~40). Single C-DELETE-CHECK per the priced calculus consumer. Full matrices in codes/39-23-1.json.
