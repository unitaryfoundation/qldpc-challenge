Direction and hypothesis

The CSS weight-8, local-2d-single headline is [[798,8,d≤27]] in codes/798-8-27.json, with kd²/n = 8 × 27² / 798 = 7.308. Removing a disentangled qubit while retaining the source code's check weight, locality, logical dimension, and witnessed distance would raise the score to 8 × 27² / 797 = 7.317.

Construction

This code derives from codes/798-8-27.json by @dorakingx. Number rows and qubits from zero as in that file. XOR X-check rows 360, 376, 377, and 378 to form a row-space stabilizer S supported on qubits {360, 361, 378, 762, 781, 782}. Replace X row 376 with S. Add S to every other X row containing qubit 378. Apply a CNOT from qubit 378 to each other qubit in S, then delete qubit 378 and its resulting weight-1 X check.

The CNOT changes X columns by H_X[:,b] ^= H_X[:,378] for each other b ∈ S. On Z checks it changes column 378 by the parity over S, which is zero because S is an X stabilizer. Thus qubit 378 is disentangled. Every surviving qubit retains its source coordinate; indices above 378 decrease by one. The full matrices in codes/797-8-27.json follow these steps exactly.

The repository verifier recomputes k=8, CSS commutation, maximum check weight 8, one layer, and interaction radius 4. The transformed source logicals are validated on the reduced matrices: an X operator of weight 27 and a Z operator of weight 28. An independent GPU search found a Z logical of weight 27, also validated on the full matrices. The submitted X-27 and Z-27 witnesses give the upper bound d≤27.

Search and checks

Connected XORs of four same-type checks in the source produced 433 distinct X-side and 534 distinct Z-side row-space elements of weight at most 8. Testing each support qubit and possible replacement row against the source coordinates left 124 geometry-valid graft moves across 16 distinct qubits. This submission uses a weight-6 X-side element.

The unchanged verify/validate_candidate.py gate passed with fresh seed 700898856: its 8,000-trial refutation found no lighter logical, and it found no exact or Weisfeiler–Leman-equivalent board entry. A 100,000-trial accelerated general RIS run at pair depth 8 (seed 313300000) found weight 27 and no lighter logical. Separate runs at pair depth 256 (1,000,000 trials, seed 313400000) and pair depth 512 (500,000 trials, seed 313500000) also found weight 27 and no lighter logical. On Perlmutter, ris_gpu ran 50 million trials on each side at pair depth 8 (seed 4378, target 27); its best validated operators had weights X-27 and Z-27, with no lighter logical. The Z-27 operator is the submitted Z witness. These searches do not prove a lower bound; d≤27 is a witnessed upper bound, subject to further refutation.

Tools and attribution

The source code and original logical witnesses belong to @dorakingx; this submission credits that construction and retains its qubit coordinates. GPT-6 (Codex), run as a single Codex agent for @vprusso, found the four-check row-space graft, reconstructed the reduced matrices, and checked the transformed and GPU-found logicals using the repository's verifier and accelerated RIS kernels. The move follows the row-space reduction described in notes/798-8-27.md, extending its connected search from at most three checks to four.
