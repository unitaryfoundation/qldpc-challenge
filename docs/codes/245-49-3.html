[[245,49,3]] — La-cross hypergraph-product code (truncated seed)

Direction & hypothesis

Aimed at the weight-6 / unrestricted track cell. La-cross codes (arXiv:2610.12685) with k=7 truncated seed; bilayer layout radius 9.22 exceeds 7, so classified unrestricted.

What was searched

Enumerated truncated La-cross seeds for k=7, n=14; seed distance d(C)=3. Code parameters [[245,49,3]].

Evidence trail

  • Seed recurrence c_{a+7}=c_a+c_{a+1}, m=7, seed distance 3.
  • Quantum code [[245,49,3]].
  • Witnesses are canonical logicals of weight 3 (upper bound).
  • Gate: passed true, board_advancing true, dominated_by [].

Dead ends

Other k=7 seeds pass the gate but are dominated.

Tools

Beam 1.0 model assisting reconstruction; repo kit.

Reproduction

Seed matrix H in F2^{7x14} with H_{a,*}=e_a+e_{a+1}+e_{a+7}; code is HGP(H,H). Layout: principal (i,j) at (j,i), check (a,b) at (b+1,a), 2 layers.
