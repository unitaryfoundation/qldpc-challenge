How this code was found

the research note submitted with this code · raw markdown · all notes

[[404,8,18]] — single-layer weight-8 tile code (3 x 3 tile, 13 x 13 bulk), reduced by row-space grafts

Direction & hypothesis

The X-tile {h00, h01, h11, h22, v02, v10, v20, v21} of codes/288-8-15.json and codes/338-8-16.json (ours) gains distance steadily with the bulk, and codes/800-8-27.json built it at 20 x 20. Between n = 338 and 796 the single-layer weight-8 cell at k = 8 held only weight-6 codes (d 17 at n = 454), so we built the tile at the sizes in between. @dorakingx then showed (notes/280-8-15.md, codes/280-8-15.json, codes/316-8-16.json) that row-space grafts delete qubits from these codes at unchanged k, weight and radius; we applied that move here.

What was searched

  • The tile on square bulks 12 x 12 to 17 x 17 (n = 392 to 722), the paper's open boundary (Steffan, Choe, Breuckmann,

    • Pereira, Eberhardt, arXiv:2504.09171). On 13 x 13 it gives [[450,8,18]].

  • Row-space grafts to a fixpoint, as notes/280-8-15.md describes: S a sum of at most three checks with a connected

    • overlap pattern, lightest first, X side then Z side; the qubit is disentangled by the CNOT fan-out and deleted; every touched row checked against weight 8 and radius 4.0 in the source layout. 46 grafts were accepted (|S| = 1: 5, 2: 5, 3: 9, 4: 11, 5: 4, 6: 3, 7: 2, 8: 7), taking n from 450 to 404.

  • Each graft with |S| >= 2 had to survive RIS at 20,000 trials and then twice at 200,000 trials with fresh seeds

    • (this repository's bit-packed engine, verify/gf2_fast.cpp). Those rungs are a filter, not the evidence.

Evidence trail

  • Fresh-seed RIS ladder on the reduced code with the same engine: 18 at 20,000, 200,000, 1,000,000, 5,000,000 and 20,000,000 trials, each rung on its own seed, nothing lighter. The distance is a witness-backed upper

    • bound, not a proof.

  • verify/validate_candidate.py passes (passed: true): it advances the weight-8 x local-2d-single board and is not a duplicate of any board entry.
  • Not dominated in weight-8 x local-2d-single: no k = 8 entry with n <= 404 reaches d 18; the nearest are

    • codes/316-8-16.json (d 16) and codes/454-8-17.json (d 17, weight 6).

Dead ends

  • A first graft pass that screened each step at 2,000 then 20,000 trials let a distance-losing graft through on the

    • 12 x 12 code (the result fell to d <= 16 at 200,000 trials); this code was grafted with the 20k + 2 x 200k filter only.

Tools

Claude Opus 5.5 in Claude Code; our research package (tile construction, graft, RIS ladder); this repository's verify/gf2_fast.cpp (RIS), cli/qldpc.py and verify/.

Reproduction

B = 3, X-tile {h00, h01, h11, h22, v02, v10, v20, v21} where h(x, y) joins vertices (x, y) and (x + 1, y) and v(x, y) joins (x, y) and (x, y + 1); Z-tile by T2 (h(x, y) <-> v(2 - x, 2 - y)); the paper's boundary on a 13 x 13 bulk, then the grafts above. The reduced checks and the coordinates (each surviving qubit keeps its site on the 45-degree rotated lattice) are in the submission JSON.
