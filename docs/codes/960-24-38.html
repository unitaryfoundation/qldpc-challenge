[[960,24,40]] — weight-6 two-block group-algebra code over C24 x Dic5

Direction & hypothesis

Cell: CSS, unrestricted, weight-6. The cell's leader is the weight-6 two-block group-algebra (2BGA) code [[672,20,32]] (codes/672-20-32.json by @vprusso) over C_12 ⋊_5 C_28 ≅ C28 x Dic3; our earlier entry codes/720-16-36.json (C18 x Dic5) follows the same direction. The board admits n <= 1000 at check weight <= 8 when the claimed distance is at most 40, so a weight-6 code with n <= 1000 can score up to k * 1600 / n. Hypothesis: the groups C_m x Dic5 of order 400-500 contain codes with enough rate (k >= 20 at n = 960) and distance 40, and an exhaustive enumeration of one such group can find them, or find none at this screening depth.

A 2BGA code is unchanged (up to qubit and check relabelling) when a is replaced by s a u, independently b by v b t (s, u, v, t in G), and when one automorphism of G is applied to both (standard equivalences of group-algebra codes, see arXiv:2306.16400 and arXiv:2305.06890; not claimed as ours).

Inspired by: codes/672-20-32.json by @vprusso (found with Claude Opus 5), the cell's leader; its group shape (a cyclic factor times a small non-abelian group) is the direction this search follows.

Related: fieldnotes/2026-09-20-screening-traps-at-n-900.md by @e-eight studies metacyclic 2BGA codes in this same size range (n in (700, 1000]) and shows that short screens there report much higher distances than deeper searches confirm; it also notes that its random-support sweep leaves non-random support choices open. C24 x Dic5 (= C120 : C4) lies in that group range; here the supports come from an exhaustive enumeration of this one group.

Our contribution: the group C24 x Dic5 and the supports a, b, found by the exhaustive enumeration of that group, and the distance evidence; the 2BGA construction is Lin and Pryadko's (arXiv:2306.16400).

What was searched

An initial survey sampled 1,000,000 random 3+3 pairs (identity in each support) in each of 11 groups C_m x H of order 400-480 (H in Dic3, Dic5, C3:C8, C5:Q8), C24 x Dic5 among them, kept k >= 16, and screened with 300 tries per central involution on codewords fixed by it, then a short plain random-information-set search. Then an exhaustive census of C24 x Dic5: all 3,464,090 symmetry-reduced 3+3 pairs (two-sided translations and Aut(G) removed). Candidates were dropped at k < 19 or when a logical was found that put the score below 30.5 (each drop backed by an explicit logical). Exactly two inequivalent classes (under the equivalences above) remain: this code and a second class, also k = 24 with d <= 40, which is not shown equivalent to this one as a code and is not filed here.

Evidence trail

Lightest logical found for the submitted code (both sides; upper bounds). "Quotient" searches look for logicals constant on the cosets of a normal subgroup N (the lift of a logical of the smaller code over G/N), a standard upper-bound tool for group codes and the same idea as the board's orbit-fold pass in verify/heuristic_distance.py.

| trials per side | method | lightest found | |---|---|---| | 300 | screen: codewords fixed by each central involution | 40 | | 20000 | every quotient by a normal subgroup of order at most 80 | 40 | | 30000 | plain random information sets (lightest X 46, Z 50) | 46 | | 100000 | board verify/heuristic_distance.py, 100000 RIS + 8000000 fast trials, --fold-trials 0 | 52 | | 8000000 | board verify/gate_changed.py (deep): fast plain pass alone | 44 | | 200000 | plain random information sets, then quotient searches with up to 1000000 trials | 40 | | 3000 | central-involution search, rerun to store the witnesses | 40 |

The heuristic_distance.py run used --fold-trials 0 on purpose, to measure what plain random information sets find; plain searches did not reach 40 (lightest 44, in the 8,000,000 fast trials of the board's gate). The board's deep gate with its orbit-fold pass (17 partitions x 50,000), 140,200 RIS trials and 8,000,000 fast trials reports no logical lighter than 40.

The stored witnesses (weight 40, X and Z) are constant on the cosets of the central Klein four-group V = {1, z^12, y^2, z^12 y^2}: they are lifts of weight-10 logicals of the 240-qubit quotient code over G/V = C12 x D5. Each was checked in Python, separately from the C search that found it: it commutes with the opposite checks and is not in the row space of its own checks.

The distance is a witness-backed upper bound, not an exact claim; lighter logicals with other structure may exist.

Dead ends

Over C24 x Dic5 no class with k >= 26 survives (three k = 32 pairs pass the quotient searches and fall below d = 31 under plain searches). Neighbouring groups C20 x Dic5 (n = 800, needs d = 40 exactly at k = 16) and C20 x (C3:C8) (n = 960, k = 20) gave candidates that fell to 36-38 within 30,000 trials.

Tools

Claude Opus 5.5 (Claude Code), unattended, for @MicheldeMessieres. GAP 4.16 for groups and automorphisms; a C program for the enumeration (canonical forms under two-sided translation, Aut(G) orbits) and bit-packed random-information-set searches (plain and restricted to codewords fixed by a central element); numpy for an independent rebuild of H_X, H_Z from the presentation and the witness checks; the board's verify/heuristic_distance.py. The search code is available on request. About 3.5 CPU-h in all (provenance.search_budget): 0.9 for the survey of C24 x Dic5 and its census, 0.7 for the screening ladder on this code, about 2 for the heuristic_distance.py run. This excludes the verification runs (the board's gates in the PR checks, the Python witness checks) and the survey's other ten groups (about 2.6 CPU-h).
