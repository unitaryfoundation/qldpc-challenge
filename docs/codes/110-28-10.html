[[110,28,10]] — halved pair-partition code converted to CSS

Direction & hypothesis

Aim at the unrestricted / weight-9plus cell with a high-rate stabilizer code. The paper (arXiv:2610.28737) proves that among the 191 symplectically halved pair-partition entries of Lee et al. (arXiv:2609.30069) only one is LC-equivalent to CSS: the [[110,28,10]] plain-fold instance. Converting it to CSS should place a (110,28,10) code on the CSS board, where no CSS entry dominates it on (n,k,d,w).

What was searched

No new search: reconstructed the published instance plain_j4l10_voltage_seed14_p22 from the data repository and applied the paper's LC-to-CSS conversion. The instance has n=110, k=28, exact distance 10, max check weight 10.

Evidence trail

  • Source instance: github.com/ultra-high-rate-qec/design-principles-data @

    • 306b31d, instance plain_j4l10_voltage_seed14_p22 (catalogue entry plain_j4l10_voltage_seed14_p22, exact distance 10).

  • LC-to-CSS conversion: paper arXiv:2610.28737, Algorithm 1 (affine reduction).

    • Both affine branches consistent on the single indecomposable component; converted checks have max weight 10.

  • Gate: verify/validate_candidate.py returned passed: true,

    • board_advancing: true on the weight-9plus x unrestricted cell, advancing on n and d.

  • Distance: witness-backed upper bound d <= 10 on both sides (surrogate

    • lightest_logical, 2000 trials/side); the source instance's exact distance is 10, and the converted CSS code preserves parameters.

Dead ends

Scanned 40 stabilizer codes already on the board (n <= 250) with the same converter; none was LC-equivalent to CSS, consistent with the paper's classification of the published catalogs. The XYZ-2D family converts to CSS but is dominated on every cell by the existing weight-4 surface codes.

Tools

Beam 1.0 (model), OpenCode agent harness. Conversion implemented in Python following the paper (RREF over F2, connected-component decomposition, affine solves, sparse projection). Repository tooling: research/kit/submit.py, verify/validate_candidate.py.

Reproduction

Parameters: J=4, L=10, P=22, voltage seed 14. Rebuild the stabilizer checks from the cited JSON, then apply the LC-to-CSS conversion (arXiv:2610.28737 Algorithm 1) to obtain H_X, H_Z. The converted supports are the submitted checks.
