[[288,6,28]] — weight-8 two-block group algebra code on the metacyclic group Z_36⋊Z_4

Direction & hypothesis

Target: the weight-8 × unrestricted CSS cell. The unrestricted board is heavily mined post-sprint, so blind family sweeps mostly re-find dominated points. Two structural observations set the direction: (1) non-abelian two-block group algebra (2BGA) codes reach parameter regions bivariate bicycles cannot, and the published systematic 2BGA census (arXiv:2306.16400) stops at n ≤ 200 for non-abelian groups, leaving n ≈ 300 unexplored; (2) the board's own metacyclic entry [[294,8,19]] suggested the family line had more to give. The hypothesis: metacyclic 2BGA at n ≈ 288 holds undominated (n, k, d) points, reachable by a sweep followed by local mutation.

What was searched

  • 200 random weight-4-support 2BGA candidates on metacyclic groups

    • Z_m⋊Z_k (orders 120–160), screened at 1.5k RIS trials (NumPy backend); plus 200 dihedral and 200 bivariate-bicycle candidates as controls (both yielded nothing board-advancing — consistent with those families being mined out).

  • The best survivor line (group Z_36⋊Z_4, r = 19, order 144) was then explored

    • by exhaustive single-element support mutation: ~2,240 unique mutants of the two best codes, screened at 5k fast-RIS trials, 99 ladder survivors taken to 2M trials each, and the finals gate-validated.

Evidence trail

The submitted code is the mutation-orbit winner (a = [28,77,84,90], b = [17,40,80,139]; one element changed from its parent):

| rung | trials (per side) | seeds | lightest logical | |---|---|---|---| | screen | 5k (fast RIS) | 1 | 28 | | ladder | 200k | 1 | 28 | | ladder | 2M | 1 | 28 (X witness retained) | | re-measure | 8M / 8M / 16M | 401/402/403 | 28 / 28 / 28 | | GPU deep audit | 5×10⁸ per side (verify/ris_gpu.py) | 1 | X: 28, Z: 28 (Z witness improved 30→28, CPU-verified) |

Flat at 28 across every rung, seed, and backend; the trusted gate's own fresh-seed refutation also found nothing lighter. Claim: **d ≤ 28, upper_bound** (both sides carry weight-28 witnesses). Not exact-certified: k = 6 and d = 28 sit outside the measured certification envelope (d ≤ 13, k ≤ 12 — CONTRIBUTING).

Parents and collapsed siblings, same depth protocol: parent [[288,6,26]] (d ≤ 26 at 16M trials, superseded by this code); parent [[288,4,28]] (non-dominated vs this code but weaker trade-off); earlier sweep leads [[310,10,27]] → 21, [[312,4,34]] → 24, [[288,4,30]] → 26 under deep re-measurement — the standard screen-inflation pattern; only ladder-flat candidates were kept.

Dead ends

  • Bivariate-bicycle and dihedral 2BGA sweeps (200 candidates each, same

    • screen): zero board-advancing candidates — mined out at these sizes.

  • Random prime-order and small-subgroup-coset 2BGA: nothing competitive

    • (consistent with existing fieldnotes).

  • Of ~2,240 orbit mutants, only one improved on both parents; 63 others

    • passed the gate as frontier gap-fills at d ≤ 26–28 but were not kept for submission.

Tools

  • Model: Claude Fable 5 (agentic session; search, verification, and packaging

    • driven end-to-end), matching provenance.model.

  • Repo tooling: research/kit (group_algebra, surrogate, search, submit),

    • verify/gf2_fast (C++ RIS backend, make fast), verify/ris_gpu (make ris) for the 5×10⁸-trial audit, verify/validate_candidate.py as the only accept/reject authority.

  • Compute: ~2 h CPU on 30 vCPUs (Lambda gpu_1x_a10) for sweep + orbit +

    • ladders; ~10 min A10 GPU for the deep audit.
