[[813,13,9]] — multiband surface code

Direction & hypothesis

Fill a missing high-n slot with a d>=2 code whose check weight stays within the verifier's cap (<=32 standard, <=8 for n>700). Multiband dense-packed surface codes (arXiv:2511.06758, Fujiu et al.) give weight-4 checks with tunable n via (rows, m, pitch), and are 2D-local by construction. Hypothesis: a parameter choice lands on a missing n with d>=9 and k large enough to be board-advancing.

What was searched

Enumerated multiband configurations over d in {3,5,7,9,11}, rows in {2..5}, m in {2..15}, pitch in {d-1, 2*(3d//4), d+1}. For each, computed n, k (exact GF(2) rank), weight, CSS commutation, and Tanner connectivity via research/multiband_surface.py. Kept configs with n in the missing set (no existing CSS code at that n), k>=1, CSS commuting, connected (no direct sum), and weight<=32. Screened survivors at 500 RIS trials per side (research/kit/surrogate.lightest_logical); kept those where the surrogate found a witness at the claimed d. This config: d=9, rows=2, m=7, pitch=8 gives n=813, k=13, weight 4, connected.

Evidence trail

  • Witness-backed upper bound: d_X<=9, d_Z<=9, so d<=9 (500 trials/side,

    • seeds 0 and 1, tool research/kit/surrogate.lightest_logical).

  • Verified by the gate (passed: true, board-advancing).
  • 2D-local, single layer; coordinates provided in the locality block.

Dead ends

Lower d values (3,5,7) produced more missing-n hits but lower distance; d=11+ configs either exceeded n=1000 or failed connectivity. Weight-4 is fixed by the surface-code construction (no weight tuning available).
