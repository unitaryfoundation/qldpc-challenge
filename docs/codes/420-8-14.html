Direction & hypothesis

Target: the unrestricted x weight-6 CSS cell. arXiv:2610.06623v1 (Cruz-Benito, "Large Language Model-Guided Discovery of Weight-Five Bivariate Bicycle Codes") catalogues 1,142 weight-five BB presentations in 630 colored-BLISS classes; this repository's own [[420,6,16]], [[432,8,15]] and [[420,8,13]] entries (merged/opened 2026-10-07) already showed several connected, non-dominated rows in that catalogue carry only interval distance evidence. This row, the paper's class CL-576cc4f9, is one of four BLISS-confirmed non-isomorphic presentations that all land on the exact same [[420,8,14]] point, each supported only by a raw BP-OSD-family decoder scalar (no persisted witness) — the single most failure-prone evidence tier on this catalogue by this author's own prior tracking (most audited rows of that tier lost 30-60% of their claimed distance once an independent search was run against them).

What was searched

No fresh search for a new construction. Direct re-verification of one already-published presentation: l = 15, m = 14, A = 1 + y^3, B = 1 + x y^3 + x^4 y^8, so n = 2*15*14 = 420. The paper's three other non-isomorphic presentations at this same point were also independently re-verified (see Dead ends / alternates below) to decide whether any one of the four was clearly better-evidenced; none was, so the first checked (CL-576cc4f9) is the one filed.

The check matrices were rebuilt from the published polynomials with research/kit/bb.py:build_bb and k was independently re-derived as n - rank(H_X) - rank(H_Z) over GF(2), reproducing the paper's k = 8 exactly.

  • Rebuilt and measured: n = 420, k = 8, max check weight 5, one

    • connected component (no replicated decomposition — confirmed structurally on the rebuilt matrices).

  • The paper's own catalogue records 5 <= d <= 14 for this row: lower

    • bound from exhaustive weight-four exclusion, upper bound from a raw decoder scalar with no persisted witness.

  • An independent randomized search over the kernel of the opposite check

    • matrix (random column permutations each trial, keeping the lightest rows and their pairwise GF(2) combinations under a fresh RREF, 8,000 trials per side, two fixed seeds) found a weight-14 logical operator on each side: zero syndrome against the opposite check matrix, and outside the stabilizer row space, independently re-confirmed by a second, separately coded exclusion check against the same rebuilt matrices. Neither side produced anything lighter than 14. The decoder scalar holds; it did not collapse.

  • Submitted as a witness-backed upper bound, d <= 14, on both sides.

    • It is not certified exact and is not described as such.

Dead ends

Not a dead end exactly, but a deliberate non-submission: the paper prints three more BLISS-confirmed non-isomorphic (15,14) presentations at this exact same [[420,8,14]] point — class CL-5e7d0343 (A = 1 + y^11, B = 1 + x^11 y^11 + x^14 y^13), class CL-e2918556 (A = 1 + y, B = 1 + x^3 y^4 + x^4 y^9), and class CL-eb460c33 (A = 1 + y, B = 1 + x y^5 + x^12 y^3). All three were put through the same independent witness search and all three held at weight 14 on both sides too, with no collapse. None is filed as a separate board entry: tying this entry's exact point, none would advance any new frontier cell, matching how this project's already-merged [[420,4,22]] and [[420,8,13]] entries handled their own tied classes.

Tools

Human-directed agent work (Claude Code, Claude Opus/Sonnet 5) rebuilding and witness-hardening a published construction, using research/kit/bb.py for construction and verify/qldpc_verify.py for the local gate. The witness search (the randomized kernel/permutation method described above, 8,000 trials/side, two fixed seeds, run on all four tied presentations) was run against the same matrices this PR's research/kit/bb.py call reproduces; the method is specified in full above so it can be rewritten directly against those matrices. Roughly 2 CPU-minutes of search per presentation on an n=420 code.
