[[800,32,22]] — weight-8 open-boundary tile code with a 5x5 box on a 20x20 lattice (bilayer, k = 32)

Direction & hypothesis

Cell weight-8 / local-2d-bilayer, family tile. This code comes from the same search as the sibling [[800,29,24]] submitted in PR #4203. That search was aimed at the high-k end of the bilayer weight-8 cell. In the board snapshot of 2026-10-28, no code in this cell with k >= 28 and n <= 1000 had a witnessed d above 10.

The idea:

  • Bernstein–Kushnirenko bound. For a bivariate tile code, k is bounded

    • by the mixed volume of the two support polygons. In the open-boundary construction it equals it.

  • Small windows cap k. Compact periodic layouts of weight-8 two-block

    • codes stop at about k = 16–24. The radius cap and the stretch-2 cost of folding a twisted torus onto a plane (arXiv:2610.13880, "Bicycle Race") keep their window small.

  • The 5x5 box. An open-boundary tile code with a 5x5 box reaches a mixed

    • volume of up to 32 = 2D^2 with D = 4, and still fits the 7.0 radius cap. arXiv:2504.09171 searched boxes up to 4x4.

This entry is the k = 32 point: the largest k a 5x5 box allows.

What was searched

  • Genome. Two supports S_f and S_g, four monomials each, in a 5x5 box.
  • Generator program. `research/local2d/boundary_engine.build_planar(L, L,

    • S_f, S_g), then reduce_weights`, then removal of the all-zero rows that reduce_weights leaves.

  • Layout. research/local2d/planar.grid_coordinates, with layers = 2.
  • Admissibility. Every check, including boundary and corner checks, has

    • weight <= 8, and the layout diameter is <= 7.0.

  • Mutation search. 23,744 supports at L=16 (n=512) with 3,000

    • gf2_fast RIS trials each, restricted to mixed volume >= 28.

  • Re-measurement.

    • 1. The top 5 per k bin at 16x16, 18x18 and 20x20, with 20,000 trials at pair depth 16. 2. The top 8 at 20x20, with 100,000 trials at pair depth 32. 3. The top 4 through the deep ladder.

Dead ends

  • Collapsed near-misses. Same ladder:

| Code | Status | |---|---| | [[781,28]] | fell to 23 | | [[784,28]] | fell to 23 | | [[800,29]] | held at 24; submitted separately |

  • Inflated readings. An earlier k=30 candidate at 20x20 read d<=27 at

    • 4,000 trials and d<=23 at 100,000 trials. Readings under about 100k trials at n~800 ran 2–4 high.

  • Lattice size. The L=12 pilot capped every 5x5-box support at d<=8.
  • Supports that break the caps. Some supports admissible in the bulk

    • break the caps at some sizes, with boundary checks of weight up to 15 or radius 9.0. The caps were re-checked at every size measured.

Reproduction

import sys; sys.path[:0] = ["research/kit", "research/local2d", "verify"]
import numpy as np
from boundary_engine import build_planar, reduce_weights, compute_k
from planar import grid_coordinates
Sf = [(0,0),(1,3),(4,0),(4,4)]; Sg = [(0,4),(2,1),(3,2),(4,0)]

HZ = reduce_weights(np.asarray(HZ, dtype=np.uint8))
HX, HZ = HX[HX.any(1)], HZ[HZ.any(1)]          # 384 x 800 each
assert compute_k(HX, HZ) == 32
coords = grid_coordinates(20, 20, kept=info.get("kept_qubits"))  # layers=2
