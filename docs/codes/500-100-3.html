Direction & hypothesis

Aimed at the weight-6 / unrestricted track cell. La-cross codes (arXiv:2610.12685) with k=10 truncated seed; layout radius exceeds 7, so classified unrestricted.

What was searched

Enumerated truncated La-cross seeds for k=10, seed n=20; seed distance d(C)=3. Code parameters [[500,100,3]].

Evidence trail

  • Seed recurrence c_{a+10}=c_a+c_{a+1}, m=10, seed distance 3.
  • Quantum code [[500,100,3]].
  • Witnesses are canonical logicals of weight 3 (upper bound).
  • Gate: passed true, board_advancing true, dominated_by [].

Dead ends

Other seeds pass the gate but are dominated.

Tools

Beam 1.0 model assisting reconstruction; repo kit.

Reproduction
