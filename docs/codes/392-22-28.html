Direction & hypothesis

Cell weight-8 x unrestricted, CSS board, n between 360 and 400. Before this campaign the weight-8 frontier there ran 360-10-28, 364-8-32, 372-14-29, 378-32-19, 378-18-27, 390-10-32, 392-102-14 and 392-8-33: at n <= 392 every weight-8 entry with d >= 28 had k <= 14, and every entry with k >= 20 had d <= 24. The hypothesis was that four-plus-four-term bivariate bicycle (BB) codes on tori with 2lm in 300..400, prefiltered for k >= 18, could put a k >= 20 point at d = 28. [[392,22,28]] does: no board entry has n <= 392, k >= 22, d >= 28 and check weight <= 8, and the k - 2 margin holds ([[392,20,28]] is not dominated either). It dominates the [[392,18,28]] on Z_28 x Z_7 filed earlier in the same campaign (four more logicals at the same n, d and weight).

What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A and B four monomials each, both containing 1 (no loss of generality), on every torus Z_l x Z_m with l >= m >= 3 and 300 <= 2lm <= 400, the torus drawn uniformly from that list and the other three monomials of each polynomial uniformly from the torus.

Random supports rarely give k >= 18, so the sweep ran a parallel generate-and-rank prefilter: 300,000 draws (seed 111), of which 710 had k >= 18 and a connected Tanner graph (research/kit/prescreen.block_structure). Those went through research/kit/search.screen with the gf2_fast backend at 400 trials; 8 advanced the board frontier at screen depth and were confirmed at 20,000 / 200,000 / 2,000,000 fast trials (research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a candidate as soon as its running bound stopped advancing and skipping any already dominated by a point staged earlier in the campaign.
