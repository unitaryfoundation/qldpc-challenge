Exact reduction

In the source numbering, take X row 0

S = {1, 4, 42, 60, 400, 420, 436, 459}

and choose a = 1. The only other X generator meeting a is source row 287, with support {1,401}. Replace it by its sum with S, so that a occurs only in S. Apply the CNOT fan-out from control 1 to targets {4,42,60,400,420,436,459}. On the binary check matrices this is

H_X[:, b] ^= H_X[:, 1]   for b in {4,42,60,400,420,436,459}
H_Z[:, 1] ^= H_Z[:, b]   for b in {4,42,60,400,420,436,459}.

The first operation maps S to the weight-one stabilizer X_1. The second maps column 1 of H_Z to the parity over S, which is zero for every Z row by CSS commutation. Qubit 1 is therefore disentangled. Delete X_1 and qubit 1, and map each surviving source index q > 1 to q - 1.

This is a Clifford equivalence followed by removal of a stabilized product qubit, hence k remains 18. Every surviving qubit keeps its source coordinate. The maximum check weight remains 8, the measured interaction radius remains 6.708203932499369, and the layout remains bilayer.

The transformed source witnesses have X weight 28 and Z weight 27 and pass the kernel and nontriviality checks. The distance claim remains an upper bound, not an exact-distance certificate.
