Direction & hypothesis

2D-local single-layer weight-8 CSS cell, through the layout inherited from the parent. The priced construction calculus was applied one move deep to every CSS entry on the board, and this code is the E-PEEL of codes/71-1-11.json ([[71,1,11]], max check weight 8; the triangular 4.8.8 color code at distance 11 reproduced from arXiv:2609.21376). Peeling qubit 2 with the one X check that touches it keeps k = 1 and lowers the witnessed distance bound by one, from 11 to 10, while dropping one qubit. Max check weight stays 8. The layout is the parent's with the peeled qubit removed; the verifier re-measured its radius and layer count.

What was searched

Every C-DELETE-CHECK, E-PEEL, and E-PUNCTURE move on each of the 2,783 CSS board entries as of 2026-11-02, 1,684,787 moves in all, with the consumer at github.com/unitaryfoundation/code-calculus @ 1b9a942. Children with a bare qubit, a disconnected Tanner graph, a Weisfeiler-Leman signature equal to a board entry or to an earlier child, or parameters already dominated inside the parent's cell were dropped before any search, leaving 334,191 distinct children. Children with n <= 60 and an inherited distance bound of at least 2, and children with 61 <= n <= 100 and a bound of at least 5, were screened with research/kit/surrogate.lightest_logical at 2,000 RIS trials per side; the survivors the kit's novelty pre-check called board-advancing were staged with research/kit/submit.py and gated with verify/validate_candidate.py, one representative per distinct (n, k, d, max weight, locality) point. This code is that representative for [[70,1,10]] at max check weight 8. The thirteen points audited first went to the board on 2026-11-04 (PRs #4588 to #4600); this one is from the remainder, re-checked against the board of 2026-11-04 with the gate's structural, deduplication, and novelty stages before the ladder below was run. The screen distance is a witness-backed upper bound; the rungs below are the independent confirmation runs on the staged file.
