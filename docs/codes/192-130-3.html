[[192,130,3]] — FCC K=12 lattice code (L=4)

Direction & hypothesis

Targeted the unrestricted / weight-9plus cell with a high-rate constant-distance CSS code. The FCC lattice has 3L^3 edges but only L^3 independent stabilizer constraints, leaving ~2/3 of degrees of freedom as logical qubits (arXiv:2603.20294).

What was searched

Construction: qubits on edges of the L=4 face-centered cubic lattice; Z-stabilizers on vertices (weight 12), X-stabilizers on octahedral voids (weight 12). Parameters k = 2L^3+2 = 130, n = 3L^3 = 192, d = 3 proven by exhaustive elimination of all weight-1 and weight-2 vectors plus constructive weight-3 logicals (arXiv:2603.20294 Appendix B).

Evidence trail

Distance d = 3 (upper bound): witness-backed weight-3 logicals on both X and Z sides. CSS commutation verified; k recomputed by GF(2) rank. Gate passed (passed: true).

Dead ends

L=2 instance refuted (weight-2 logical found). L=8 exceeds submission n cap (1000).
