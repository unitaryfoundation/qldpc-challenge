Direction & hypothesis

Target: the general-stabilizer board's unrestricted x weight-8 (and looser) cells. A perturbed bivariate bicycle (PBB) code augments a CSS bivariate-bicycle code's two polynomials (A, B) with two more, (C, D), placed in the stabilizer matrix's block-1 z-part: `H = (A B | C D; 0 0 | B^T A^T) (A C^T + B D^T` symmetric over GF(2) is the only extra commutativity constraint this imposes). When C = D = 0 it degenerates to the CSS BB code; nonzero (C, D) produces genuinely mixed X/Z stabilizers, i.e. a general stabilizer code rather than a CSS one. This submission mines an already-completed, now-published non-CSS evolutionary campaign ("Campaign 5"/"campaign7") from a companion repository rather than running a fresh search here.

What was searched

Source: github.com/qiskit-community/qcode-discovery @ d6abdbd, results/campaign7_report.md.
