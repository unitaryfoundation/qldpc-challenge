[[72,39,1]] check-deletion from 72-38-3

Direction & hypothesis

Issue #4162 asks for high-rate codes (k/n >= 0.15) inside the w <= 8 box. The local-SAT CSS parent 72-38-3 (rate 38/72 ~ 0.53, weight 8) sits in a thin high-k cell, and deleting one independent X check raises k by one while keeping n and w, producing a (72, 39, <=1) point that no existing entry dominates.

What was searched

Reconstructed the parent H_X, H_Z from codes/72-38-3.json, enumerated single-row deletions of H_X and H_Z, kept those that reduced rank (independent checks), and re-screened each survivor's distance with distance_rand at 200 trials (numpy) and then 1,000,000 trials (fast backend, two fresh seeds). All independent deletions collapsed to d <= 1.

Evidence trail

Confirmation ladder for the submitted code, each rung a fresh seed unless marked otherwise, reading the lightest logical found:

| budget (trials/side) | lightest logical | | ---: | ---: | | 200 (numpy screen) | 1 | | 1,000,000 (fast seed 0) | 1 | | 1,000,000 (fast seed 1) | 1 |

3 fresh-seed rung(s) agree at the best bound, the deepest of them at 1,000,000 trials per side. The submitted witness reproduces it: X: d <= 3 (upper_bound), Z: d <= 1 (upper_bound).

Dead ends

  • Deleting dependent rows left the code unchanged and produced exact

    • duplicates of the parent.

  • Parents with circuit-like check sets (e.g. 64-34-4) had no independent

    • single deletion that raised k.

  • Deeper deletion chains were not attempted here; the single deletion already

    • lands on the frontier.

Tools

Model: Beam 1.0 (OpenCode CLI agent). Repo tooling: research/kit/submit.py, research/kit/coordination.py, research/kit/surrogate.py. The local verdict is verify/validate_candidate.py; the bundle was assembled by research/kit/promote.py. Compute: a few CPU-minutes (1M-trial fast-backend rungs).

Reproduction

Rebuild from codes/72-38-3.json by deleting its first X check row (0-indexed) from H_X, keeping H_Z unchanged; equivalently reconstruct H_X (17 x 72) and H_Z (17 x 72) from the parent's check supports, remove row 0 of H_X, and run make_submission with family check-deletion. The witness is a weight-1 logical found by distance_rand.
