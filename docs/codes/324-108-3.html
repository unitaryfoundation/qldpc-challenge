Cell weight-8 x unrestricted (maximum check weight 8), CSS board, n between 221 and 400. This is a high-rate, distance-3 point. The sweep aimed at k >= 18 with large d (random 4 + 4-term bivariate bicycle (BB) codes on tori with 2lm in 240..340, prefiltered for k >= 18); this draw landed far above that k threshold, and at d = 3 it still advances the frontier's high-rate end.
