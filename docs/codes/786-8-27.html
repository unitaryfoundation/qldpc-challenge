Direction and hypothesis

The published CSS tile code in codes/794-8-27.json has parameters [[794,8,d≤27]] and witnessed score 8 × 27² / 794 = 7.345. Eight compatible local reductions remove eight physical qubits while retaining k=8, maximum check weight 8, a one-layer radius-4 layout, and explicit X-27 and Z-27 logicals. The resulting witnessed score is 8 × 27² / 786 = 7.420.

Construction

Start with codes/794-8-27.json. Delete X check 339 and qubit 338; the check is the sole X check on that qubit and has support {338,339,359,379,736,754,774,775}. In the 793-qubit intermediate, XOR Z checks 372 and 373 to obtain support {338,357,358,753,774}. Use Z check 373 as pivot, XOR this support into any other Z check on qubit 774, then delete the pivot and qubit.

In the 792-qubit intermediate, delete X check 142 and qubit 119; that check is the sole X check on qubit 119 and has support {119,120,140,160,515,533,553,554}. In the 791-qubit intermediate, use Z check 0 with support {0,432} as pivot and delete qubit 0. In the 790-qubit intermediate, use Z check 40 with support {77,430} as pivot and delete qubit 430. In the 789-qubit intermediate, use Z check 370 with support {355,770} as pivot and delete qubit 770. In the 788-qubit intermediate, use Z check 12 with support {11,12,31,49,404,423,442,443} as pivot and delete qubit 404. For each Z pivot, clear the target qubit from other Z checks by XOR with the pivot before deleting it. At every step shorten the opposite-side checks at the deleted qubit, remove its coordinate, and retain the order of all surviving rows and coordinates. The submitted JSON contains the final matrices, layout, and logical witnesses.

Fourteen variants remained. A 10,000-trial pair-depth-8 accelerated RIS screen of all 14 found no lighter logical.

Deeper RIS runs found validated weight-26 logicals for all 13 other variants in that set: X37, Z377, Z380, Z382, Z385, Z386, Z387, Z391, Z399, Z402, Z405, Z406, and Z408. Z407 produced no lighter logical in 10,000 pair-depth-8 trials. It returned best weight 27 through 100,000 pair-depth-2048 trials, 500,000 pair-depth-512 trials (seed 837701407), 100,000 pair-depth-4096 trials (seed 1195701407), and 100,000 pair-depth-8192 trials (seed 1605301407). A Perlmutter GPU search ran 50 million pair-depth-8 trials per CSS side (seed 8407). Both sides returned best weight 27. The GPU wrapper CPU-verified both returned logicals, and independent validation on the exact submitted matrices confirmed their supports. This bounded search found no logical below 27.

The unchanged trusted candidate gate passed with seed 558695926. It recomputed CSS commutation, n=786, k=8, maximum check weight 8, one layer, radius 4, both weight-27 logicals, and Tanner and stabilizer-group connectivity. d≤27 is a witness-backed upper bound. The bounded refutation searches above do not prove the minimum distance is 27.
