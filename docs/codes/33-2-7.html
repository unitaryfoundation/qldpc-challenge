How this code was found

the research note submitted with this code · raw markdown · all notes

[[33,2,7]]: fold of 66-4-10 along the ZX-duality h -> c - h (a mirror code)

Direction & hypothesis

Cell: check weight 6, so the weight-6 class, unrestricted locality (no layout submitted), stabilizer board. A CSS code on 2m qubits with a fixed-point-free ZX-duality (an involution of the qubits mapping the X-checks onto the Z-checks) halves to a stabilizer code on m qubits (Burton, Durso-Sabina, Brown, arXiv:2406.09951; the explicit symplectic halving is Def. 3 of Lee, Okada, Maskara, Kasai, Zhou, arXiv:2609.30069). Its nontrivial logicals correspond to the nontrivial Z-logicals of the parent, a logical with y Y factors and t X or Z factors to one of weight 2y + t, so d is at least half the parent's distance. For a two-block code over an abelian group G the map exchanging (1,h) and (2,c-h) is such a duality for every c in G, and the fold is a mirror code of Khesin and Lu (arXiv:2603.05496). Hypothesis: folding the certified two-block entries of the CSS board gives stabilizer codes beyond the stabilizer board's frontier. Here the parent is 66-4-10 (MathysRennela), d = 10 certified in certs/66-4-10.json.

What was searched

The 357 CSS entries of board commit 8042f9da that are abelian two-block codes with a certified exact distance, check weight at most 8 and n at most 400, and 9 two-block codes of ours (366 parents): every affine fixed-point-free ZX-duality, up to conjugation by translations and by the affine symmetries of the checks, 1011 classes (640 of the form h -> c - h between the blocks, 320 twisted block swaps, 51 block-preserving). Each fold was screened by an information-set search scored by Pauli weight (2000 trials, seed 20261110) against the stabilizer board. Of the 232 folds with n <= 90 that neither a board entry nor another fold of ours dominates, 211 got exact distances (Magma for most of them) and 21 kept intervals; all 358 folds with an exact distance were then verified independently (rebuild, meet-in-the-middle search, local Clifford tests, equivalence with board entries). |G| = 33 is odd, so G = 2G and 66-4-10 has a single class of these dualities.

Evidence trail

  • Construction: provenance.construction; n = 33, rank 31, k = 2; 25 generators of weight 6, 7 of weight 5 and 1 of weight 4; 9 Y factors in 8 generators; every qubit in at most 6 generators.
  • Not CSS under single-qubit Cliffords: the generator-level parity system that the board's verifier solves has no solution (qubit 0 carries X, Y and Z), and each generator is the only nontrivial stabilizer supported in its support, which lifts the statement to the whole group (Lemma 6 of the README of the package below).
  • Lower bound 7, three independent exhaustive computations: (1) tropidist b03ec2d4077f in the board's Pauli encoding, exact 7 in 0.2 s on one thread, recorded in certs/33-2-7.json (same pull request); (2) a meet-in-the-middle search (every Pauli of weight <= 3 against every Pauli of weight <= 3, matched by syndrome) finds no nontrivial logical of weight <= 6 (0.0 s); with 4 + 3 it finds one of weight 7 (0.1 s); the program was validated against plain enumeration on 12 small folds and in 329 positive controls; (3) Magma V2.30-1 MinimumDistance: 7, in 0.0 s.
  • Upper bound: the witness, one of 29 logicals of weight 7 found by the information-set search.
  • Final claim: d = 7 exactly. The entry claims exact, which the verifier reads as upper_bound for stabilizer codes; the certificate in this pull request carries the exact tier.
  • Board placement at 8042f9da (stabilizer entries, unrestricted cells): no entry dominates or equals it; it dominates 34-2-7-s (on n). No CSS entry dominates or equals it either.
  • Literature: It is a mirror code of Khesin and Lu (arXiv:2603.05496) with G = Z/3 x Z/11, A = {(0,0),(1,4),(2,5)}, B = {(0,0),(1,7),(2,0)}, not in their code table (they describe their search over abelian |A| = |B| = 3 as almost exhaustive up to n = 300); in the sources of our literature check (summarized in the README of folded-stabilizer-codes/) we found no published code with the parameters [[33,2,7]]. The tables of codetables.de list a [[33,2,10]] code, a dense code without weight restriction.

Dead ends

  • The stabilizer entry 33-2-8 has the same n and k and d = 8 at check weight 7, so this code advances the frontier through its check weight 6 only; 66-4-10 has no other class of these dualities.
  • Of the 1011 fold classes of the search, 71 are locally Clifford equivalent to CSS codes (the board would reject them), all with d <= 2, and 7 are equivalent to existing board entries (the genon 72-6-8-b, for example, is the fold of the gross code along h -> (0,1) - h).
  • Mirror codes from the same search that are not new: [[48,8,6]] (check weight 6) and [[48,10,6]] (check weight 7) are codes of Khesin and Lu, and our [[72,4,10]] (check weight 6, folds of 144-8-12) is dominated by their [[60,4,10]].

Tools

Claude Opus 5.5 (Claude Code); Python (standard library) for the constructions and checks; GAP 4.16 for the board's numbering of the group elements; C programs for the information-set and meet-in-the-middle searches; Magma V2.30-1; tropidist (Cheng, Guo, Pan, arXiv:2611.08247) at the board's pinned commit. About 2 CPU-hours for the search over all parents and its verification, a few CPU-minutes for this code.
