Reproduction

The published nonidentity supports are a=[2], b=[2, 9, 13] in GAP's one-based indexing. Add identity and convert to zero-based. Build HX=[L(a)|R(b)], HZ=[R(b)^T|L(a)^T] with left/right regular representations. Verify CSS; k = 112 - rank(HX) - rank(HZ) = 42. Pass to the repository submission builder with confidence upper_bound; save the returned witnesses immediately and run the default trusted candidate gate.
