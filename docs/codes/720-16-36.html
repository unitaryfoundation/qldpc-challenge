[[720,16,36]] — weight-6 two-block group-algebra code over C18 x Dic5

Direction & hypothesis

Cell: CSS, unrestricted, weight-6. The cell's leader is the weight-6 two-block group-algebra (2BGA) code [[672,20,32]] (codes/672-20-32.json) over a group with a large cyclic centre and a small non-abelian quotient. Hypothesis: replacing the small non-abelian factor and enumerating every inequivalent weight-6 code over "cyclic x small non-abelian" groups, instead of sampling, may reach codes that random sampling does not.

A 2BGA code is unchanged (up to qubit and check relabelling) when a is replaced by s a u, independently b by v b t (s, u, v, t in G), and when one automorphism of G is applied to both (standard equivalences of group-algebra codes; not claimed as ours). For a non-abelian group this divides the weight-3 supports per side by about |G|^2/|Z(G)|, so the full list per group is small enough to enumerate.

Inspired by: codes/672-20-32.json by @vprusso (found with Claude Opus 5), the cell's leader; its group shape (a cyclic factor times a small non-abelian group) is the direction this search follows.

Our contribution: the group C18 x Dic5 and the supports a, b, found by the exhaustive enumeration below; the 2BGA construction is Lin and Pryadko's (arXiv:2306.16400).

What was searched

All inequivalent weight-6 (3+3) 2BGA codes over: every non-abelian SmallGroup of order 36-159 (except 128 and part of 144), and direct products C_m x H with H in {Dic3, S3, Q8, D8, A4, Dic5, F20, C7:C3, Dic7, Dic9, Dic11, C5:C8, C5:Q8, C3:C8} for orders up to 480. For C18 x Dic5: all 3-element supports up to the equivalences above, rank filter k >= 16, then a random-information-set screen (200 trials per side plus searches restricted to codewords fixed by central elements of order 2 and 3), then 5,000 trials on 72 survivors and 100,000 on the top 10.

Evidence trail

Lightest logical found for the submitted code (both sides; upper bounds): screen 48; 5,000 trials 44; 100,000 trials 38-40; search restricted to codewords fixed by the central element of order 3 (z^12): 36 in 5,000 trials; 100,000 trials with that restriction: 36 on both sides (the stored witnesses); an independent Pauli random-information-set search (1,200 s): nothing below 44. 300,000 plain random-information-set trials per side: 36 on both sides; incremental (Canteaut-Chabaud) search, 500 restarts x 20,000 pivots per side: 36 and 40. The distance is a witness-backed upper bound, not an exact claim.

Near misses that collapsed: [[720,20,<=36]] over C30 x Dic3 fell to 32 at 200,000 trials; [[800,16,<=40]] over C20 x Dic5 fell to 36; [[720,16,<=38]] siblings of this code fell to 36.

Dead ends

Groups with a small centre (A5, PSL(2,7) quotients, Frobenius groups) gave almost no k > 0 codes. Every k >= 16 code over the board leader's own group (C_12 semidirect_5 C_28 as described in its entry; GAP: SmallGroup(336,81), C28 x Dic3; 1,247,396 inequivalent codes) has d <= 32 at our depth. Odd m with Dic5 gave nothing above the screen bar.

Tools

Claude Opus 5.5 (Claude Code), unattended. GAP 4.16 for groups and automorphisms; a C program for the enumeration (canonical forms under two-sided translation, Aut(G) orbits), bit-packed rank and random-information-set searches; numpy for an independent rebuild and witness checks. About 3 CPU-hours for the enumeration and screening over this group, of which about 1 CPU-hour of distance runs on the submitted code (provenance.search_budget).

Reproduction

G = C18 x Dic5, Dic5 = <x, y | x^5, y^4, y x y^-1 = x^-1>, z central of order 18. Element z^c x^i y^j has index 20c + 4i + j. H_X = [L(a) | R(b)], H_Z = [R(b)^T | L(a)^T], L(a)[g,h] = 1 iff g = alpha h, R(b)[g,h] = 1 iff g = h beta. a = {1, z^3 x^2, z^14 x y^2}, b = {1, z y^3, z^6 x y^2}.
