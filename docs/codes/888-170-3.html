[[888,170,3]] contracted affine checkerboard core, exact d = 3

Direction & hypothesis

Issue #2939 recorded a contraction sweep of the affine mod-5 checkerboard cores that was killed at 11 of 36 seeds while still descending. Its 36x27, phases (2,2), order 2 base (k = 170) was one of the three bases that never started. This entry is that base run over all six seeds; the best chain stops at n = 888.

Construction and tooling are #2938's (research/geometric_grafts/campaign.py, @MathysRennela): rectangle completion of the affine mod-5 checkerboard grammar of notes/961-169-3.md, projection onto the encoding core, then pivot moves of degree at most 3 (XOR an own-side row into every other own-side row covering a qubit, delete the row, delete the qubit) accepted only when k is unchanged, d >= 3 holds exactly, and the stabilizer group stays one connected block. Our part is running the sweep to completion and filing what it found.

What was searched

All 36 planned chains, one process per (base, seed), on a laptop and on a Perlmutter CPU node; the sixth base of #2939's list, 34x29 at order 0, is incomplete in the constructor and yields no chain, as campaign.py itself reports. The per-base summary is recorded on issue #2939; for this base:

Two of six seeds end at 888 and the other four at 890, so the base has converged on a two-qubit band. This entry is the seed-2 chain: base 36x27, phases (2,2), order 2; projected onto its encoding core, n = 964, k = 170; 76 accepted moves, deterministic. Pivot moves leave a few empty or repeated check rows behind (four on each side here); those are dropped when the matrices are written out, which changes neither the stabilizer group nor the code.

Where it sits

Max check weight 8 and max check diameter sqrt(20) = 4.47 after contraction, so the cell is weight-8 x local-2d-bilayer. The cell's entries with k >= 170 at d >= 3 sit at n >= 897 ([[897,173,3]], [[899,173,3]]); this one reaches k = 170 at n = 888. It dominates none of them (lower k) and none dominates it (higher n), so it is a new Pareto point. The weight-4 records near this k, [[945,172,3]] and [[923,173,3]], are in a different cell and are untouched.
