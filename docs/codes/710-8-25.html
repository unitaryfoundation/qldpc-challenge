[[710,8,25]] — twelve local reductions of a planar tile code

Direction & hypothesis

The published codes/722-8-25.json is a weight-8, single-layer 2D tile code with eight logical qubits and explicit weight-25 logical operators. Local stabilizer pivots can remove physical qubits while retaining its checks, layout class, and logical witnesses. We sought a smaller n in that board cell. The reported distance is a witness-backed upper bound.

What was searched

Eleven compatible pivots reduced the published 722-qubit code to a staged 711-qubit ancestor. A twelfth single-pivot scan found 101 structural 710-qubit variants preserving check weight at most 8, radius at most 4, and inherited weight-25 logicals. Fifty-six retained k=8, Tanner and stabilizer-block connectivity, and valid logicals. Projection of 354 light ancestor logicals, including stabilizer-row translates and RIS witnesses lifted from the children, refuted nine variants with lighter logicals. A 10,000-trial, pair-depth-8 screen covered all 54 initial survivors. We tested X693/pivot352, X710/pivot351, and Z675/pivot287 at 100,000 trials and pair depth 512. The first two returned weight 25; Z675/pivot287 produced a weight-24 X logical confirmed by the unchanged verifier. We selected X693/pivot352 for the final code.

Evidence trail

The unchanged trusted candidate gate passed the X693/pivot352 JSON with seed 860816874. It checked CSS commutation, n=710, k=8, maximum check weight 8, a connected one-layer radius-4 layout, the two weight-25 logicals, deduplication, and an 8,000-trial RIS refutation search. It marked the weight-8, local-2d-single cell as advancing by lower n. An independent twelve-pivot reconstruction from codes/722-8-25.json matched the candidate checks and coordinates. The Z witness matches the published parent's projection; the X witness descends from a validated RIS result on the 719-qubit ancestor.

On the exact 710-qubit matrices, accelerated RIS returned no logical below 25 in 100,000 pair-depth-512 trials (seed 1222169652), 300,000 pair-depth-512 trials (seed 1222369652), 200,000 pair-depth-4096 trials (seed 4806269652), 1,000,000 pair-depth-512 trials (seed 1223069652), and 1,000,000 pair-depth-4096 trials (seed 4807069652). Every returned logical was checked against those matrices. The initial 10,000-trial pair-depth-8 run returned a weight-26 logical, while the candidate already contained valid weight-25 witnesses.

d≤25 is a witness-backed upper bound. The bounded searches do not prove a minimum distance of 25. The witnessed score is 8 × 25² / 710 = 7.042, versus 6.925 for the published parent. Against codes/717-8-25.json, this code removes 7 physical qubits at the same k, witnessed bound, weight, and layout class.

Dead ends

Z675/pivot287 fell to a trusted-verifier-confirmed weight-24 X logical after its 100,000-trial pair-depth-512 screen. Saved logical projections ruled out nine variants in total. The other shallow-screen survivors have not been deeply confirmed.

Tools

GPT-6 (Codex) ran as one agent for @vprusso. The repository's unchanged verifier and candidate gate, exact GF(2) rank, connectivity routines, and accelerated gf2_fast RIS screened and checked candidates.
