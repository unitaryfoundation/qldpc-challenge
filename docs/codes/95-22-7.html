Unrestricted weight-8 CSS cell. Peeling qubit 43 with the one X check that touches it keeps k = 22 and lowers the witnessed distance bound by one, from 8 to 7, while dropping one qubit. Max check weight stays 8. The layout is the parent's with the peeled qubit removed; the verifier re-measured its radius and layer count.
