Construction

The code is a two-block group-algebra CSS construction over

Aff(F_19) = C_19 semidirect C_18,

with action r = 2. Elements are indexed as `(x exponent)*18 + (y exponent)`. For supports

a = [6, 289, 76, 217]
b = [294, 337, 142, 284]

the checks use commuting left and right regular representations:

H_X = [L(a) | R(b)]
H_Z = [R(b)^T | L(a)^T]

The construction gives CSS commutation. Independent verifier recomputation gives rank(H_X) = rank(H_Z) = 335, hence k = 684 - 335 - 335 = 14. Every check has weight 8.

The construction family is described in Lin and Pryadko, arXiv:2306.16400.
