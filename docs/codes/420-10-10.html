Direction & hypothesis

Target: the unrestricted x weight-6 CSS cell. arXiv:2610.06623v1 (Cruz-Benito, "Large Language Model-Guided Discovery of Weight-Five Bivariate Bicycle Codes") catalogues 1,142 weight-five BB presentations in 630 colored-BLISS classes; this repository's own [[420,6,16]], [[432,8,15]], [[420,8,13]] and [[420,8,14]] entries (merged/opened 2026-10-07) already showed several connected, non-dominated rows in that catalogue carry only interval distance evidence. This row, the paper's class CL-18ce8ea0, is another: k = 10 at n = 420, supported only by a raw BP-OSD-family decoder scalar (no persisted witness) — the single most failure-prone evidence tier on this catalogue by this author's own prior tracking.

What was searched

No fresh search for a new construction. Direct re-verification of one already-published presentation: l = 15, m = 14, A = 1 + x^5 y^2 + x^13 y^3, B = 1 + x^3 y^7, so n = 2*15*14 = 420.

The check matrices were rebuilt from these polynomials with research/kit/bb.py:build_bb and k was independently re-derived as n - rank(H_X) - rank(H_Z) over GF(2), reproducing the paper's k = 10 exactly.

Evidence trail

  • Rebuilt and measured: n = 420, k = 10, max check weight 5, one

    • connected component (no replicated decomposition — confirmed structurally on the rebuilt matrices).

  • The paper's own catalogue records 5 <= d <= 10 for this row: lower

    • bound from exhaustive weight-four exclusion, upper bound from a raw decoder scalar with no persisted witness.

  • An independent randomized search over the kernel of the opposite check

    • matrix (random column permutations each trial, keeping the lightest rows and their pairwise GF(2) combinations under a fresh RREF, 8,000 trials per side, two fixed seeds) found a weight-10 logical operator on each side: zero syndrome against the opposite check matrix, and outside the stabilizer row space, independently re-confirmed by a second, separately coded exclusion check against the same rebuilt matrices. Neither side produced anything lighter than 10. The decoder scalar holds; it did not collapse. The gap to the certified lower bound (d >= 5) remains open — an exact method (MILP) could still in principle find something lighter than 10 — but the independent witness replaces the paper's raw decoder scalar with a checkable one at the same value.

  • Submitted as a witness-backed upper bound, d <= 10, on both sides.

    • It is not certified exact and is not described as such.

  • uv run python verify/qldpc_verify.py codes/420-10-10.json passes

    • locally with ok: true, `earned_distance.d = {value: 10, tier: upper_bound}, and one connected css_equivalent` image. A full-board verify/verify_all.py pass found no fingerprint or signature collision with any existing entry.

Dead ends

None for this row specifically — the search found a weight-10 logical on the first full pass and nothing lighter.

Tools

Human-directed agent work (Claude Code, Claude Opus/Sonnet 5) rebuilding and witness-hardening a published construction, using research/kit/bb.py for construction and verify/qldpc_verify.py for the local gate. The witness search (the randomized kernel/permutation method described above, 8,000 trials/side, two fixed seeds) was run against the same matrices this PR's research/kit/bb.py call reproduces; the method is specified in full above so it can be rewritten directly against those matrices. Roughly 2 CPU-minutes of search on an n=420 code.
