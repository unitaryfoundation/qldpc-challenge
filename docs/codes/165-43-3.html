[[165,43,3]] — Asymmetric hypergraph product of (5x10) and (7x13) classical LDPC matrices

Direction & hypothesis

Targeted missing odd blocklengths n on the CSS weight-6 x unrestricted board. Symmetric algebraic constructions (n = 2lm bivariate bicycle, n = 2N lifted product) skip odd n such as n = 165, whereas an asymmetric hypergraph product n = n_1 n_2 + m_1 m_2 can land directly on 165 = 10 * 13 + 5 * 7 while keeping check weight w <= 6.

What was searched

  • Built a pool of small (m, n) classical LDPC parity-check matrices (n in [5, 23], m < n, regular row/column weights (r, c) in {(2,2), (3,2), (4,2), (4,3), (5,3)}) filtered by exact classical minimum distance d_1 >= 3 and d_1^T >= 3 over GF(2) (seed 2026), yielding 117 (m, n) sizes.
  • Combined pairs matching missing n in [80, 500] via products.hypergraph_product, checking w <= 8, k >= 4, exact classical distance bound min(d_1, d_2, d_1^T, d_2^T) >= 3, and Pareto dominance via research/kit/frontier.py.

Evidence trail

  • Surrogate screening: surrogate.distance_rand at 200 trials returned d <= 3.
  • Trusted gate (verify/validate_candidate.py via research/kit/coordination.py gate): passed: true, board_advancing: true on CSS weight-6 x unrestricted, with no lighter logical in 8000 RIS trials (seed 460074161).
  • Claimed distance is a witness-backed upper bound (confidence: upper_bound).

Dead ends

  • 1D generalized bicycle searches on Z_m (m in {43, 97, 103, 109}) with weight-3 and weight-4 polynomials found no non-trivial gcd(p(x), x^m - 1) divisors due to large multiplicative order of 2 mod m.
  • Distance amplification (local staging search, script not committed) produced valid codes at n = 458 and n = 759, but both were dominated on the board.

Tools

  • Model: Gemini Hydrogen 4
  • Author: @mathysrennela
  • Repo tooling: research/kit/products.py (hypergraph_product), research/kit/frontier.py, research/kit/surrogate.py, verify/validate_candidate.py.

Reproduction

Asymmetric hypergraph product (research/kit/products.py, hypergraph_product(H1, H2)) of a 5 x 10 classical LDPC matrix and a 7 x 13 classical LDPC matrix (n = 10*13 + 5*7 = 165, w = 6, k = 43). Exact H_X and H_Z matrices are embedded in codes/165-43-3.json.
