[[768,258,6]] — girth-12 circulant CSS family (arXiv:2610.19451, Construction I) at N=128

Direction & hypothesis

weight-6 x unrestricted, family tag other. This is the N=128 member of the [[6N, 2N+2, 6]] girth-12 circulant family of arXiv:2610.19451 (Nourozi, Smarandache, Mitchell), the exact instance the paper itself showcases in Section V and Table I. It extends the same high-rate (R = 1/3 + 1/(3N)) corner of the weight-6 x unrestricted frontier as its smaller sibling [[222,76,6]], which is filed as a separate PR: with the board's high-rate d=6 entries currently at [[546,184,6]] (k = 184) and [[960,258,6]] (k = 258, n = 960), a weight-6 code holding k = 258 at n = 768 is undominated — same k and d as the n=960 entry, 256 fewer qubits.

What was searched

Reproduction rather than a search: the pattern is fixed and only N varies. All 131 admissible members (N=31 and N=37..166, n <= 996) were compared against the full verified board on the four frontier axes; 130 are undominated, the exception being N=91 whose parameters equal the existing [[546,184,6]]. This PR files N=128 because it is the paper's own showcase instance and the one that strictly beats an existing frontier entry on n. No distance search was needed: Theorem 1 proves d = 6 exactly and exhibits the weight-6 witness for every admissible N.

Evidence trail

Witness-backed upper bound d <= 6, carried by analytic operators. The Z-side witness is the paper's Eq. (12): block 0 is e_1, block 4 is e_1 + e_{-11} + e_{-5}, block 5 is e_{-11} + e_{-5}, blocks 1-3 zero (indices mod N, weight 6). The X-side witness is its mirror under the incidence-graph isomorphism of the rank proof (pi = (3,2,1,0,5,4), supports reflected t -> -t, block v rescaled by C_{-b_v}). The paper also counts the minimum-weight logical supports at N=128: 3,840 weight-6 supports per CSS side, against 4,864 for the comparable Komoto-Kasai girth-12 code of arXiv:2501.13444 — a 21% reduction that motivates their lower measured frame error rate. Both witnesses were re-checked by the submission tool's search, the trusted verifier, and the refutation pass (8,000 RIS trials, nothing lighter). The paper's exactness proof gives the matching lower bound: every nonzero kernel vector of the column-weight-2 incidence matrix contains a cycle, so d >= 6. Exact certification is out of reach at k = 258, so the board shows d <=.
