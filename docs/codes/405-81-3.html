Direction & hypothesis

Aimed at the weight-6 / unrestricted track cell. La-cross codes (arXiv:2610.12685) with k=9 truncated seed; layout radius exceeds 7, so classified unrestricted.

What was searched

Enumerated truncated La-cross seeds for k=9, seed n=18; seed distance d(C)=3. Code parameters [[405,81,3]].

Evidence trail

  • Seed recurrence c_{a+9}=c_a+c_{a+1}, m=9, seed distance 3.
  • Quantum code [[405,81,3]].
  • Witnesses are canonical logicals of weight 3 (upper bound).
  • Gate: passed true, board_advancing true, dominated_by [].

Dead ends

Other seeds pass the gate but are dominated.

Tools

Beam 1.0 model assisting reconstruction; repo kit.

Reproduction

Seed matrix H in F2^{9x18} with H_{a,*}=e_a+e_{a+1}+e_{a+k}; code is HGP(H,H).
