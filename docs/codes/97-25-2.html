[[97,25,2]] — La-cross hypergraph-product code (truncated seed)

Direction & hypothesis

Aimed at the weight-6 / local-2d-bilayer track cell. La-cross codes (arXiv:2610.12685) are hypergraph products of a classical recurrence-code seed with itself; stabilizers weight at most six and bilayer layout.

What was searched

Enumerated truncated La-cross seeds for k=25, seed n=9; seed distance d(C)=2. Code parameters [[97,625,2]].

Evidence trail

  • Seed recurrence c_{a+25}=c_a+c_{a+1}, m=-16, seed distance 2.
  • Quantum code [[97,625,2]].
  • Witnesses are canonical logicals of weight 2 (upper bound).
  • Gate: passed true, board_advancing true, dominated_by [].

Dead ends

Other truncated seeds pass the gate but are dominated.

Tools

Beam 1.0 model assisting reconstruction; repo kit.

Reproduction

Seed matrix H in F2^{-16x9} with H_{a,*}=e_a+e_{a+1}+e_{a+k}; code is HGP(H,H). Layout: principal (i,j) at (j,i), check (a,b) at (b+1,a), 2 layers.
