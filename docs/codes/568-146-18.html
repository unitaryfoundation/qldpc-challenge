[[568,146,18]] — girth-eight pair-partition CPM at lift 71

The distance claim is a witness-backed upper bound, d <= 18, with explicit weight-18 logicals on both sides. Randomized survival is not a lower-bound certificate. No exact distance or circuit-level distance is claimed.

Direction & hypothesis

Target: the CSS unrestricted x weight-8 cell. TRACKS.md cites the [[168,20,14]] reference at kd^2/n = 23.3333. The current cell is stronger: at base commit 03109da544b960717a39cef0d38d93581f05a54f its largest stored score for n <= 700 is [[584,150,18]], 83.219178. The submitted parameters score 83.281690. This is a small improvement within that size cap, not a record over the extended n <= 1000 tier, where [[904,230,22]] scores 123.141593.

Use the pair-partition CPM construction of Okada and Kasai, arXiv:2607.14091, with (J,L)=(3,8). The cube matching system used in notes/904-230-22.md preserves commutation while allowing exponent mutations. Shorter lifts can slightly improve the rate at a fixed distance; the question was whether any retain d = 18 after deep search.

What was searched

First reproduce the matrices of codes/904-230-22.json exactly from its exponents. Then solve the 36 paired-difference equations in 48 variables over F_P. Their nullity is 19. Draw null-space coefficients with NumPy's seeded generator and mutate one coefficient at a time, modulo P.

Enumerate signed exponent forms of closed non-backtracking base walks of length 4, 6 and 8 on the 3-by-8 protograph. Identify equal forms and forms related by an overall sign; discard the identically zero form. There are 84, 336 and 4830 forms per side. Minimize lexicographically the total number of vanishing length-4/6 forms, then vanishing length-8 forms. Reject an increasing move; accept ties. Retain only draws with no length-4/6 zero. This objective counts distinct exponent forms, not all rooted walks.

Pilot: 32 draws, seed 202610041, cyclic lift schedule 41,43,47,53,67,71, 2000 proposed coefficient moves per restart. Focused follow-up: 64 draws, seed 202610042, schedule 53,67,71,41, 6000 moves per restart. Each draw received exact rank, CSS and weight checks, 16 NumPy witness trials per side, and 2000 accelerated RIS trials per side at pair depth 8, four threads. Preserve returned witnesses and maintain best-distance bins by (n,k). All screening values are upper bounds.

The selected matrix is pilot index 17, P=71, with 136 vanishing length-8 forms summed over both sides. Its ranks are 211 and 211, n=568, k=146, all check rows have weight 8, and all columns have weight 3 on each side. The trusted verifier reports Tanner girth 8 on both sides.

Reproduction

The following independent recipe reconstructs the parity checks, in the same ordering as the submitted JSON:

import numpy as np
P = 71
EX = [[61,36,7,60,1,43,13,29],
      [26,57,18,70,8,26,66,6],
      [22,65,41,34,66,63,9,12]]
EZ = [[1,59,20,3,12,57,26,52],
      [15,56,32,36,68,63,9,5],
      [63,13,55,24,36,53,23,31]]
def lift(E):
    H = np.zeros((3*P,8*P), dtype=np.int8)
    r = np.arange(P)
    for i in range(3):
        for j in range(8):
            H[i*P+r,j*P+(r-E[i][j])%P] = 1
    return H
HX,HZ = lift(EX),lift(EZ)
assert not np.any((HX @ HZ.T) % 2)

The matching triple is M0=(0,4)(1,7)(2,6)(3,5), M1=(0,7)(1,2)(3,4)(5,6), M2=(0,2)(1,5)(3,7)(4,6). For block-row pair (i,j), use M[(i-j) mod 3]. Each pair (a,b) obeys EX[i,a]-EX[i,b]-EZ[j,a]+EZ[j,b]=0 modulo 71, giving even mixed overlap.
