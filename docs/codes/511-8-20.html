How this code was found

the research note submitted with this code · raw markdown · all notes

[[511,8,20]] — single-layer weight-8 tile code (3 x 3 tile, 14 x 14 bulk), one row-space graft

Direction & hypothesis

The X-tile {h00, h01, h11, h22, v02, v10, v20, v21} of codes/288-8-15.json and codes/338-8-16.json (ours) gains distance steadily with the bulk, and codes/800-8-27.json built it at 20 x 20. Between n = 338 and 796 the single-layer weight-8 cell at k = 8 held only weight-6 codes, so we built the tile at the sizes in between.

What was searched

  • The tile on square bulks 12 x 12 to 17 x 17 (n = 392 to 722), the paper's open boundary (Steffan, Choe, Breuckmann,

    • Pereira, Eberhardt, arXiv:2504.09171). On 14 x 14 it gives [[512,8,20]].

  • One row-space graft, the move @dorakingx introduced on this board (notes/280-8-15.md, used there for codes/280-8-15.json and codes/316-8-16.json), takes n from 512 to 511 at unchanged k, weight 8 and radius 4.0. Grafting continued to n = 500 under a per-step RIS filter (20k + 2 x 200k trials), but the result failed a final 2 x 1M-trial check, and bisection over the accepted chain kept only the first graft.

Evidence trail

  • Fresh-seed RIS ladder with this repository's bit-packed engine (verify/gf2_fast.cpp), each rung on its own seed:

    • 20 at 20k, 20 at 200k, 20 at 1M, 20 at 5M trials, nothing lighter. The distance is a witness-backed upper bound, not a proof.

  • Not dominated in weight-8 x local-2d-single: the best k = 8 entry at n <= 511 is codes/454-8-17.json (d 17, weight 6); the next entry

    • reaching d = 20 is codes/658-8-20.json (d 20, weight 6).

Dead ends

  • Above n = 500 the row-space grafts mostly cost distance: the per-step filter passed chains that a longer search then refuted, so we keep only what survives the final check.
  • At n >= 578 the RIS bound kept falling with more trials (22 to 21 at n = 578, 24 to 23 at n = 648), so we report

    • the lightest logical found and treat larger budgets as able to lower it further.

Tools

Claude Opus 5.5 in Claude Code; our research package (tile construction, graft, RIS ladder); this repository's verify/gf2_fast.cpp (RIS), cli/qldpc.py and verify/.

Reproduction

B = 3, X-tile {h00, h01, h11, h22, v02, v10, v20, v21} where h(x, y) joins vertices (x, y) and (x + 1, y) and v(x, y) joins (x, y) and (x, y + 1); Z-tile by T2 (h(x, y) <-> v(2 - x, 2 - y)); the paper's boundary on a 14 x 14 bulk, then the graft above. The checks and the coordinates (one qubit per site of the 45-degree rotated lattice) are in the submission JSON.
