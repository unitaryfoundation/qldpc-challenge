Direction & hypothesis

Aimed at the high-rate end of the weight-9plus x unrestricted cell: no board entry has k >= 282 at n <= 483, so this code is non-dominated in the cell while carrying 58% of its qubits as logicals. The frontier is a Pareto test over (n, k, d, w), not a ranking by kd^2/n (TRACKS.md).

The construction is the polynomial-minor family of arXiv:2610.19459, https://arxiv.org/abs/2610.19459 (Nourozi, Smarandache, Mitchell). Its dimension is designed rather than found: pick a divisor g of x^N+1, take a, b, c as codewords of the cyclic code generated by g, and the CSS condition H_X H_Z^T = 0 holds for any entries at all (their Theorem 2), with k = 3 deg g + 2 deg f for odd N (their Theorem 5). The paper's 13 instances stop at N = 85 with deg g <= 24; what this entry exploits is a divisor that is large AND sparse, which keeps the minors light enough for the 32-qubit check cap while deg g = 92 keeps k high.

Evidence trail

1500 trials: d = 3. 400000 trials: d = 3, side X. The claim is then pinned by argument rather than by search: a weight-1 logical needs an all-zero column of the opposite check matrix, and a weight-2 one needs two *equal* columns, so the complete list of weight-1 and weight-2 candidates is read straight off H_X and H_Z -- here it is empty on both sides, so no operator of weight below 3 exists. d = 3 exactly; the entry is filed as the witness-backed upper bound because the exact tier is a server-side certificate, not a claim a submitter can make.

Board bar: 0, i.e. no entry has k >= 282 at n <= 483 at this check weight, so nothing on the board dominates this one.

Rebuilding from the parameters below reproduces the entry row for row: the entry stores the full circulant expansion, 322 X-rows and 161 Z-rows (the dependencies among cyclic shifts are expected -- every cyclic entry on this board stores them), whose ranks are 135 and 66, so k = 483 - 135 - 66 = 282; maximum check weight 24.
