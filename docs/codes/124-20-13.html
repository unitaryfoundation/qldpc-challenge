[[124,20,13]] GF(4) generalized-bicycle code

Direction & hypothesis

Use a fixed GF(4) polynomial pair and a binary expansion to reach distance 13 at short blocklength; optimize the generator basis without changing the CSS stabilizer spaces. This is a conventional generalized-bicycle construction; no new family or literature novelty is claimed.

Resource comparison: [[128,20,14]] has maximum check weight 16; the submitted code uses four fewer data qubits and lighter checks at distance 13. Across code types, the stabilizer [[130,29,13]] uses six more data qubits but encodes more logical qubits and has maximum check weight 10 and degree 8. These are resource tradeoffs, not a common performance ranking.

What was searched

This promotion confirms one fixed period 31 pair, rather than a new parameter sweep. Two new independent seeds each ran 1,000,000 fast RIS trials on each CSS side on this exact final check basis.
