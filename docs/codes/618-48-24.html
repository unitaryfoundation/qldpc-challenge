Direction & hypothesis

Cell: check weight 11, so the any weight class, unrestricted locality (no layout submitted), CSS board. One step of the distance amplification of Liang, Gu, Chen, Eisert and Wang (arXiv:2609.37231) with the [[N,N-2,2]] amplifier turns a CSS code [[n,k,d]] whose retained checks are linearly independent into a [[(N+1)n - k, (N-2)k, 2d]] code, at check weight max(w_X + 1, w_Z + 1, N + q_Z, N + q_X) with q the largest column weights. The distance doubles exactly, for X and Z separately (Lemma 4 there), so every board base with a certified exact distance gives an amplified code with a proved exact distance. Hypothesis: some of these are new points of the frontier, in particular where the board's amplified entries keep dependent base rows (which only lengthen the code) or use bases without a certificate. Here the base is codes/90-12-12.json ([[90,12,12]] two-block code over a group of order 45, board entry of @FarLab), certified exact in certs/90-12-12.json.

What was searched

All CSS entries of board commit 8042f9da with an exact certificate were amplified on paper with the [[N,N-2,2]] amplifiers for N = 4, 6, 8, 10 (935, 784, 664 and 567 bases with (N+1)n - k <= 1000). Of the admissible candidates with check weight at most 12, 89 are not dominated by a CSS entry in (n, k, d, w) and 57 of these also not by each other; most have d = 4 (high-rate bases of distance 2). The eight with d >= 12 were built and verified, with linearly independent base rows spanning the row spaces chosen to minimize the check weight (randomized greedy; a counting bound shows that no choice of rows gives a lower weight). This code is one of them.
