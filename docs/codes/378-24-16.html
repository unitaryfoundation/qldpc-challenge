Direction & hypothesis

Cell weight-6 x unrestricted, CSS board, n between 300 and 400. Before this filing the weight-6 frontier there held 310-10-22, 330-22-9, 330-68-6, 340-16-18, 360-12-24, 360-20-20, 360-38-8 and 382-36-10: every weight-6 entry with k >= 24 had d <= 10, and every one with d >= 12 had k <= 20. The hypothesis was that two-block group-algebra (2BGA) codes on non-abelian groups of order 150 to 200, which reach parameters the abelian bivariate bicycle torus does not, could put a k >= 24, d >= 12 point into that gap at check weight 6. [[378,24,16]] does, with room: no board entry has n <= 378, k >= 24, d >= 16 and check weight <= 6, and neither [[378,22,16]] nor [[378,24,14]] is dominated either. Its kd^2/n = 16.25 is above every weight-6 entry with k >= 20 on the board.

What was searched

Random-support 2BGA codes H_X = [L(a) | R(b)], H_Z = [R(b)^T | L(a)^T] with a, b three group elements each, both containing the identity (no loss of generality: multiplying a or b by a group element permutes qubits and checks). The group menu was every non-abelian group of order 111 to 200 the kit builds from Cayley-table constructors: dihedral D_n, metacyclic C_n ⋊_r C_k (up to two actions r per (n, k)), C_m x D_k, C_m x A4, C_m x S4, C_m x A5, D_a x D_b, C_m x (C_n ⋊ C_k) for eight small metacyclic factors, S5, and the split metacyclic presentations ZSZ(l1, l2, q) of research/kit/nonabelian_lp.py.

Random supports almost never give usable k (a generic weight-3 element is invertible on the higher-dimensional irreducible blocks of F_2[G]), so the sweep ran a parallel k prefilter: 200,000 draws at 222 <= n <= 400 (seed 51), of which 198,731 had k < 14 and 888 were direct sums; the k histogram of the 381 kept was 14:90, 16:159, 18:49, 20:38, 24:37, 28:3, 32:3, 44:2. Those 381 went through research/kit/search.screen with the gf2_fast backend at 400 trials; 6 advanced the board frontier at screen depth and were confirmed at 20,000 / 200,000 / 2,000,000 fast trials (research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a candidate as soon as its running bound stopped advancing. An earlier serial sweep of 10,000 draws at 300 <= n <= 400 (seed 31) had found the weaker [[378,24,12]] on C_21 ⋊ C_9 (= C_3 x (C_7 ⋊ C_9)), which this code dominates; a [[384,24,12]] on ZSZ(48,4,17) and a [[392,24,12]] bivariate bicycle on Z_14 x Z_14 also held through 2,000,000 trials and are dominated by it too.

Reproduction

The group is research/kit/nonabelian_lp.py's zsz(63, 3, 58), i.e. research/kit/group_algebra.py's metacyclic(63, 3, 58): C_63 ⋊ C_3 with y x y^-1 = x^58, element x^i y^j at index 3 i + j, identity at 0 (58 has order 3 mod 63, so the group is non-abelian of order 189, with elements of order 63; it is not isomorphic to the C_21 ⋊ C_9 of the dominated [[378,24,12]]). With x = (1, 0), y = (0, 1):

a = 1 + x^5 y + x^35 y (indices 0, 16, 106), b = 1 + x^5 y^2 + x^15 (indices 0, 17, 45).
