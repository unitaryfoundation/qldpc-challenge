Direction & hypothesis

Open-boundary planar bivariate-bicycle code from research/local2d/boundary_engine.py build_planar(16, 16, S_f, S_g) with S_f = x^0 y^0 + x^1 y^2 + x^2 y^1 + x^2 y^2 and S_g = x^0 y^2 + x^1 y^0 + x^1 y^1 + x^2 y^0, both 4-subsets of a 3x3 box, on a 16x16 grid; the 48 secondary boundary stabilizers of weight > 8 are dropped, which recovers the weight-8 stabilizer set and leaves the rank unchanged. CSS, n = 2*16*16 = 512, k = 8. LAYOUT: the unit square lattice rotated 45 degrees with the two blocks on its two sublattices, qubit (i, j, block c) at (i + j + c, j - i). That map is injective on (i, j, c), so all 512 sites are distinct and the minimum spacing is exactly 1; the pattern is the one codes/572-8-19.json uses. Because both supports lie in a 3x3 box, every check spans at most di = dj = 2, and a same-block pair separated by (di, dj) sits at distance sqrt(2*(di^2 + dj^2)) = 4, so the measured interaction radius is 4.0 -- inside the local-2d-single cap. The arXiv:2504.09171 B=4 tile has 4x4 supports and lands at sqrt(18) = 4.2426 instead, which is why the whole k = 18 tile family sits in local-2d-bilayer. This construction is this repository's own; the rotated-square layout pattern is taken from the board entry named above, and the distance is a witness-backed upper bound.
