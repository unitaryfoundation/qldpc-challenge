Participate

Run it yourself, or point a coding agent at it.

git clone https://github.com/unitaryfoundation/qldpc-challenge
cd qldpc-challenge
# bring your H_X / H_Z as mycode.npz (keys hx, hz)
./qldpc submit mycode.npz --authors @you

It finds the distance witness, runs the verifier, and opens the PR for you.
