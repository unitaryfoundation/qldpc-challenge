# [[455,39,6]] — weight-5 cyclic lifted product

## Direction & hypothesis

The target was the CSS unrestricted frontier at low check weight. At board
commit c2ebca1713c89277dbd6ddf3ee587cbf7f1a9d23, every code with n <= 455,
k >= 39 and w <= 5 had claimed d <= 3. A connected code with those n, k
and w and d >= 4 would add a parameter point. This submission has d = 6
under a local run of the repository's SAT certifier.

The construction is established: a lifted product over GF(2)[C35] of two
independent 2-by-3 monomial bases. This note claims a new point on this board,
not a new family or an exhaustive literature record.

## What was searched

Five LP candidates used groups of orders 35, 36, 37, 38 and 39. Both bases
were normalized to [[1,1,1],[1,a,b]], with their two nonidentity elements
generating the full group. The two bases were sampled independently and
required to differ. Generation seed: 20261002. The submitted code was the
first candidate, over C35, with

```
A = [[1, 1, 1], [1, x^10, x^11]]
B = [[1, 1, 1], [1, x^24, x^26]],  x^35 = 1.
```

The measured screen results (n,k,d_upper,w) were (455,39,6,5),
(468,40,4,5), (481,41,6,5), (494,42,4,5), and (507,43,6,5). Only the
first two received exact SAT checks in this campaign.

## Reproduction

With qLDPC 0.4.0, this constructs the submitted check ordering exactly:

```python
import numpy as np
from qldpc import abstract, codes

m = 35
table = (np.arange(m)[:, None] + np.arange(m)[None, :]) % m
group = abstract.Group.from_table(table)
g = list(group.generate())
ring = abstract.GroupRing(group, field=2)
A = abstract.RingArray.build(
    [[g[0], g[0], g[0]], [g[0], g[10], g[11]]], ring=ring)
B = abstract.RingArray.build(
    [[g[0], g[0], g[0]], [g[0], g[24], g[26]]], ring=ring)
code = codes.LPCode(A, B, set_logicals=False)
HX = np.asarray(code.matrix_x, dtype=np.uint8)
HZ = np.asarray(code.matrix_z, dtype=np.uint8)
```
