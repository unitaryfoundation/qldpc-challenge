# [[360,18,27]] — weight-8 bivariate bicycle code on Z_60 x Z_3

## Direction & hypothesis

Cell `weight-8 x unrestricted`, CSS board, n between 330 and 380. Before
this campaign the weight-8 frontier there ran 330-10-27, 336-28-20,
336-24-24, 350-8-29, 360-10-28, 364-8-32, 372-14-29 and 378-18-27: no
weight-8 entry with n <= 360 and k >= 18 had d above 24. The hypothesis was
that four-plus-four-term bivariate bicycle (BB) codes on long thin tori
(Z_60 x Z_3 and similar) could put a k = 18 point near d = 27 below
n = 378. [[360,18,27]] does: no board entry has n <= 360, k >= 18, d >= 27
and check weight <= 8, and the d - 2 margin holds ([[360,18,25]] is not
dominated either). It is not a d-only gain (no board entry has the same n,
k and weight), and it complements the [[360,16,28]] filed from the same
campaign (two more logicals, distance one lower).

## What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A and B four
monomials each, both containing 1 (no loss of generality), on every torus
Z_l x Z_m with l >= m >= 3 and 300 <= 2lm <= 400, the torus drawn uniformly
from that list and the other three monomials of each polynomial uniformly
from the torus.

Random supports rarely give k >= 16, so the sweep ran a parallel
generate-and-rank prefilter: 300,000 draws (seed 92), of which 1,338 had
k >= 16 and a connected Tanner graph (research/kit/prescreen.block_structure).
Those went through research/kit/search.screen with the gf2_fast backend at
400 trials; 33 advanced the board frontier at screen depth and were
confirmed at 20,000 / 200,000 / 2,000,000 fast trials
(research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a
candidate as soon as its running bound stopped advancing and skipping any
already dominated by a point staged earlier in the campaign. Three were
staged: this code, a [[378,26,26]] on Z_21 x Z_9 (filed separately) and a
[[378,18,29]] on Z_63 x Z_3.

## Evidence trail

Witness-backed **upper bound** d <= 27, not an exact distance.

| stage | trials per candidate | lightest logical |
|---|---|---|
| screen (gf2_fast, seed from fingerprint) | 400 | 37 |
| confirm | 20,000 | 27 |
| confirm | 200,000 | 27 |
| confirm | 2,000,000 | 27 |
| deep ladder, 3 fresh seeds (55453, 63372, 71291), gf2_fast | 10,000,000 each | 27, 27, 27 |

The bound reached 27 at 20,000 trials and then held; it is still only an
upper bound.

`verify/validate_candidate.py` (through research/kit/coordination.py's gate
wrapper) returned `passed: true`, `board_advancing: true`, `d_only_gain:
false`, label "advances the weight-8 x unrestricted board". Literature
novelty is unverified; board-relative novelty comes from
verify/validate_candidate.py (fingerprint and Weisfeiler-Leman dedup
against every board entry found nothing).

## Dead ends

- Earlier prefiltered 4 + 4 BB sweeps over the whole 222..400 band
  (100,000, 200,000 and 300,000 draws): the best n = 360 point they found
  was a [[360,16,27]], also on Z_60 x Z_3.
- A 3 + 5 split of the same check weight (300,000 and 400,000 draws) gave
  only k = 16 points ([[360,16,28]], [[294,16,24]]).
- Cyclic generalized-bicycle codes with a designed divisor g | x^m - 1,
  weight-4 a and b (check weight 8): 4,000 draws at 300 <= n <= 400 gave
  nothing advancing even at 400 trials.
- Random-support 2BGA on non-abelian groups at check weight 8, 16,000
  serial plus 150,000 prefiltered draws: every screen-depth survivor
  collapsed by 20,000 trials.

## Reproduction

Torus Z_60 x Z_3 (x of order 60, y of order 3), terms (i, j) = x^i y^j:

A = 1 + x^4 + x^9 + x^33 y,
B = 1 + x^17 + x^46 y^2 + x^55 y.

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from bb import build_bb
from css import compute_k
HX, HZ = build_bb(60, 3, [(0, 0), (4, 0), (9, 0), (33, 1)],
                  [(0, 0), (17, 0), (46, 2), (55, 1)])   # n = 360
assert compute_k(HX, HZ) == 18
```

Check sets match codes/360-18-27.json row for row in this order. Witness
search: `surrogate.distance_rand_witness(HX, HZ, trials=2_000_000,
seed=94000276, backend="fast", pair_depth=8)` returns a weight-27 logical.
