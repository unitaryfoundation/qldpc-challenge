# [[72,6,9]]: fold of the gross code along a block-preserving ZX-duality

## Direction & hypothesis

Cell: check weight at most 6, unrestricted locality (no layout submitted), stabilizer board. A CSS code on 2m qubits with a fixed-point-free ZX-duality (an involution of the qubits mapping the X-checks onto the Z-checks) halves to a stabilizer code on m qubits (Burton, Durso-Sabina, Brown, arXiv:2406.09951, Thm. 3.5; the explicit symplectic halving is Def. 3 of Lee, Okada, Maskara, Kasai, Zhou, arXiv:2609.30069). Its nontrivial logicals correspond to the nontrivial Z-logicals of the parent, a logical with y Y factors and t X or Z factors to one of weight 2y + t, so d is at least half the parent's distance and drops where lifts carry many Y. The genon entry 72-6-8-b is a fold of the gross code [[144,12,12]] along a duality that swaps the two blocks. Hypothesis: another duality of the same parent gives a larger distance.

## What was searched

All affine fixed-point-free ZX-dualities (h -> c + psi(h) on each block, psi an automorphism, swapping or preserving the blocks) of ten weight-6 abelian two-block parents with known distance, of length 144 to 756 (among them the gross and two-gross codes and the board entries 510-16-26 and 558-14-28), up to translations, each fold screened by information-set searches scored by Pauli weight (1e4 trials, Lee-Brickell and Stern). For the gross code there are 78 such involutions in five classes: four swap the blocks (psi = -1) and one preserves them; only the gross code has a block-preserving class. This code is the fold along it.

## Evidence trail

- Construction: provenance.construction; n = 72, rank 66, k = 6, all 72 generators of weight 6 without Y.
- Not CSS under single-qubit Cliffords: the generator-level parity system that the board's verifier solves has no solution, and each generator is the only nontrivial stabilizer supported in its support, which lifts the statement to the whole group (Lemma 9 of the README of the package below).
- Lower bound 9, four independent exhaustive computations: (1) tropidist b03ec2d4077f in the board's Pauli encoding, exact 9 in 1.8 s on one thread, recorded in certs/72-6-9-s.json (same pull request); (2) a meet-in-the-middle search over all 84,965,491 Paulis of weight at most 4 pairs none of them to a nontrivial logical, so no nontrivial logical has weight at most 8 (validated on [[5,1,3]] and on the board entries 13-1-5, 17-1-7, 21-1-7 and 72-6-8-b, where it finds 3, 5, 7, 7 and 8); (3) Magma V2.30-1 MinimumDistance: 9, in 411 s; (4) an exhaustive search over the logicals with at most 4 non-Y factors (least weight 12 for t = 0 and t = 4, none for t = 1, 2, 3) together with d = 12 of the parent (certs/144-12-12.json) and the parity of the lifts gives d >= min(12, (12 + 6)/2) = 9.
- Upper bound: the witness. There are exactly 24 nontrivial logicals of weight 9 (exhaustive count), each with three Y factors; an information-set search with 1e5 trials (seed 20261110) found the same 24.
- Final claim: d = 9 exactly. The entry claims exact, which the verifier reads as upper_bound for stabilizer codes; the certificate in this pull request carries the exact tier.

## Dead ends

- The four block-swapping dualities of the gross code give folds with d = 8 (three classes, exact by the meet-in-the-middle search; the class of g -> (0,1) - g is the construction of 72-6-8-b) and d <= 6 (the class of g -> -g: four weight-6 logicals made of Y only).
- The same census on the two-gross code [[288,12,18]] gives only block-swapping classes, with d <= 15 (one of them is the board's 144-6-15-b).
- On the CSS board the parameters [[72,6,9]] at check weight 6 are not new (72-6-9); this code is new on the stabilizer board only, where it dominates 72-6-8-b on d (same n, k and check weight; d <= 8 there by its witness).

## Tools

Claude Opus 5.5 (Claude Code); Python (standard library) for the constructions and checks; C programs for the meet-in-the-middle search, the search over logicals with few non-Y factors, the count of the weight-9 logicals and the information-set search; Magma V2.30-1; tropidist (Cheng, Guo, Pan, arXiv:2611.08247) at the board's pinned commit. About 30 CPU-minutes.
