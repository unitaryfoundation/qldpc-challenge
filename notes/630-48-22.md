## Direction & hypothesis

Target: unrestricted / any-weight cell (w=10). Hypothesis: distance amplification
(arXiv:2609.37231) doubles both k and d of a base code while keeping n within
the admissibility cap when the base is small enough. The [[126,24,11]] bivariate-bicycle
base (already on the board) amplifies to [[630,48,22]] with n=630 <= 700.

## What was searched

paper). No parameter sweep; single construction. Screening: board domination

## Evidence trail

Distance claim d=22 is an upper bound: witness-backed via the tensor product of
the base logicals (weight 11 * 2 = 22). The paper's lower bound gives
ceil(2*11)=22, so the code distance is exactly 22 under the paper's assumptions.
CLI RIS search (20,000 trials + 2,000,000 accelerator trials) found no lighter
logical; gate passed (dry run).

## Dead ends

Deeper amplification (3-4 steps) exceeds the admissibility cap (n > 700) and is
not submittable. One-step amplification of smaller bases (e.g. [[18,4,4]]) is
admissible but dominated.
