# [[224,18,16]] — weight-7 bivariate bicycle code on Z_28 x Z_4

## Direction & hypothesis

Cell `weight-8 x unrestricted` (maximum check weight 7), CSS board, n between 221 and 400. Before this code, the frontier (board plus this campaign's open PRs) at check weight <= 7, d >= 8 and n from 221 to 224 ran through 224-12-19, 224-18-15, 224-24-10. The hypothesis was that random 3 + 4-term bivariate bicycle (BB) codes on tori with 2lm in 222..300, prefiltered for k >= 12, still reach points there that the board does not hold.

[[224,18,16]] does: no board entry has n <= 224, k >= 18, d >= 16 and check weight <= 7. Against [[224,18,15]] (same n, k and weight) the gain is in d only; it also beats other entries, so the gate does not classify the overall gain as d-only. The pair was re-measured at matched depth (see Evidence trail). Its maximum check weight is 7 (3 + 4 terms): weight-8 entries may reach these parameters, but no entry of check weight <= 7 does.

## What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A of 3 and B of 4 monomials, both containing 1 (no loss of generality), on every torus Z_l x Z_m with l >= m >= 3 and 222 <= 2lm <= 300; the torus is drawn uniformly from that list and the other monomials uniformly from the torus.

This sweep (seed 702) drew 400,020 codes in a parallel generate-and-rank prefilter; 797 had k >= 12 and a connected Tanner graph (research/kit/prescreen.block_structure). Those went through research/kit/search.screen with the gf2_fast backend at 400 trials; 2 advanced the board frontier at screen depth and 2 were taken to 20,000 / 200,000 / 2,000,000 fast trials (research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a candidate as soon as its running bound stopped advancing; 1 survived that and was staged.

## Reproduction

Torus Z_28 x Z_4 (x of order 28, y of order 4), terms (i, j) = x^i y^j:

A = 1 + x y^3 + x^17 y^2,
B = 1 + x^10 y + x^18 y^2 + x^23.

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from bb import build_bb
from css import compute_k
HX, HZ = build_bb(28, 4, [(0, 0), (1, 3), (17, 2)],
                  [(0, 0), (10, 1), (18, 2), (23, 0)])   # n = 224
assert compute_k(HX, HZ) == 18
```

Ladder: `surrogate.distance_rand_witness(HX, HZ, trials=20_000_000, seed=<s>, backend="fast", pair_depth=8)` with s in {65350, 73269, 81188} returns logicals of weight 16, 16, 16.
