# [[546,236,4]] — self-dual PSL(2,13) {7,7} hyperbolic surface code

Third of three codes from one paper; see `notes/84-38-3.md` for the shared
construction and `notes/330-68-6.md` for the second. All three are rebuilt from
the algebra of arXiv:2610.10948 by `research/hyperbolic_psl.py`.

**This code is filed at `d ≤ 4`, not the `d = 5` the paper reports for this
member.** That gap is stated plainly below and is not papered over.

## Direction & hypothesis

Target cell: **weight-8 / unrestricted**, family `topological`.

Aimed squarely at the `k` axis at fixed `n`. The board holds six entries at
`n = 546`; the strongest is [[546,46,8]] at weight 5. A weight-7 code at the
*same* blocklength with `k = 236` — five times the incumbent `k` — occupies a
corner nothing else reaches. The {7,7} rate of 3/7 makes that arithmetic
automatic: `n = 546` forces `k = 236`.

## What was searched

Same algebraic search as `notes/84-38-3.md`, over generator classes for
`p = 7, q = 13`, deduplicated on check-support signature. The enumeration yields
**more than 1500 distinct classes**, all giving `n = 546`, `k = 236`.

**Five** of those classes were measured, at 1,500 and 3,000 trials per side on
fresh seeds. All five returned `d = 4` on both sides. None reached the paper's
`d = 5`. A wider scan was started and stopped rather than run to completion over
the remaining ~1500 classes.

This is an **incomplete search, not a refutation**. The paper's `d = 5` is
neither claimed nor disproved here; what is claimed is the witnessed `d ≤ 4` the
search actually reached. The sweep was stopped because the class enumeration
itself — each candidate pair re-deriving the full order-`|Q|` closure — dominates
runtime before any distance search begins.

Screening: `research/kit/surrogate.lightest_logical` on fresh seeds, witnesses
confirmed by `validate_logical`.

Flat on both sides at both depths, so `d ≤ 4` is witness-backed, **not**

`./qldpc submit` re-searched independently through its 2,000,000-trial
accelerator pass and did not tighten either side — useful independent
confirmation that no weight-3 logical exists on either side, and therefore that
the sweep's `d = 4` is not an artefact of the shallower sweep budget. It
returned its own witnesses rather than the sweep's, and the committed file
carries the submit pass's operators.

Gate verdict: `passed: true`, `board_advancing: true`, `dominated_by: []`,
`advances_by: [d, k, n, w]`.

`kd²/n = 8.65`, far below the cell's 123.14 headline. The record is on the
`(n, k)` corner, not on efficiency.

## Dead ends

- **The paper's `d = 5` for this member was not reproduced.** Five measured
  classes all returned 4. Completing the sweep over ~1500 classes is the obvious
  next move and was not done.
- **The paper's headline codes remain unfileable**, 1.7×–51× over the `n ≤ 700`
  cap. See `notes/84-38-3.md`.
- **Class enumeration is the bottleneck at `q = 13`**, not the distance search.

## Reproduction

```bash
uv run --extra research python research/hyperbolic_psl.py 13 7 --list
uv run --extra research python research/hyperbolic_psl.py 13 7 --build 0 --outdir out
uv run --extra research python research/hyperbolic_psl.py 13 7 --scan --target 5 --budget 25
```

The last line is the search that was stopped: it looks for a `d = 5` class and
prints one line per class measured. Anyone picking this up should raise
`--budget` well past 25 before concluding `d = 5` is unreachable.

Matrices are **recomputed from the published construction, not copied** —
arXiv:2610.10948 offers its parity-check matrices on request only, so no
machine-readable artifact was available and none is cited as evidence.

On novelty, see `notes/84-38-3.md`: the nearest prior art is five *planar*
hyperbolic codes (`notes/660-68-8.md`), a different construction from closed
`PSL(2,q)` quotients. The gate's `literature_novelty` label is UNVERIFIED for
every candidate and checks nothing.
