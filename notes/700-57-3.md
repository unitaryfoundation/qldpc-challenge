# [[700,57,3]] — rectangular holey rotated surface code — g=0.73 (r=√2)

## Construction

Rectangular 28×25 extension of the holey rotated surface code [[625,50,3]] (PR #433).

- **Grid:** 28×25 vertex grid, n=700 qubits at integer points (x,y)∈[0,28)×[0,25), min spacing 1.
- **Checks:** Rotated surface code plaquettes (weight ≤4, diameter √2) + boundary pairs (weight 2, diameter 1). X on even cells (i+j even), Z on odd cells.
- **Holes:** Period-3 parity-matched sublattice, margin 3 cells from boundary: cells (i,j) with i%3==0, j%3==0, parity (i+j)%2==0→X-hole, ==1→Z-hole. For 28×25: 8×7=56 hole positions → 28 X-holes + 28 Z-holes. Parent k=1 + 56 holes = 57. Boundary parity adjusted for even Lx: right Z edge start flipped (0 vs 1) to preserve CSS (H_X H_Z^T=0); otherwise X bottom (1), X top (0), Z left (0) as in square case.
- **Layout:** Integer grid, r=√2 exactly (unit squares √2, boundary pairs 1), layers=1, class local-2d-single, weight class weight-4.

## Parameters

- n=700, k=57, d=3 (hole-to-boundary weight-3 string), w=4, r=√2≈1.4142, layers=1
- g = 4kd²/(n r⁴) = 9k/n (at d=3, r=√2) = 9×57/700 = 0.732857... vs 0.72 for 625-50-3.
- Comparison: 625-50-3 (25×25) → g=0.72 (k=50); 675-50-3 (27×25) → g=0.666 (no extra hole row). 28×25 is maximal n≤700 odd/even rectangular that adds a hole row (Nx 7→8).
