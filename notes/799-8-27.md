## Exact reduction

In the source numbering, take X row 0

```text
S = {2, 400, 401}
```

and choose `a = 400`.  The only other X generator meeting `a` is source row
18, with support `{1,22,400,420,421}`.  Replace it by its sum with `S`, so that
`a` occurs only in `S`.  Apply the CNOT fan-out from control `400` to targets
`2` and `401`.  On the binary check matrices this is

```text
H_X[:, b] ^= H_X[:, 400]   for b in {2, 401}
H_Z[:, 400] ^= H_Z[:, b]   for b in {2, 401}.
```

The first operation maps `S` to the weight-one stabilizer `X_400`.  The second
maps column 400 of `H_Z` to the parity over `S`, which is zero for every Z row
by CSS commutation.  Qubit 400 is therefore disentangled.  Delete `X_400` and
qubit 400, and map each surviving source index `q > 400` to `q - 1`.

This is a Clifford equivalence followed by removal of a stabilized product
qubit, hence `k` remains 8.  Every surviving qubit keeps its source coordinate.
The maximum check weight remains 8, the measured interaction radius remains
4.0, and the layout remains single-layer with one qubit per site.

Both source logical witnesses avoid qubit 400.  Applying the same Clifford and
renumbering therefore gives the two weight-27 witnesses recorded in the JSON.
They independently pass the kernel and nontriviality checks.  The distance
claim remains an upper bound, not an exact-distance certificate.

## Independent refutation

The current challenge verifier passes the schema, CSS commutation, claimed
dimension, both logical witnesses, weight class, and all locality checks.  The
candidate then survived two independent local reproductions of the current CI
refutation sequence:

| pass | base seed | ordinary RIS | RIS-fast | lightest found |
| --- | ---: | ---: | ---: | ---: |
| A | 2026101001 | 120880 | 8000000 | 27 |
| B | 2027101004 | 120880 | 8000000 | 27 |

Each pass also ran the circulant-GB detector and a 50000-trial orbit-fold
stage.  This tile code is not circulant GB, and the orbit stage found no
applicable folded partition.  Across 16241760 post-reduction RIS trials, no
logical below weight 27 was found.  These are strong bounded searches, not a
proof of exact distance.
