# [[60,6,10]] — 2BGA code on ab(5,3,2) (|G| = 30), a = [0, 3, 6, 20], b = [0, 9, 12, 14]

## Direction & hypothesis

Track cell: unrestricted x weight-8 (max check weight 8). The board is dense below n = 110, so the
target was a specific hole: a point with n' <= 60, k' >= 6, d' >= 10 at check weight <= 8 that no board
entry occupies. This code gains on d, n against
[[60,6,9]] (w=8, `codes/60-6-9.json`), [[66,6,10]] (w=8, `codes/66-6-10.json`). The hypothesis behind the sweep was that the
small-group two-block (2BGA) family, enumerated over every group of order 8..55 the kit can build
(abelian, metacyclic, dicyclic, generalized dihedral, a few semidirect and matrix groups) with
supports of size 2+2, 3+3 and 4+4, still holds non-dominated points that the board's generalized-bicycle
and bivariate-bicycle entries missed, because the board's small-n entries come mostly from cyclic groups
and tori. Board-relative novelty is from `verify/validate_candidate.py`; literature novelty is unverified
(Lin-Pryadko's 2BGA tables, arXiv:2306.16400, cover many small groups and this instance may be in them).

## What was searched

H_X = [L(a) | R(b)], H_Z = [R(b)^T | L(a)^T] over F_2[G] with G = the abelian group Z_{5}} x Z_{{3}} x Z_{{2} built as `group_algebra.cyclic_product(5,3,2)`: elements are the tuples in `itertools.product` order, index = position in that order (identity = 0). a = [0, 3, 6, 20] and b = [0, 9, 12, 14] are lists of element indices (|a| = 4, |b| = 4, check weight 8).

Sweep (research/kit samplers and `surrogate.distance_rand`, backend gf2_fast, one thread per candidate,
60 processes):
- 2bga: 3,044,305 candidates built, 1,771,957 with k >= 3 screened at 400 gf2_fast RIS trials, 416 unique records non-dominated on the board at that reading; funnel 20000 trials: 416 of 416 still advancing, 200000 trials: 416 of 416 still advancing.

Supports were drawn with the identity in both a and b (left/right translation of a or b is a qubit
relabelling, so this loses nothing), distinct elements only, and every candidate was compared with the
live board (every CSS entry with n <= 130, on n, k, d and max check weight) before any further trials
were spent. The screening reading is an upper bound, so this funnel never discards a true advance.

## Evidence trail

Packaging witnesses: `surrogate.lightest_logical`, 8,000 NumPy trials per side, seed 11 -> X-logical of
weight 10, Z-logical of weight 10; d = min = 10.

Deep ladder (fresh seeds, `surrogate.distance_rand_witness` backend gf2_fast, 60 threads, pair depth 8):

| trials per seed | seed | side of lightest | lightest logical | time |
|---|---|---|---|---|
| 20,000,000 | fast seed 47732 | X | 10 | 9.0 s |
| 20,000,000 | fast seed 55651 | X | 10 | 8.9 s |
| 20,000,000 | fast seed 63570 | X | 10 | 9.0 s |

Ladder verdict: corroborated (min over rungs = 10, claimed 10).
A SAT search for anything lighter (`verify/sat_certify.py`, selector encoding, 600 s per solve) returned X: status UNSAT; Z: status UNSAT (d_exact flag True). The submission is filed as `upper_bound` regardless; an exact tier is the server's to award.

Final claim: witness-backed upper bound d <= 10 (`confidence: upper_bound`), with d_X <= 10 and d_Z <= 10.

## Dead ends

- Of the stage-1 non-dominated records, most collapsed when the trial budget rose (see the funnel counts
  above): a d read at 400 fast trials is routinely 1-3 too high at n ~ 60-110.
- Abelian 2BGA (bivariate bicycle) supports at 3+3 on l*m in 32..55 reproduced board points but opened no new
  weight-6 cell: the board's BB coverage there is effectively complete.
- Weight-4 (2+2) supports on non-abelian groups never beat the toric-code line kd^2/n = 2.

## Reproduction

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from group_algebra import build_2bga
from group_algebra import cyclic_product
mul, _ = cyclic_product(5,3,2)
HX, HZ = build_2bga(mul, [0, 3, 6, 20], [0, 9, 12, 14])   # n = 60, k = 6
```

Then `make_submission(HX, HZ, ..., trials=8000, seed=11)` from `research/kit/submit.py` reproduces the
witnesses; the deep ladder used three fresh seeds at the trial counts in the table above.
