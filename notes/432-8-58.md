# [[432,8,58]] — weight-10 distance-first metacyclic 2BGA

## Direction & hypothesis

Target cell: `weight-9plus x unrestricted`, operational efficiency
`K = kd^2/n`. The distance-first route of `2026-08-08-leaderboard-opportunity-map.md`
(Opportunity D) posits that a moderate check weight (8--12) with a small
logical dimension (`k` between 4 and 16) can win a Pareto axis by trading rate
for exceptionally large distance, in the style of `[[348,4,34]]`,
`[[376,6,32]]`, and `[[684,8,85]]`.

This code is a **weight-10, `k = 8`, `d = 58`** metacyclic two-block group
algebra (2BGA) code: `K = 8 · 58² / 432 = 62.3`, with witnesses certifying
`d <= 58`. It advances the `weight-9plus x unrestricted` Pareto frontier:
no board code with weight <= 10 matches it on `(n, k, d)` simultaneously.

## What was searched

Swept 2BGA-generated generalized-bicycle families: metacyclic and
dihedral lifted products at `n` in 240--504, `k` in 4--16, supports `a`, `b`
of total weight 8--12. Stage 1 (`research/candidates/oppD/src/d_yield.py`)
screened 310 survivors with cheap RIS; stage 2
(`research/candidates/oppD/src/d_confirm.py`) re-confirmed the top 30 at
12,000 trials. The confirmation of this spec (screen d = 70, confirmed d = 58
at 12k trials) held, while all other top-30 screens collapsed
(e.g. `[[432,12,70]]` screen -> d = 24 actual: screen inflation is severe,
which is exactly why the deep confirm ran before submission).

## Evidence trail

- Spec: metacyclic group (n=36, k_m=6, r=13), supports
  `a = [98, 99, 163, 184, 185]`, `b = [39, 45, 64, 137, 149]`.
- CSS: `HX` 216 x 432, `HZ` 216 x 432, commutation verified, `k = 8`.
- Max check weight: 10 (both sides), so the code lands in
  `weight-9plus x unrestricted`.
- Distance: X witness weight 58, Z witness weight 58 (RIS at 12,000 trials);
  the verifier's own refutation (8,000 fresh trials, seeded differently)
  found no lighter logical. Filed as `upper_bound`, not exact-certified.
- Gate: `verify/validate_candidate.py` -> `passed: true`,
  `board_advancing: true`, `dominated_by: []`, `exact_duplicate_of: null`
  in the `weight-9plus x unrestricted` cell.
- The w-axis mattered: heavier codes (e.g. `[[390,82,38]]` w=32, K=303) have
  higher raw K but do **not** dominate a weight-10 point; this code is the
  strongest distance-first w<=10 point on the board.

## Dead ends

- Every other top-30 screen survivor (d_screen >= 50) collapsed at 12k
  trials: `[[432,12,70]]` -> d 24, `[[420,12,66]]` -> d 30. Screen d is a
  noisy upper bound and must never be used as a submission claim.
- Dihedral lifted products at the same sizes did not reach the d >= 40 bar.
