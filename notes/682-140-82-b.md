## Reproduction

Let `C(S)` be the 341 by 341 binary circulant whose row `i` has ones at columns
`(i+s) mod 341` for `s` in `S`. Use
`H_X = [C(A) | C(B)]` and `H_Z = [C(B)^T | C(A)^T]`, with

```text
A = [0,7,22,41,51,95,114,165,176,198,224,238,268,289,312]
B = [8,66,80,96,105,115,178,192,205,221,256,279,280,293,324]
```

The following standard-library-only snippet reconstructs the submitted rows:

```python
import json
from pathlib import Path

m = 341
A = [0,7,22,41,51,95,114,165,176,198,224,238,268,289,312]
B = [8,66,80,96,105,115,178,192,205,221,256,279,280,293,324]
hx = [sorted([(i+a) % m for a in A] +
             [m+(i+b) % m for b in B]) for i in range(m)]
hz = [sorted([(i-b) % m for b in B] +
             [m+(i-a) % m for a in A]) for i in range(m)]
doc = json.loads(Path("codes/682-140-82-b.json").read_text())
assert doc["checks"]["X"] == hx
assert doc["checks"]["Z"] == hz
```
