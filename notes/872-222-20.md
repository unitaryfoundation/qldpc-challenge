## Reproduction

Rebuild the matrices in the exact submitted ordering with this recipe:

```python
import numpy as np
P = 109
EX = [[13,82,43,52,73,10,49,97],
      [48,26,5,31,30,71,42,68],
      [25,95,9,6,93,0,23,74]]
EZ = [[106,2,90,58,57,16,96,17],
      [101,108,22,105,83,36,59,41],
      [101,97,58,39,60,33,72,76]]
def lift(E):
    H = np.zeros((3*P,8*P), dtype=np.int8)
    r = np.arange(P)
    for i in range(3):
        for j in range(8):
            H[i*P+r,j*P+(r-E[i][j])%P] = 1
    return H
HX, HZ = lift(EX), lift(EZ)
assert not np.any((HX @ HZ.T) % 2)
```

Cube matchings: M0=(0,4)(1,7)(2,6)(3,5), M1=(0,7)(1,2)(3,4)(5,6),
M2=(0,2)(1,5)(3,7)(4,6). For block-row pair (i,j), each (a,b) in M[(i-j) mod
3] satisfies EX[i,a]-EX[i,b]-EZ[j,a]+EZ[j,b]=0 modulo 109. These paired
differences establish CSS commutation. The matrices have ranks 325 and 325,
hence k=872-650=222; every check has weight 8 and every column has weight 3.
The inline recipe reproduces the matrix object without requiring the original
search workspace.
