# [[396,202,6]] — Cornucopia q=11 with searched column shifts

## Direction & hypothesis

Target cell: weight-9plus × unrestricted on the CSS board (weight-12 checks,
no layout), family `other`. The Cornucopia construction (Lu, Li, Ma et al.,
"A modular quantum computer based on Cornucopia codes", arXiv:2610.19073v2)
fixes only the row maps; its twelve column shifts are free parameters. The
hypothesis: at this admissible q (n = 36q ≤ 700) an unexplored shift tuple
would produce a code that is not dominated by the Cornucopia instance of the
same (n, k) already on the board.

## What was searched

200-tuple random column-shift tuples at q=11 (sA, sB ∈ Z_11^6 each), every code
screened with the `gf2_fast` randomized logical search at 500 trials, seeds
from the sweep's own RNG stream. The best tuple, sA=[3, 0, 7, 9, 2, 4], sB=[4, 0, 2, 6, 8, 5], was then
confirmed at 10,000 accelerator trials plus a 1,000-trial-per-side RIS pass.

## Evidence trail

Ladder for the submitted code: 500-trial screen → d<=6; 10,000-trial
accelerator pass → d<=6 (witnesses embedded in the entry); the gate's own
refutation on a fresh seed found nothing lighter. The claim is a
witness-backed upper bound, not an exact distance.

## Dead ends

The same sweep at q=13 produced nothing above d ≤ 6 while the board already
holds q=13 at d=8, so q=13 was dropped. Within this sweep, tuples screened at
500 trials routinely collapsed to d ≤ 4 at smaller q; none of the confirmed
readings moved below the submitted bound.

## Tools

Model: Beam 1.0. Repo tooling: `research/kit/submit.make_submission`,
`research/kit/surrogate` (NumPy + `gf2_fast` backend), gate
`research/kit/coordination.py gate`. Build matrices per arXiv:2610.19073v2
Methods, Eq. (1).

## Reproduction

q=11, row maps ρ_A(0)=r+1, ρ_A(1)=2r+2, ρ_B(2)=r+1, ρ_B(3)=2r+2 (identity
otherwise), column shifts sA=[3, 0, 7, 9, 2, 4], sB=[4, 0, 2, 6, 8, 5] on Z_11.
Index data qubit (b,r,c) as (3b+r)q+c; HX block (i,j) = [A_(j-i) | B_(j-i)],
HZ block (i,j) = [B_(i-j)^-1 | A_(i-j)^-1] for i∈{0,1,2}, j∈{0..5}.
