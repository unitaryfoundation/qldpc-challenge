# [[682,152,80]] cyclic generalized-bicycle CSS code

## Direction and hypothesis

The CSS weight-9plus, unrestricted cell currently includes
`[[682,142,d≤82]]` in `codes/682-142-82.json`, with witnessed-bound score
`142 × 82² / 682 = 1400.01`. A code with 152 logical qubits beats that score
when its best saved distance bound is at least 80. This submission has maximum
check weight 30 and witnessed-bound score `152 × 80² / 682 = 1426.39`.

## Construction

Let `C(S)` be the 341 by 341 binary circulant whose row `i` has ones in
columns `(i+s) mod 341` for `s ∈ S`. Set

```
a = [0, 64, 83, 136, 138, 145, 149, 158, 169, 200, 211, 217, 219, 224]
b = [23, 44, 69, 111, 124, 145, 165, 169, 178, 211, 220, 238, 241, 244, 254, 273]
H_X = [C(a) | C(b)]
H_Z = [C(b)^T | C(a)^T]
```

The matrices commute. The two circulant polynomials have a common divisor of
degree 76 in `GF(2)[x]/(x^341 - 1)`, giving `k = 2 × 76 = 152`.

## Search and evidence

The search began with the degree-71 cyclic ideal recovered from the published
`[[682,142,d≤82]]` code. Permuted-kernel RREF samples and two rounds of
pairwise shifted XORs produced sparse words. The submitted pair has 14 terms
in `a` and 16 in `b`.

The lightest saved logical is a weight-80 single-block X operator. Its support
and the valid weight-80 Z image under the generalized-bicycle dual permutation
are included in `codes/682-152-80.json`. Every reported support was checked
against the full CSS matrices as a non-stabilizer logical.

The unchanged `verify/validate_candidate.py` gate passed with fresh seed
1223920244, found no lighter logical in its 8,000-trial refutation, and found
no exact or Weisfeiler–Leman-equivalent board entry. Five further independent
8,000-trial runs of the repository's Python refutation gate found no logical
below 80 (seeds 312600034, 312601034, 312602034, 312603034, 312604034).
These are searches, not a lower-bound proof: **`d ≤ 80` is a witnessed upper
bound**, and a future refutation may lower it.

## Other screened pairs

weight-72 logical. Another `k=162` pair survived one million single-block

excluded. Several other sparse pairs fell below the required score under
