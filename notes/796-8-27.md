# [[796,8,27]] two-graft planar tile-code reduction

## Direction and hypothesis

The weight-8, local-2d-single CSS headline is `[[798,8,d≤27]]` in
`codes/798-8-27.json` by `@dorakingx`, with `kd²/n = 8 × 27² / 798 = 7.308`.
Two independent qubit reductions raise the witnessed score to
`8 × 27² / 796 = 7.327`, provided a lighter logical is not found.

## Construction

All row and qubit indices here refer to the source `codes/798-8-27.json`.
The first X-side row-space stabilizer is the XOR of rows 360, 376, 377, and
378. It has support `S1={360,361,378,762,781,782}`. Replace row 376 with
`S1`, use `S1` to clear qubit 378 from other X checks, apply CNOTs from
qubit 378 to every other qubit in `S1`, then delete the disentangled qubit
378 and its weight-one check.

The second X-side stabilizer is the XOR of source rows 0, 1, 18, and 19.
It has support `S2={1,3,21,22,399,400,418,420}` and is disjoint from
`S1`. After the first deletion, source qubit 399 has index 398. Replace
source row 0 with `S2`, clear that qubit from other X checks, apply the
corresponding CNOT fanout, and delete the second disentangled qubit and
weight-one check. Every surviving qubit keeps its source coordinate.

The final matrices are reproduced by this sequence. The repository verifier
computes `n=796`, `k=8`, CSS commutation, maximum check weight 8, a
connected stabilizer group, one layer, and interaction radius 4. The
submitted X-27 and Z-27 logical witnesses validate on the full matrices.
The X witness is transported from the source code; the Z witness is
transported from the GPU-found Z-27 logical on the intermediate
`[[797,8,d≤27]]` code in PR #3385. **`d≤27` is an upper bound**, not a
proof of exact distance.

## Search and checks

The unchanged `verify/validate_candidate.py` gate passed against the clean
board with seed 1110336512. It found no exact or Weisfeiler–Leman-equivalent
board entry and marked the code as advancing through lower `n`.

The general accelerated RIS search found no logical below 27 in one million
trials at pair depth 256, nor in 500,000 trials at pair depth 512. Five
independent pure-Python searches at 8,000 trials each found weights 29, 30,
29, 27, and 31. These searches can refute a distance claim but do not
establish a lower bound.
