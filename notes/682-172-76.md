# [[682,172,76]] — recombined cyclic generalized-bicycle CSS code

## Direction & hypothesis

The published uncapped CSS `kd²/n` record is `codes/682-142-82.json`,
scoring 1400.012. This code has k = 172, maximum check weight 32,
and a witnessed upper bound of 76. At that bound it scores
172 × 76² / 682 = 1456.704. Exact distance and literature novelty
are open.

## What was searched

The construction uses two circulants over Z₃₄₁, with supports

```
a = [0,1,9,15,48,82,87,102,117,120,137,189,198,244,252,269,296,315]
b = [0,1,32,33,90,94,132,134,152,187,196,253,280,297]
```

For each row i, X has supports `(i+a) mod 341` and
`341+(i+b) mod 341`; Z has `(i-b) mod 341` and
`341+(i-a) mod 341`. The reproduction script builds all 682 check
rows, checks equality to the submitted matrices and GF(2) ranks
255/255, and validates the saved operators. This is an ordinary CSS
generalized-bicycle code; “recombined” records how its sparse
generators were found in the divisor-ideal search, not a distance
theorem.

## Evidence trail

The initial saved-operator bound was X80 and Z80. A 1,000-trial folded
screen found X77 and Z77, and a 10,000-trial structural screen found
X84. These raw witnesses and the initial complete code are committed
in `research/evidence/682-172-css-ar0018/`.

An independent two-thread native RIS run at pair depth 512 returned
Z77 after 100,000 trials and X77 after 1,000,000 trials, with seeds
306190000 and 306190001. A second independent run at the same depth
returned X80 after 100,000 trials and X76 after 1,000,000 trials,
with seeds 306220000 and 306220001. The submitted file uses the Z77
and X76 witnesses. Both raw runs, their pinned requests, and every
support are committed under the same evidence directory. The X76
operator passed direct logical validation on the exact submitted
checks. These witnesses certify **d ≤ 76**, not an exact distance or
a lower bound.

The unchanged candidate validator passed at seed 310618276 against
clean board commit `70767dc9`, finding no lighter logical in its
8,000-trial refutation, no exact or WL-equivalent board entry, and no
dominating CSS code. Its verdict is
`research/evidence/682-172-css-ar0018/validator-verdict.json`.
The validator identifies `codes/682-172-50.json` as a same-parameter
peer. A matched-depth audit searched both codes at 100,000 trials,
pair depth 512 and seed 306240000. It found Z78 on each, both directly
validated, but neither reached its own claimed bound (then 77 and 50;
the submitted bound is now 76).
The audit is **inconclusive** and establishes no distance advantage
over the peer. Its record and both raw supports are committed in
`research/evidence/682-172-css-ar0018/`. The audited input has the
same check matrices as the submitted file; the latter also carries
the independent Z77 witness from the earlier local search.

## Dead ends

The earlier d≤80 and d≤77 bounds were superseded by independent X76
and Z77 operators. The earlier raw supports remain as evidence.
Enumerating combinations of up to four periodic cosets and pairs of
cyclic shifts of the earlier saved operators found no lower logical
at that time; neither restricted search proves the minimum distance.
