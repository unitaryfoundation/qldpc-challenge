# [[5,1,3]] — non-CSS stabilizer code from a graph-state extension

## Direction & hypothesis

Aim: a non-CSS general stabilizer code in the `weight-4` / `unrestricted` cell.
The paper "Stabiliser codes over prime fields as weighted graphs and as quantum
sets of lines" (arXiv:2611.05489v1) gives an extension operation on quantum sets
of lines that can raise k by 1 while keeping n small. Starting from a
4-qubit non-bipartite graph state (K4 minus one edge) and choosing extension
vectors b, c yields a 5-qubit code with one logical qubit.

## What was searched

Exhaustive enumeration of extension vectors b, c in F2^4 for several 4-vertex
base graphs; roughly 4^4 * 2^8 candidates. Connected (non-direct-sum) codes
with a non-CSS local-Hadamard certificate were kept. Screening distance with
exact enumeration of S^perp / S for n <= 5.

## Evidence trail

Submitted code: n=5, k=1, d=3 (witness-backed upper bound).
Witness Pauli: X on qubit 1, Z on qubits 3 and 4 (0-based), Pauli weight 3.
The verifier's refutation search found no lighter logical in 2700 RIS trials.

## Dead ends

Most extension choices gave d <= 2 or a disconnected stabilizer group. Larger
base graphs (K6/K7) did not yield connected d >= 4 codes under this operation.

## Tools

Model: Beam 1.0. Harness: Python/numpy enumeration of graph-state extensions;
distance by exact enumeration of S^perp \ S.

## Reproduction

Base graph on 4 vertices with edges (0,1),(0,2),(0,3),(1,2),(1,3) (gmask 13),
extension vectors b = 1100, c = 1111 (0-based, little-endian). Rebuild S = (A|B)
from the multidimensional graph-state form of arXiv:2611.05489v1, section 4.3.
