# [[240,20,19]] — weight-8 bivariate bicycle code on Z_12 x Z_10

## Direction & hypothesis

Cell `weight-8 x unrestricted` (maximum check weight 8), CSS board, n between 221 and 400. Before this code, the frontier (board plus this campaign's open PRs) at check weight <= 8, d >= 9 and n from 221 to 240 ran through 224-24-16, 232-62-12, 240-10-22, 240-18-20, 240-22-18, 240-24-17, 240-28-16. The hypothesis was that random 4 + 4-term bivariate bicycle (BB) codes on tori with 2lm in 240..340, prefiltered for k >= 16, still reach points there that the board does not hold.

[[240,20,19]] does: no board entry has n <= 240, k >= 20, d >= 19 and check weight <= 8. Against [[240,20,18]] (same n, k and weight) the gain is in d only; it also beats other entries, so the gate does not classify the overall gain as d-only. The pair was re-measured at matched depth (see Evidence trail).

## What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A of 4 and B of 4 monomials, both containing 1 (no loss of generality), on every torus Z_l x Z_m with l >= m >= 3 and 240 <= 2lm <= 340; the torus is drawn uniformly from that list and the other monomials uniformly from the torus.

This sweep (seed 623) drew 500,010 codes in a parallel generate-and-rank prefilter; 2,265 had k >= 16 and a connected Tanner graph (research/kit/prescreen.block_structure). Those went through research/kit/search.screen with the gf2_fast backend at 400 trials; 15 advanced the board frontier at screen depth and 15 were taken to 20,000 / 200,000 / 2,000,000 fast trials (research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a candidate as soon as its running bound stopped advancing; 1 survived that and was staged.

## Dead ends

- In this sweep 14 of 15 screen-depth survivors collapsed below the frontier by 2,000,000 trials: 400-trial readings run several units high at this n.
- Earlier in this campaign on the same band: cyclic generalized-bicycle codes with a designed divisor at weights (3,3) and (4,4), random-support 2BGA on non-abelian groups at check weight 8, non-abelian lifted products, and weight-6 BB/2BGA at k >= 28 gave nothing that survived 20,000 trials on the frontier.
- Random 2 + 6 splits at check weight 8 never reached k >= 18 with an advancing distance.

## Reproduction

Torus Z_12 x Z_10 (x of order 12, y of order 10), terms (i, j) = x^i y^j:

A = 1 + x^3 y^9 + x^9 y^6 + x^10 y^5,
B = 1 + x^2 y + x^3 y^8 + x^10.

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from bb import build_bb
from css import compute_k
HX, HZ = build_bb(12, 10, [(0, 0), (3, 9), (9, 6), (10, 5)],
                  [(0, 0), (2, 1), (3, 8), (10, 0)])   # n = 240
assert compute_k(HX, HZ) == 20
```

Ladder: `surrogate.distance_rand_witness(HX, HZ, trials=20_000_000, seed=<s>, backend="fast", pair_depth=8)` with s in {68057, 75976, 83895} returns logicals of weight 19, 19, 19.
