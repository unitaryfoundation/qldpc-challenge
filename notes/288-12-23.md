# [[288,12,23]] — weight-7 bivariate bicycle code on Z_36 x Z_4

## Direction & hypothesis

Cell `weight-8 x unrestricted` (maximum check weight 7), CSS board, n between 221 and 400. Before this code, the frontier (board plus this campaign's open PRs) at check weight <= 7, d >= 11 and n from 228 to 288 ran through 240-16-18, 248-10-21, 248-20-13, 252-12-22, 252-16-20, 252-20-16, 254-14-21, 270-24-12. The hypothesis was that random 3 + 4-term bivariate bicycle (BB) codes on tori with 2lm in 222..400, prefiltered for k >= 12, still reach points there that the board does not hold.

[[288,12,23]] does: no board entry has n <= 288, k >= 12, d >= 23 and check weight <= 7. Its maximum check weight is 7 (3 + 4 terms): weight-8 entries reach these parameters or better, but no entry of check weight <= 7 does.

## What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A of 3 and B of 4 monomials, both containing 1 (no loss of generality), on every torus Z_l x Z_m with l >= m >= 3 and 222 <= 2lm <= 400; the torus is drawn uniformly from that list and the other monomials uniformly from the torus.

This sweep (seed 701) drew 400,020 codes in a parallel generate-and-rank prefilter; 907 had k >= 12 and a connected Tanner graph (research/kit/prescreen.block_structure). Those went through research/kit/search.screen with the gf2_fast backend at 400 trials; 34 advanced the board frontier at screen depth and 33 were taken to 20,000 / 200,000 / 2,000,000 fast trials (research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a candidate as soon as its running bound stopped advancing; 3 survived that and were staged.

## Reproduction

Torus Z_36 x Z_4 (x of order 36, y of order 4), terms (i, j) = x^i y^j:

A = 1 + x^17 y + x^22 y^3,
B = 1 + x^25 y^3 + x^27 + x^31.

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from bb import build_bb
from css import compute_k
HX, HZ = build_bb(36, 4, [(0, 0), (17, 1), (22, 3)],
                  [(0, 0), (25, 3), (27, 0), (31, 0)])   # n = 288
assert compute_k(HX, HZ) == 12
```

Ladder: `surrogate.distance_rand_witness(HX, HZ, trials=10_000_000, seed=<s>, backend="fast", pair_depth=8)` with s in {65013, 72932, 80851} returns logicals of weight 23, 23, 23.
