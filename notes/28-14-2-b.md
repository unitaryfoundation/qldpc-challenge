# [[28,14,2]] — PP-SCALE with mixed ±1 column slopes, code-calculus v0.3.1rc

## Direction & hypothesis

Target cell: weight-4 / unrestricted. The lead: the 2026-11-23 stress
campaign found that `PP-SCALE`'s rung-3 SNF path recaptures known matrices
whenever the slope pattern is uniform (all-−1-slope bundles are position
reflections of the unit-slope grid), so the productive part of the family is
bundles whose slope pattern is *not* uniform across columns. A mixed ±1
pattern (Q rows alternating 1, 0, 1, 0) gives columns with slopes 1 and
P − 1 = −1; the resulting matrices are not in the unit-slope grid, and the
question was whether they are new to the board and gate-passing.

## What was searched

Mixed-slope subset of the deterministic SNF grid: Q rows alternating
(1, 0, 1, 0) (both sectors matched or x/z-crossed), shift patterns from the
five classic block-mixing patterns, base at P0 = 3 (root r = 2 of order 2),
target sizes P ∈ {7, 11, 13} with roots_r = [P − 1] — 480 tuples attempted,
of which 384 derived; 96 had fingerprints new to the dedup index (board +
open PRs + every staged find of this campaign). The first 8 new-fingerprint,
connected derivations were packaged and gated: 8/8 passed and were
board-advancing. This note's code is the canonical `all0-alternating`
member at P = 7.

## Evidence trail

- Derivation: the SNF bundle reproduces the base code at P0 = 3 (the
  consumer's reproduction check; the base carries slopes 2 = −1 and 1 on
  alternating columns) and evaluates cleanly at P = 7 (6² = 1 mod 7).
- Newness: `dedup_oracle` fingerprints (canonical form + WL) do not match
  any board entry, open PR, or staged candidate of this campaign — unlike
  the uniform-slope bundles, which were all exact duplicates.
- Distance: the verifier's witness search found weight-2 logicals on both
  sides at 8,000 RIS trials per side; the submitted claim is d ≤ 2
  (`upper_bound`). No lower endpoint is claimed.
- Gate: `passed: true`, `board_advancing: true`, `advances_by: [d, k, n]`,
  `dominated_by: []`, cell weight-4/unrestricted.
- Parameters: n = 28, k = 14, w = 4.

## Dead ends

- Uniform all-(−1)-slope bundles: 12/12 exact duplicates (position
  reflection of the unit-slope grid) — the negative result that motivated
  the mixed-slope lead.
- The x/z-crossed slope assignments (Q_x ≠ Q_z) mostly fail the paired
  relative-affine orthogonality premise (the relative maps stop pairing);
  the matched-slope subset carries the yield.
- Identical X/Z shift patterns: disconnected (p 4-qubit blocks).

## Reproduction

`repro/28-14-2-b.py` in this PR rebuilds H_X and H_Z from the evaluated
target pattern (P = 7, L = 4, column slopes (6, 1, 6, 1) — i.e. ±1 — X shifts
(0,0,0,0), Z shifts (0,1,0,1)) and writes `28-14-2-b.npz`; run it, then

```
./qldpc submit 28-14-2-b.npz --authors @mathysrennela
```

Through the consumer directly (the SNF-bundle route this release admits):

```
bundle = {"P0": 3, "orders_e": [2], "roots_r0": [2],
          "Q_x": [[1], [0], [1], [0]], "Q_z": [[1], [0], [1], [0]],
          "G_x": [[0], [0], [0], [0]], "G_z": [[0], [1], [0], [1]],
          "theta_x": [1], "theta_z": [1],
          "blocks_x0": [[(2, 0), (1, 0), (2, 0), (1, 0)]],
          "blocks_z0": [[(2, 0), (1, 0), (2, 0), (1, 0)]]}
bundle["roots_r"] = [6]
construct({"constructor": "PP-SCALE", "state": base, "P": 7, "bundle": bundle})
```
