# [[360,20,26]] — weight-8 bivariate bicycle code on Z_30 x Z_6

## Direction & hypothesis

Cell `weight-8 x unrestricted` (maximum check weight 8), CSS board, n between 221 and 400. Before this code, the frontier (board plus this campaign's open PRs) at check weight <= 8 and n from 300 to 360 ran through 300-12-25, 300-32-15, 300-36-13, 300-104-3, 300-152-2, 306-26-19, 306-106-3, 308-10-26, 310-12-26, 330-10-27, 330-112-3 (w6), 336-24-24. The hypothesis was that random 4 + 4-term bivariate bicycle (BB) codes on tori with 2lm in 300..400, prefiltered for k >= 20, still reach points there that the board does not hold.

[[360,20,26]] does: no board entry has n <= 360, k >= 20, d >= 26 and check weight <= 8. It is not a d-only gain (no board entry has the same n, k and weight with a lower d).

## What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A of 4 and B of 4 monomials, both containing 1 (no loss of generality), on every torus Z_l x Z_m with l >= m >= 3 and 300 <= 2lm <= 400; the torus is drawn uniformly from that list and the other monomials uniformly from the torus.

This sweep (seed 601) drew 400,020 codes in a parallel generate-and-rank prefilter; 664 had k >= 20 and a connected Tanner graph (research/kit/prescreen.block_structure). Those went through research/kit/search.screen with the gf2_fast backend at 400 trials; 6 advanced the board frontier at screen depth and 6 were taken to 20,000 / 200,000 / 2,000,000 fast trials (research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a candidate as soon as its running bound stopped advancing; 1 survived that and was staged.

## Dead ends

- In this sweep 5 of 6 screen-depth survivors collapsed below the frontier by 2,000,000 trials: 400-trial readings run several units high at this n.
- Earlier in this campaign on the same band: cyclic generalized-bicycle codes with a designed divisor at weights (3,3) and (4,4), random-support 2BGA on non-abelian groups at check weight 8, non-abelian lifted products, and weight-6 BB/2BGA at k >= 28 gave nothing that survived 20,000 trials on the frontier.
- Random 2 + 6 splits at check weight 8 never reached k >= 18 with an advancing distance.

## Reproduction

Torus Z_30 x Z_6 (x of order 30, y of order 6), terms (i, j) = x^i y^j:

A = 1 + x^4 y^3 + x^11 y^2 + x^19 y,
B = 1 + x^7 y^3 + x^8 y + x^12 y^2.

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from bb import build_bb
from css import compute_k
HX, HZ = build_bb(30, 6, [(0, 0), (4, 3), (11, 2), (19, 1)],
                  [(0, 0), (7, 3), (8, 1), (12, 2)])   # n = 360
assert compute_k(HX, HZ) == 20
```

Ladder: `surrogate.distance_rand_witness(HX, HZ, trials=10_000_000, seed=<s>, backend="fast", pair_depth=8)` with s in {61508, 69427, 77346} returns logicals of weight 26, 26, 26.
