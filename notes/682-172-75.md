## What was searched

The construction uses two circulants over Z₃₄₁, with supports

```
a = [0,1,9,15,48,82,87,102,117,120,137,189,198,244,252,269,296,315]
b = [0,4,19,35,66,97,102,128,132,165,187,195,267,330]
```

For each row i, X has supports `(i+a) mod 341` and
`341+(i+b) mod 341`; Z has `(i-b) mod 341` and
`341+(i-a) mod 341`. The reproduction script builds all 682 check
rows, checks equality to the submitted matrices and GF(2) ranks
255/255, and validates the saved operators. This is an ordinary CSS
generalized-bicycle code; the word “recombined” records how these
sparse generators were found in the divisor-ideal search, not a
separate distance theorem.
