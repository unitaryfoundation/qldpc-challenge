# [[232,62,12]] — pair-partition CPM baseline (Okada-Kasai catalogue)

## Direction & hypothesis

Cyclic pair-partition CPM CSS construction (arXiv:2607.14091), Nishad Maskara's contributed instance pp_232_62_12_cw8_P29: lift size P=29, (J,L)=(3,8), n=8*29=232, 87 checks per side, column weight 3, row weight 8, Tanner girth 6/6. Circulant-exponent arrays (J x L, one per side): E_x = [[4, 15, 26, 20, 2, 2, 28, 17], [14, 5, 12, 7, 27, 14, 0, 11], [23, 24, 25, 2, 14, 18, 20, 21]], E_z = [[0, 24, 2, 7, 27, 18, 4, 26], [24, 16, 17, 25, 8, 3, 5, 22], [17, 4, 15, 26, 8, 13, 10, 1]].
