# [[84,6,6]] — Asymmetric weight-5 two-block group algebra code on SmallGroup(42,6)

## Direction & hypothesis

Targeted the `weight-6` / `unrestricted` cell using asymmetric `(3, 2)` two-block group algebra (2BGA) constructions on non-abelian groups of order 42 (`n = 84`, max check weight `w = 5`). Because `w = 5` sits strictly below `w = 6` on the check-weight axis, a `[[84,6,6]]` `w = 5` code advances the Pareto frontier without needing to beat `w = 6` codes on `(n, k, d)` alone.

## What was searched

Random sweep of 21,000 asymmetric and symmetric bivariate-bicycle and small-group 2BGA codes (seed `20261125`), filtering for CSS commutation, `k >= 4`, connected Tanner graph and stabilizer group, and no exact or Weisfeiler-Leman match against the current board. Candidates were screened at 1,500 fast RIS trials (`verify/gf2_fast`), and non-dominated survivors were re-screened at 200,000 fast RIS trials.

## Evidence trail

- 1,500 RIS trials (`gf2_fast`): `d <= 6`
- 200,000 RIS trials (`gf2_fast`): `d <= 6`
- Validation gate (`verify/validate_candidate.py`): `d_X <= 6`, `d_Z <= 6` (witnessed upper bound), `no lighter logical in 5860 RIS trials`, `passed: true`, `board_advancing: true`, `exact_duplicate_of: null`, `wl_equivalent_of: null`.
- Submission accelerator pass (`./qldpc submit`): `2,000,000` RIS trials (`d_X <= 6`, `d_Z <= 6`).

Final claim: witness-backed `upper_bound` `d <= 6` (`d_X <= 6, d_Z <= 6`), `w = 5`. Literature novelty unverified.

## Dead ends

Most sampled `(3, 2)` and `(3, 3)` 2BGA instances on smaller groups (`order <= 36`) either matched existing board WL signatures or were dominated by existing `weight-6` frontier entries.
