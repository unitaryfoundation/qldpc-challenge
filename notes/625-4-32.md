# [[625,4,32]] — weight-8 mirror-folded single-layer planar non-CSS stabilizer code

## Direction & hypothesis

Open-boundary planar bivariate-bicycle CSS codes on the 45-degree rotated single-layer square lattice `A(i, j) = (i + j, j - i)`, `B(i, j) = (i + j, j - i + 1)` (following Liang, Eberhardt, and Chen, arXiv:2504.08887, and the single-layer sublattice layout of `codes/454-8-17.json`) admit a natural **Euclidean mirror fold (symplectic halving)** onto the `y <= 0` half-plane whenever the parent CSS code is symmetric under the horizontal reflection `sigma: (x, y) -> (x, 1 - y)` (`A(i, j) <-> B(j, i)`). Because reflection across `y = 0.5` is a Euclidean contraction between opposite half-planes (`||p - sigma(q)|| <= ||p - q||` for `p_y <= 0` and `q_y >= 1`), folding any `sigma`-symmetric planar CSS code onto the `y <= 0` half-chip automatically preserves:

1. exact symplectic commutation (`A_fold B_fold^T + B_fold A_fold^T = 0 mod 2`),
2. check weight `<= w_parent`,
3. single-layer 2D integer-grid locality (`layers = 1`, `min_spacing = 1.0`, `interaction_radius <= r_parent <= 4.0`),

while yielding a genuinely **non-CSS** planar stabilizer code of blocklength `n = L^2`. We swept all `sigma`-symmetric weight-6 and weight-8 tile pairs `(S_f, S_g)` fitting inside `interaction_radius <= 4.0` on the rotated square lattice to find families with linear distance scaling `d(L) > L` and `kd^2/n > 5.333`.

## What was searched

- Exhaustive sweep over bulk-commuting `sigma`-symmetric tile pairs `(S_f, S_g)` inside the `4 x 4` offset box with Euclidean diameter `<= 4.0` on the rotated square lattice:
  - **Weight `<= 6`:** 361 bulk-commuting pairs tested; the strongest family achieved `k = 4`, `d(L) ~ 0.7 L`, `kd^2/n <= 2.47`.
  - **Weight `<= 8`:** sweeping weight-(4, 4) pairs uncovered the tile `S_f = [(0, 1), (0, 3), (1, 2), (2, 3)]`, `S_g = [(0, 3), (1, 1), (2, 1), (2, 2)]`, which produces a connected, genuinely non-CSS single-layer planar family `[[L^2, 4, ceil(3L/2) - 6]]` with `w = 8`, `layers = 1`, `interaction_radius = 4.0`, and asymptotic `kd^2/n -> 9.0`.
- Scaling verified across `L = 8..15` (`n = 64..225`) and evaluated up to `L = 25` (`n = 625`):

## Evidence trail

Because `n = 625` is beyond exact non-CSS MILP range, the distance claim is an explicit **upper bound (`d <= 32`)**, supported by both targeted vertical-strip search (which matches the exact `ceil(3L/2) - 6` law from `L = 8..15`) and unrefuted global RIS:

| Verification method | Budget | Lightest nontrivial logical |
|---|---:|---|
| Vertical-strip RIS search (targeted across `x`-strips) | multi-strip vectorized RIS | **32** (stored witness, 22 X-positions, 21 Z-positions, 11 Y-overlaps, total Pauli weight 32) |
| Global RIS screen | 20,000 trials | 44 |
| `verify/validate_candidate.py` (RIS refutation gate) | 8,000 RIS trials (seed 1639089723) | not refuted (`<= 32`) |

Note on distance tightness: the stored weight-32 witness is substantially lighter than global RIS (44), and matches `ceil(3 * 25 / 2) - 6 = 32` exactly. However, no exact lower bound is proved at `L = 25`; `d` is filed strictly with `confidence: "upper_bound"`.

Non-CSS: `verify/qldpc_verify.py` confirms no single-qubit Clifford frame transforms the stabilizer generators into CSS (`stabilizer_code_is_not_css` and `stabilizer_code_is_not_locally_css` both pass).

Board-relative placement: `verify/validate_candidate.py` returns `passed: true`, `board_advancing: true`, `dominated_by: []`, `d_only_gain: false`, `exact_duplicate_of: null`, and `wl_equivalent_of: null` in cell `weight-8 x local-2d-single` (`stabilizer`). Literature novelty is not claimed (`provenance.novelty: "unknown"`).

## Dead ends

- All 361 bulk-commuting `sigma`-symmetric weight-6 tiles in the `4 x 4` box topped out at `kd^2/n <= 2.47` (`k = 4`, `d ~ 0.7 L`).
- HiGHS MILP on the full `n = 625` non-CSS stabilizer parity-check matrix timed out without a lower bound; lower-bound certification at `L = 25` remains open.
- Larger `L` members of the same family (e.g., `L > 25`) push `kd^2/n` closer to `9.0`, but make both RIS refutation and witness tightening more expensive; `L = 25` was chosen as a clean point with an explicit tight weight-32 witness matching the `ceil(3L/2) - 6` scaling law.

## Reproduction

1. On an `L x L` (`L = 25`) grid, define `2 L^2 = 1250` parent qubits `A(i, j)` and `B(i, j)` (`0 <= i, j < L`) at 45-degree rotated integer coordinates `A(i, j) = (i + j, j - i)` and `B(i, j) = (i + j, j - i + 1)`.
2. Define the horizontal reflection `sigma: A(i, j) <-> B(j, i)` across `y = 0.5`. The `n = L^2 = 625` half-chip qubits with `y <= 0` are `A(i, j)` for `j <= i` and `B(i, j)` for `j < i`.
3. Form directional X-check rows `HX` by translating `S_f = [(0, 1), (0, 3), (1, 2), (2, 3)]` on `A` and `S_g = [(0, 3), (1, 1), (2, 1), (2, 2)]` on `B` over all `(ci, cj)` whose out-of-bounds sites occur only in the `i`-direction (`0 <= j < L`, `i not in [0, L)`). Set `HZ = sigma(HX)`.
4. Compute the symmetric conflict matrix `M = (HX @ HZ^T) mod 2`, drop rows with `M[r, r] = 1`, and greedily drop the highest-conflict remaining row until `M = 0`.
5. Fold the surviving rows onto the `y <= 0` half-chip by setting `A_fold[r, q] = HX[r, left[q]]` and `B_fold[r, q] = HX[r, sigma(left[q])]`. Remove any weight-1 stabilizers by Gaussian elimination (and drop decoupled qubits, if any); at `L = 25` all 625 qubits survive with 621 independent checks of max weight 8 and `interaction_radius = 4.0`.
