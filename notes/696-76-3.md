# [[696,76,3]] — irregular holey rotated surface code, g=0.9828

## Direction & hypothesis

Irregular holey rotated surface code on a 29x24 integer vertex grid, n = 696. Cell (i,j) carries an X check when i+j is even and a Z check otherwise; 75 cells are punched out as holes, giving k = 1 + holes = 76. Boundary parity combination (0, 1, 1, 1) chosen by scanning all 16 so that H_X H_Z^T = 0. Holes placed by greedy max-independent-set with hill climbing under the d=3 spacing rule (same-parity Chebyshev >= 3, any-parity Manhattan >= 3, margin 3), searched jointly over grid shape. r = sqrt(2) exactly, single layer.

Same family as [[700,75,3]] and [[625,50,3]]. The gain is grid shape: those fix a single grid, but the cap is Lx*Ly <= 700 and g = 9k/n rewards a smaller n at equal hole count. A 29x24 grid holds 75 holes in 696 qubits where 28x25 held 74 in 700. Constructor calibrated against the plain rotated surface code, reproducing [[25,1,5]], [[49,1,7]] and [[81,1,9]] before any holey run was believed.
