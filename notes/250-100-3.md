# [[250,100,3]] K6 incidence hypergraph product

## Direction & hypothesis

Target the `unrestricted / weight-8` frontier at `d = 3, k = 100` using
`research/kit/products.py` (`products.hypergraph_product(H1, H2)`). For the
5-regular complete graph `K_6` (6 vertices, 15 edges, girth 3), dropping 1
redundant vertex row from the `6 x 15` vertex-edge incidence matrix yields a
full-row-rank `5 x 15` matrix `H` (`k_1 = 10, d_1 = 3`, row weight 5, column
weight `<= 2`), whose symmetric hypergraph product has `n = 15^2 + 5^2 = 250`,
`k = 10^2 = 100`, `d = 3`, and max check weight `w = 5 + 2 = 7`.

## What was searched

Screened symmetric and asymmetric hypergraph products of regular-graph
incidence matrices with `Delta in {5, 6}` (`w in {7, 8}`) across `K_6`, `K_7`,
`K_{4,5}`, `K_{5,5}`, `K_{5,6}`, and `K_{6,6}`. For `K_6 x K_6` with 1
redundant vertex row dropped per factor, `products.hypergraph_product`
produces `[[250,100,3]]` (`kd^2/n = 3.600`, max check weight 7).

## Evidence trail

Confirmation ladder for the submitted code, each rung a fresh seed unless
marked otherwise, reading the lightest logical found:

3 fresh-seed rung(s) agree at the best bound, the deepest of them at 200,000

Distance `d = 3` follows from Tillich-Zemor Theorem 1 (cycle-space girth 3 of
`K_6`) and was independently checked with `verify/sat_certify.py`
(CryptoMiniSat 5.14 SAT, UNSAT below weight 3 on both sides in 0.10 s);
claimed as a witness-backed upper bound.

## Reproduction

Reproducible via `./qldpc reproduce 250-100-3 --construction`
(`repro/250-100-3.json`), or directly:

```python
import sys, itertools, numpy as np; sys.path.insert(0, 'research/kit')
from products import hypergraph_product
edges = list(itertools.combinations(range(6), 2))
H = np.zeros((6, len(edges)), dtype=np.int8)
for j, (u, v) in enumerate(edges): H[u, j] = H[v, j] = 1
hx, hz = hypergraph_product(H[:-1], H[:-1])
```
