# [[996,166,36]] irregular pair-partition CPM code, hexagon-floor exponents

## Direction & hypothesis

Cell: CSS, unrestricted, weight 8, extended tier (700 < n <= 1000 needs w <= 8
and d <= 40). The board holds two lifts of @MicheldeMessieres's irregular 5x12
"pair-complement-2" template at P = 83: codes/996-166-32.json (PR #4045,
kd^2/n 170.7) and codes/996-166-34.json (PR #4055, 192.7). Each pairing of the
template's X-row/Z-row overlaps forces some zero-sum block 6-cycles (block
hexagons) in every lift; PR #4045's pairing forces 12 per side and its filed
draw has 22, with weight-32 logicals both inside the eight degree-3 block
columns and spread over 10-12 block columns. Hypothesis: the excess hexagons,
not the template or the pairing, set that entry's 32, so a draw of the same
pairing with only the forced 12 per side reads higher. This code: PR #4045's
template and pairing unchanged, a new exponent draw at that floor; 166 * 36^2
/ 996 = 216.0 as an upper bound (d <= 36).

## What was searched

The pairing equations leave a 27-dimensional space of exponent points over
Z_83, 6-dimensional modulo the block row and column shifts that give
equivalent codes. Random points were kept when the block Tanner graph has no
4-cycles and no hexagons beyond the forced 12 per side (about 2% of
4-cycle-free points); the first of 24 such draws (seed 7) is this code.
Screen: full-length Stern for 4, 30 and 200 s per side (lightest 66, 52, 38),
then Stern restricted to each of the 495 subcodes on eight block columns
(6,000 iterations each), which found weight-36 logicals on both sides inside
block columns 0-7, the degree-3 columns: the filed witnesses. Ceiling of this
pairing: in 8,966 draws with 12-14 hexagons per side, a short Stern run on
block columns 0-7 found a word of weight <= 36 in every one (5,426 read
exactly 36), which we attribute to 6 block 8-cycles the pairing forces there,
so we expect no lift of it to exceed 36.

Rungs are full-length Stern ISD iterations (p = 2, l = 16, an uncommitted C++
implementation with a stabilizer filter; not RIS trials), and a rung's budget
is the smaller of its two sides' counts. From round 1 each rung is one round
of two independent runs per side on fresh seeds, read as the lightest logical
of its four runs; every find was re-checked against the opposite checks and
its own row space. The restricted search that found the filed witnesses (What
was searched) is not in the table. Cumulative full-length depth: 55,118,061
iterations (X) and 55,067,099 (Z), with nothing lighter than 36 (4 weight-36 X
finds and 8 Z, some inside block columns 0-7, the rest spread over 11-12 block
columns). Every logical of this family has even weight (block rows 0-2 of each
side sum to the all-ones vector), so the next value below 36 is 34. The code
is X<->Z symmetric: swapping the two columns of each block-column pair and
negating the row index mod 83 (plus a per-pair shift) carries the X row space
onto the Z row space, verified with research/provenance/iso_common.py, so d_X
= d_Z and the X and Z runs are two searches of one problem. Not a relabelling
of either board lift: research/audits/permutation_audit.py, with its
enumeration budget raised to 2e9 row sums, returns inequivalent for both pairs
(provenance.notes has the argument). The claim is a witness-backed upper
bound, d <= 36; no lower bound is claimed.

## Dead ends

- Our own pairing "A" (from an exact DFS/large-neighbourhood search over
  4-cycle-free pairings; no forced block 8-cycles in columns 0-7) lifts the
  degree-3 ceiling to 40, but its deepest draw has spread weight-34 logicals
  from about 10M iterations on (d <= 34 at about 28M X / 24.5M Z), so the full
  code did not gain.
- Block-restricted searches cannot bound d at this length: a pairing-A draw
  read 40 on every 8- and 9-block subcode and on the degree-3 subcode, and
  full-length Stern then found a weight-36 logical spread over all 12 block
  columns; our local stagings at 40 and 38 were refuted that way.
- Short full-length runs are too shallow: 120 s per side read 44 (X) and 40
  (Z) on a code that later read 34.
- PR #4035's 4x10 template: floor draws at P = 97 read 24-31; its degree-3
  subcode has rate 1/2 and random exponents there already read 26-34, so we
  expect no pairing of it to reach 37.
