# [[9,1,3]] — non-CSS stabilizer code on a 3x3 grid (g = 1)

## Direction & hypothesis

The stabilizer board had no entry with geometric efficiency g >= 1; the best
stabilizer code carrying an honest 2D layout sat at about g ~ 0.36
(`[[8,2,3]]`). The `local-2d-single x weight-4` stabilizer cell has only a
handful of frontier entries, so a genuinely non-CSS stabilizer family with a
compact 2D layout would be board-advancing almost by default. The hypothesis
was that a 3x3 grid (9 qubits) could host a 9-qubit non-CSS stabilizer code
whose generators are 2x2-block Paulis, giving radius sqrt(2) and g = 1.

## What was searched

A randomized backtracking search over Pauli generators supported on subsets of a
3x3 integer grid with diameter at most sqrt(2) (i.e. 2x2 blocks), weight at
most 4. Candidate generator sets were built greedily: starting from a random
local generator, add a generator that commutes (symplectic inner product) with
every chosen one and is independent over GF(2). Sets were filtered to have no
nontrivial logical of weight 1 or 2 (exhaustive enumeration of all Paulis of
those weights) and to be genuinely non-CSS under single-qubit Clifford
(brute force over the 2^9 Clifford twists). About 200,000 trials were run
across several seeds; the surviving 9-generator (k = 1) set is the one
submitted. Larger k (k >= 2) was searched but no non-CSS set with the
same locality filter survived, so this entry is a k = 1 existence proof.

## Evidence trail

- n = 9, k = 1, claimed d = 3 (upper bound).
- Exhaustive enumeration of every Pauli of weight 1 and 2 finds no nontrivial
  logical and no stabilizer element, so d >= 3; a weight-3 logical witness is
  stored (`X = [0,1]`, `Z = [0,2]`, Pauli weight 3).
- Refutation gate: no lighter logical in 2860 RIS trials (seed recorded in the
  verdict).
- Locality: single layer, interaction radius sqrt(2) ~ 1.414 (2x2 blocks),
  min site spacing 1.0; g = 4*1*3^2 / (9*1*(sqrt2)^4) = 1.0.
- Non-CSS: verified by `stabilizer_code_is_not_locally_css` (no single-qubit
  Clifford makes every generator pure X or pure Z).

## Dead ends

- k >= 2 variants on the same 3x3 grid did not survive the no-weight-1/2-logical
  plus non-CSS filter in ~200k trials; the search found only the k = 1 code.
- Larger grids (4x3, 3x4) with radius up to 2.0 were searched for k >= 3 but
  produced no surviving non-CSS set; the radius needed for g >= 1 with those
  parameters was not reached.
- The code is dominated on the (n,k,d,w) frontier by `[[5,1,3]]` and
  `[[8,2,3]]` (lower n / higher k), so it is filed as a non-frontier record
  rather than a frontier advance; its value is the first stabilizer entry with
  g >= 1 and an honest 2D layout.

## Tools

Model-assisted search and layout; exact model/version unspecified. Repository
tooling: `research/kit/coordination.py gate`, `verify/qldpc_verify.py`,
GF(2) linear algebra from `verify/gf2.py`. Compute: a few hours of CPU on a
single machine, randomized backtracking with exhaustive distance filtering.

## Reproduction

Generators (symplectic pairs (X-mask, Z-mask) on 9 qubits):

```
(18, 27), (432, 16), (6, 2), (2, 52), (200, 216),
(128, 64), (9, 9), (432, 304)
```

Coordinates (row-major 3x3 grid): qubit i at (i mod 3, i // 3). Rebuild the
submission document from `codes/9-1-3-s.json`; the verifier recomputes n, k,
weight class, locality class, and interaction radius from it.
