# [[11,3,3]] — priced-calculus C-DELETE-CHECK+ E-GRAFT from [[12,2,4]], 3D layout

## Direction & hypothesis

Target cell: the `unrestricted` locality classes (weight-6/8/any) on the CSS board,
aiming to beat the `[[12,2,4]]` entry on `n` at fixed `k=2`→`3` and `d=3..4`.
The opening: the priced construction calculus (`research/kit/` search over
C-DELETE-CHECK / E-GRAFT edit scripts) had already produced several `[[10,*]]`
variants on this parent, so a one-qubit-smaller `[[11,3,3]]` with an extra logical
was expected to be reachable by a slightly larger edit budget.

The layout was added specifically to price the code in the **D = 3 geometric
efficiency** class (issue #4163): a compact 3D grid of spacing 1 gives small
interaction radius at unit site spacing, which is the regime that score reads.

## What was searched

- Parent: `codes/12-2-4.json`, itself a SAT-searched CSS code (`[[12,2,4]]`,
  weight-6, arXiv:2608.23460 Sec. VI adapted to CSS).
- Edit scripts explored by the priced calculus: `C-DELETE-CHECK+` (delete one
  check) composed with `E-GRAFT` (graft an edge/qubit to reconnect the Tanner
  graph). Sweep over which check to delete and which graft to apply.
- Distance: reuse-witnesses path through `./qldpc submit`, i.e. the draft's own
  `distance.X/Z` witnesses `[0,1,7]` were validated against the rebuilt matrices
  and re-scored; an accelerator pass of **2,000,000 RIS trials** confirmed
  `d <= 3` on both sides.
- Board dedup by exact fingerprint and WL signature (local-Hadamard images
  included): no equivalent entry found.

## Evidence trail

Confirmation ladder (witness-backed upper bounds, both sides):

- Draft witness `d_X = 3`, `d_Z = 3` on support `[0,1,7]` — validated against
  rebuilt `H_X`, `H_Z`.
- Accelerator pass, 2,000,000 trials: `d <= 3` (no lighter logical found).
- `coordination.py gate` refutation: 2,940 RIS trials, fresh seed 710312263,
  no lighter logical — `passed: true`, `board_advancing: true`,
  `advances_by: ["n"]` on the weight-6 × unrestricted cell.

Final claim: **witness-backed upper bound `d <= 3`**, not an exact distance.
Lower interval bounds live in the separate local ledger (see
`provenance.notes` in the submitted JSON).

The frontier advance: dominates `[[12,2,4]]` on `n` (11 < 12) at equal-or-better
`k` (3 > 2) and `d` (3 ≤ 4, but `k d²/n` improves), in the `unrestricted / weight-6`,
`weight-8` and `any-weight` cells. Score `kd²/n = 2.455`.

## Dead ends

- The **circuit tier** for this code failed to verify: the generated memory
  circuits had `d_circ = 1` for the X memory (a weight-1 undetected logical,
  `X_dem_structure: detectability`). This is a generator bug (`--circuit` path),
  not a property of the code; the code tier is unaffected. Reported in the submit
  log.
- Many other staged candidates from the same campaign were **refuted** (over-claimed
  distance): e.g. `[[8,2,3]]` collapsed to a weight-2 logical, `[[17,5,2]]` and
  several `[[11,*]]`/`[[13,*]]` variants likewise. The batch gate sweep over
  ~28,000 staged candidates found ~12,000 passing, but most passing ones were
  small-`d` or exact-duplicate; this was the first `d >= 3` pass that also
  advanced the board.
- The 3-qubit repetition code as a layer-code input **degenerates** (no X checks),
  so it was dropped early in the layer-code line of work (issue #4163).

## Reproduction

Parent: `codes/12-2-4.json` (`[[12,2,4]]`), edited by the priced construction
calculus (research/kit) — `C-DELETE-CHECK+` (remove one X check) composed with
`E-GRAFT` (reconnect the Tanner graph). The resulting `[[11,3,3]]` document with
its 3D `locality.coordinates` (compact grid, spacing 1, `layers=1`) is committed
in this PR as `codes/11-3-3-f.json`.

Distance was produced by reusing the draft's witnesses (`distance.X/Z`, support
`[0,1,7]`) validated against the rebuilt matrices, then a 2,000,000-trial
accelerator pass (`./qldpc submit --reuse-witnesses`), followed by the gate
refutation (`research/kit/coordination.py gate`) at 2,940 RIS trials on a fresh
seed. The verification command run locally was
`python verify/qldpc_verify.py codes/11-3-3-f.json`.
