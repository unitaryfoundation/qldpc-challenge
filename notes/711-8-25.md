# [[711,8,25]] — eleven local reductions of a planar tile code

## Direction & hypothesis

The published `codes/722-8-25.json` is a weight-8, single-layer 2D tile
code with eight logical qubits and explicit weight-25 logical operators.
Local stabilizer pivots can remove physical qubits while retaining its
checks, layout class, and logical witnesses. We sought a smaller `n` in
that board cell. The reported distance is a witness-backed upper bound.

## What was searched

Ten compatible pivots reduced the published 722-qubit code to a staged
712-qubit ancestor. An eleventh single-pivot scan found 97 structural
711-qubit variants preserving check weight at most 8, radius at most 4,
and inherited weight-25 logicals. Fifty-four retained `k=8`, Tanner and
stabilizer-block connectivity, and valid logicals. Projection of 475
light ancestor logicals, including stabilizer-row translates and RIS
witnesses lifted from the children, refuted 15 variants with lighter
logicals. A 10,000-trial, pair-depth-8 screen covered all 50 initial
survivors. We tested X711/pivots351 and 352, Z675/pivot288, and
Z711/pivot287 at 100,000 trials and pair depth 512. All returned
weight 25. A later 300,000-trial run found a valid weight-24 Z logical
for X711/pivot352; the unchanged verifier confirmed it. We selected
Z711/pivot287 for the final code.

## Evidence trail

The unchanged trusted candidate gate passed the Z711/pivot287 JSON with
seed 2061908962. It checked CSS commutation, `n=711`, `k=8`, maximum
check weight 8, a connected one-layer radius-4 layout, the two
weight-25 logicals, deduplication, and an 8,000-trial RIS refutation
search. It marked the weight-8, local-2d-single cell as advancing by
lower `n`. An independent eleven-pivot reconstruction from
`codes/722-8-25.json` matched the candidate checks and coordinates.
The Z witness matches the published parent's projection; the X
witness descends from a validated RIS result on the 719-qubit ancestor.

On the exact 711-qubit matrices, accelerated RIS returned no logical
below 25 in 100,000 pair-depth-512 trials (seed 1223271387), 300,000
pair-depth-512 trials (seed 1223471387), 200,000 pair-depth-4096 trials
(seed 4807371387), 1,000,000 pair-depth-512 trials (seed 1224171387),
and 1,000,000 pair-depth-4096 trials (seed 4808171387). Every returned
logical was checked against those matrices. The initial 10,000-trial
pair-depth-8 run returned a weight-27 logical, while the candidate
already contained valid weight-25 witnesses.

**`d≤25` is a witness-backed upper bound.** The bounded searches do not
prove a minimum distance of 25. The witnessed score is
`8 × 25² / 711 = 7.032`, versus 6.925 for the published parent.
Against `codes/717-8-25.json`, this code removes 6 physical qubits
at the same `k`, witnessed bound, weight, and layout class.

## Dead ends

The X711/pivot352 variant passed a shorter trusted gate and a
200,000-trial pair-depth-4096 screen, but a later 300,000-trial
pair-depth-512 run found a trusted-verifier-confirmed weight-24 Z
logical. Saved logical projections ruled out 15 variants in total.
The other shallow-screen survivors have not been deeply confirmed.

## Tools

routines, and accelerated `gf2_fast` RIS screened and checked candidates.

## Reproduction

Start from `codes/722-8-25.json`. At each step, XOR the named pivot
row into every other same-side check containing the target qubit;
delete the pivot row and qubit, shorten opposite-side checks, delete
that coordinate, and renumber surviving qubits. In order:

1. Z row 289, support `{0,362,363}`, target qubit 0.
2. Z row 289, support `{1,18,361,380,381}`, target qubit 18.
3. Z row 350, support `{356,357,716}`, target qubit 357.
4. Z row 353, support `{356,357,715,716}`, target qubit 357.
5. X row 291, support `{16,17,35,393,412,413}`, target qubit 17.
6. X row 272, support `{301,302,321,341,662,679,698,699}`, target qubit 341.
7. X row 348, support `{282,301,321,641,678}`, target qubit 321.
8. X row 273, support `{303,304,322,341,662,679,698,699}`, target qubit 341.
9. Z row 290, support `{339,695}`, target qubit 695.
10. Z row 84, support `{90,91,110,127,445,465,484,485}`, target qubit 485.
11. Z row 287, support `{318,319,337,352,672,692,710,711}`, target qubit 711.

Project the published Z witness through all eleven pivots. The X
witness in the candidate JSON comes from accelerated RIS on the
719-qubit intermediate and is projected through the final eight
pivots. The JSON contains the final checks, coordinates, and both
witness supports.
