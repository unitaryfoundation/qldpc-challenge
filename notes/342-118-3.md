# [[342,118,3]] — weight-8 bivariate bicycle code on Z_57 x Z_3

## Direction & hypothesis

Cell `weight-8 x unrestricted` (maximum check weight 8), CSS board, n between 221 and 400. This is a high-rate, distance-3 point. Before this code, the high-rate end of the frontier at check weight <= 8 and d >= 3 between n = 282 and n = 342 ran through 288-100-3, 300-104-3, 306-106-3 and 330-112-3 (weight 6). The sweep aimed at k >= 22 with large d (random 4 + 4-term bivariate bicycle (BB) codes on tori with 2lm in 300..400, prefiltered for k >= 22); this draw landed far above that k threshold, and at d = 3 it still advances the frontier's high-rate end.

[[342,118,3]] does: no board entry has n <= 342, k >= 118, d >= 3 and check weight <= 8. It is not a d-only gain (no board entry has the same n, k and weight with a lower d).

## What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A of 4 and B of 4 monomials, both containing 1 (no loss of generality), on every torus Z_l x Z_m with l >= m >= 3 and 300 <= 2lm <= 400; the torus is drawn uniformly from that list and the other monomials uniformly from the torus.

This sweep (seed 611) drew 600,000 codes in a parallel generate-and-rank prefilter; 566 had k >= 22 and a connected Tanner graph (research/kit/prescreen.block_structure). Those went through research/kit/search.screen with the gf2_fast backend at 400 trials; 6 advanced the board frontier at screen depth and 6 were taken to 20,000 / 200,000 / 2,000,000 fast trials (research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a candidate as soon as its running bound stopped advancing; 1 survived that and was staged.
