# [[108,58,4]] — Cornucopia q=3 with searched column shifts

## Direction & hypothesis

Target cell: weight-9plus × unrestricted on the CSS board (weight-12 checks,
no layout), family `other`. The Cornucopia construction (Lu, Li, Ma et al.,
"A modular quantum computer based on Cornucopia codes", arXiv:2610.19073v2)
fixes only the row maps; its twelve column shifts are free parameters. The
hypothesis was that at a small, admissible `q` (n = 36q ≤ 700) an unexplored
shift tuple would land on the frontier where no Cornucopia instance of these
parameters existed yet.

## What was searched

200 random column-shift tuples at q=3 (sA, sB ∈ Z_3^6 each), every code
screened with the `gf2_fast` randomized logical search at 500 trials, seeds
from the sweep's own RNG stream. The best tuple, sA=[1,1,0,2,0,1],
sB=[2,1,1,2,0,2], was then confirmed at 10,000 accelerator trials.

## Evidence trail

Ladder for the submitted code: 500-trial screen → d ≤ 4; 10,000-trial
accelerator pass → d ≤ 4 on both sides (witnesses embedded in the entry);
the gate's own refutation (fresh seed, 6,820 RIS trials) found nothing
lighter. The claim is a witness-backed upper bound, not an exact distance.

## Dead ends

Shift tuples screened at 500 trials frequently collapsed to d ≤ 2 (roughly
one in five). Nothing collapsed below the submitted bound after confirmation.

## Tools

Model: Beam 1.0. Repo tooling: `research/kit/submit.make_submission`,
`research/kit/surrogate` (NumPy + `gf2_fast` backend), gate
`research/kit/coordination.py gate`. Build matrices per arXiv:2610.19073v2
Methods, Eq. (1).

## Reproduction

q=3, row maps ρ_A(0)=r+1, ρ_A(1)=2r+2, ρ_B(2)=r+1, ρ_B(3)=2r+2 (identity
otherwise), column shifts sA=[1,1,0,2,0,1], sB=[2,1,1,2,0,2] on Z_3.
Index data qubit (b,r,c) as (3b+r)q+c; HX block (i,j) = [A_(j-i) | B_(j-i)],
HZ block (i,j) = [B_(i-j)^-1 | A_(i-j)^-1] for i∈{0,1,2}, j∈{0..5}.
