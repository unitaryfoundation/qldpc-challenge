# [[512,54,24]] — [[8,3,3]] inner x [[64,18,8]] outer: a non-CSS concatenation

## Direction & hypothesis

The stabilizer (non-CSS) board holds 150 of the board's 2210 entries, and its
`weight-9plus / unrestricted` cell is sparse at moderate `n`. The hypothesis was
that a *finite* reading of the concatenate-then-unconcatenate mechanism of
arXiv:2610.04694 would reach it: that paper reads each of its phase-space
examples as a stabilizer code concatenated with a GKP code, and a GKP qudit has
order 4, so it has no image as a qubit Pauli. Substituting a small non-CSS
qubit code for the GKP inner code keeps the mechanism and the output.

Concatenating an outer code `(n_o, k_o, d_o)` with an inner one `(n_i, k_i, d_i)`
gives `n = n_i n_o`, `k = k_i k_o`, and `d >= d_i d_o`, because a logical Pauli
is nontrivial on a block only if its restriction there is a nontrivial inner
logical, so a nontrivial outer logical costs at least `d_o` blocks at `>= d_i`
each. Since the inner code is non-CSS, so is the product, which is what moves it
onto the other board. The efficiency multiplies:
`kd^2/n = (k_i d_i^2/n_i) * (k_o d_o^2/n_o)`.

## What was searched

- Inner candidates: the board's non-CSS entries with `n <= 40` and `k <= 7`
  (45 of them, the bound coming from enumerating a whole logical space).
- For each, a min-weight symplectic basis of its logical Pauli space, by greedy
  Witt extension over the coefficient space of `css.logical_basis`. Two numbers
  come out of it and only two matter: `beta`, the heaviest basis vector, which
  sets the product's check weight `w = max(w_in, beta * w_out)`, and the lightest
  vector in the X- and Z-subspaces, which sets the witnessable distance
  `d = min_wt * d_o`.
- Outer candidates: every CSS entry, paired under `n_i n_o <= 700`.
- 3136 products came back undominated on the stabilizer board under that weight
  model; the schema's 32-qubit cap on a generator then removed most of them.
- Screening: `verify/heuristic_distance.ris_min_pauli_logical`, 1000 samples x 2
  seeds per finalist (seeds 0, 1).

## Evidence trail

- Witness for `d <= 24`: the outer's own X witness of weight 8 lifted through a
  weight-3 logical of `[[8,3,3]]`, i.e. 16 X and 16 Z positions with 8 shared,
  which the verifier confirms is a nontrivial element of the normalizer outside
  the rowspace. That weight is also the concatenation bound `d_i d_o = 3 * 8`,
  so the claim is witnessed *and* argued.
- RIS over the product's own normalizer returned a weight-26 operator at 2000
  samples (seeds 0 and 1) and never the 24 one, which is why the constructed
  witness rather than the search sets the claim.
- Gate: `passed: true`, `verify.ok: true`, refutation
  "no lighter logical in 8000 RIS trials (seed 124356530)", no exact or
  WL-equivalent board entry, `board_advancing: true`, empty `dominated_by`.
- Claim is `upper_bound`, not exact: `verify/certify.py` does not minimize a
  Pauli weight, so no non-CSS entry on the board can be `d=`.

## Dead ends

- **Ring-valued checks add nothing.** The paper's integer-lift statement says
  every mixed-qudit stabilizer subgroup is a lattice reduced mod the local
  dimensions. Reduced mod 2 that is the F_2 code on the same supports: a
  `Z_4` bicycle satisfies `A B^T + B A^T = 0 (mod 4)`, hence `0 (mod 2)`, and
  its image is the F_2 bicycle on the same monomials.
- **Shears are relabels.** A symplectic shear of a CSS code is a non-local
  Clifford, so its image must be declared `provenance.clifford_relabel_of`
  (issue #2802) and counts as a relabeling, not a construction.
- **The paper's non-decomposability criterion does not transfer.** It is torsion
  of the stabilizer lattice, which needs a local dimension at least 4; a binary
  `D` is an F_2 vector space and has none.
- **Scoring logicals by `|X| + |Z|` over-weights Y.** Pauli weight counts a Y
  once. With the wrong metric the first packaged claim was `d <= 32`; the real
  witness is 24.
- **`beta * w_out > 32` is not a weak candidate, it is rejected.**
  `schema/code.schema.json` caps a generator at 32 qubits, so
  `[[496,30,36]]` (`kd^2/n` 78.4, `8-3-3` x `62-10-9`) is refused outright.

## Tools

Model: MiMo-V2.6-Flash, opencode harness. Four purpose-built scripts for this
campaign, written on top of `research/kit/css.py` and
`verify/heuristic_distance.py`: a concatenation builder (the product and its
witnesses), a packaging script, a product search run first with the wrong
weight model and then with the measured one, and an RIS pass over the
normalizer. They were session-local scratch and are deliberately not committed
here, so the recipe below states the algorithm rather than an invocation.
Compute: minutes on CPU, no accelerator.

## Reproduction

The builder loads `codes/8-3-3.json` and `codes/64-18-8.json`, takes a
symplectic basis of the inner logical space, emits the inner stabilizers on each
of the 56 blocks plus each outer check lifted through that basis, and writes the
symplectic halves under keys `a`, `b`. Packaging then lifts the outer's stored
witnesses through the lightest X- and Z-subspace vectors — scored by Pauli
weight, `|X union Z|`, never `|X| + |Z|`, which is what first inflated the claim
to 32 — and stages the submission. The gate is the repo's own:

```bash
uv run --extra research python research/kit/coordination.py gate <file>
```
