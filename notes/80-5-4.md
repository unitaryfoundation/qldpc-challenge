# [[80,5,4]] even-d multiband dense-packed surface code (d=4, rows=3, m=3, pitch=2)

## Direction & hypothesis

Target the `local-2d-single / weight-4` track cell at `d = 4, k = 5` using the
even-`d` (`rows = 3, pitch = d - 2`) regime of `research/multiband_surface.py`
(resolving Open Problem 4 of
`fieldnotes/2026-09-01-multiband-dense-packing-method.md`). At `d = 4, rows =
3, pitch = 2`, each step in `m` costs 28 physical qubits per 2 logical qubits
(`n = 28m - 4, k = 2m - 1`), compared to 38 qubits per 2 logical qubits for
punctured `d = 5` two-band codes.

## What was searched

Swept `d in {4, 6, 8}`, `rows in {2..9}`, `m in {2..33}`, and even `pitch in
{2..2d}` in `research/multiband_surface.py`, filtering by exact GF(2) rank,
CSS commutation, single-component Tanner connectivity, and cell nondomination.
At `d = 4, rows = 3, m = 3, pitch = 2`, the builder produces `[[80,5,4]]`
(`kd^2/n = 1.000`, max check weight 4, single-layer 2D layout).

## Evidence trail

Confirmation ladder for the submitted code, each rung a fresh seed unless
marked otherwise, reading the lightest logical found:

| budget (trials/side) | lightest logical |
| ---: | ---: |
| 20,000 (NumPy RIS witness) | 4 |
| 200,000 (fast RIS seed 101) | 4 |
| 200,000 (fast RIS seed 102) | 4 |

3 fresh-seed rung(s) agree at the best bound, the deepest of them at 200,000
trials per side. The submitted witness reproduces it: X: d <= 4 (upper_bound),
Z: d <= 4 (upper_bound).

Also checked with `verify/sat_certify.py` (CryptoMiniSat 5.14 SAT, UNSAT below
weight 4 on both sides) and `verify/certify.py` (HiGHS MILP); claimed as a
witness-backed upper bound.

## Dead ends

- Odd pitches (`pitch = 3`) at `d = 4` fail CSS commutation (`css = False`).
- At `d = 4, rows = 3, m = 3, pitch = 4` (`[[104,9,4]]` nominal), the distance
  collapses below 4.
- Higher odd band counts `rows in {5, 7, 9}` at `d = 4, m = 3, pitch = 2` give
  `n = 108, 136, 164` with `k = 5` unchanged.
