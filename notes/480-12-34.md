# [[480,12,36]] — mirror fold of the board's [[960,24,40]]

## Direction & hypothesis

Target: the unrestricted weight-6 stabilizer cell. Applying an X/Z-swapping mirror to a strong CSS parent can halve its physical and logical qubits while retaining enough distance to extend this cell's frontier. At submission preparation on 21 October 2026, the best existing kd^2/n in this cell is 23.33, from codes/336-10-28.json. The submitted witness-backed bound gives 32.40. The candidate is non-dominated and dominates no existing entry; the score comparison is separate from Pareto membership.

**Parent:** [parent snapshot][parent] by @MicheldeMessieres, a weight-6 two-block group-algebra (2BGA) code over C24 x Dic5. The 2BGA construction is due to Lin and Pryadko ([arXiv:2306.16400](https://arxiv.org/abs/2306.16400)).

**Fold technique:** the mirror-code construction of Khesin and Lu ([arXiv:2603.05496](https://arxiv.org/abs/2603.05496)); the board's fieldnote fieldnotes/2026-09-28-symplectic-doubling-and-halving.md by @MathysRennela; and the fold convention used by @MicheldeMessieres in codes/336-10-28.json and codes/452-115-18.json, merged in PRs #3079 and #2991. Proposition 4 of [arXiv:2609.30069](https://arxiv.org/abs/2609.30069) gives a halving criterion for the CPM family; this 2BGA fold is justified by its explicit mirror and isotropy checks, rather than an assertion that it satisfies that CPM-specific proposition.

The contribution here is the mirror enumeration for this parent, selection of a fold, and the distance evidence below. The parent and the folding operation are credited prior work; a new construction is not claimed.

## What was searched

- Enumerated block swaps tau(1,g) = (2, h psi(g)^epsilon), with epsilon = +1 or -1, over every group automorphism psi and every h in G. The reverse block map is the inverse of the forward map. Retained mirrors that exchange the parent's X- and Z-checks, then grouped the folded presentations by the verifier's Weisfeiler-Lehman (WL) signature.
- The parent gives three WL classes. All three yielded a lightest found Pauli weight of 36; class 0 is submitted. WL classes do not establish inequivalence under arbitrary changes of stabilizer generators or Clifford transformations.
- Central-orbit search restricts fold logicals to be constant on orbits of central subgroups whose translations commute with tau. Cyclic and two-generator subgroups of order at most 24 produced seven usable partitions for this fold.
- Parent-quotient search finds parent logicals constant on cosets of central subgroups, lifts them, applies every central translation, and scores the number of mirror pairs touched. The first rung used 20 central subgroups; the second used nine. The ordinary pool uses unrestricted parent searches followed by the same translations. Plain doubling search uses the identity Pauli frame and re-scores its logicals by Pauli weight.

Failure to find a lighter logical, including the results 65 and 42 from weaker searches, cannot establish exact distance. Selecting mirrors using found upper bounds also leaves a search-depth selection effect.

The current-board gate reports no exact duplicate or matching WL signature, no dominator, no dominated entry, and no distance-only peer requiring a matched-depth audit. These checks concern this board, not equivalence to all published codes.

## Reproduction

Use the parent's checks in [parent snapshot][parent]. Its group is G = C24 x Dic5 with z central of order 24, x^5 = 1, y^4 = 1 and y x y^-1 = x^-1. Index z^c x^i y^j by 20c + 4i + j, for 0 <= c < 24, 0 <= i < 5 and 0 <= j < 4. Multiplication in these coordinates is (c,i,j)(c',i',j') = (c+c' mod 24, i+(-1)^j i' mod 5, j+j' mod 4). Parent qubits 0..479 form block 1; 480..959 form block 2.

Set h = z^3 x^2 y and define psi on generators by z -> z^5, x -> x^4, y -> z^12 x y^3. Then tau(1,g) = (2,h psi(g)) and tau(2,h psi(g)) = (1,g). This fixed-point-free involution maps the 480 parent X-checks onto the Z-checks.

List the representatives q_i with q_i < tau(q_i) in increasing order. Fold qubit i is the pair {q_i,tau(q_i)}. For every parent X-check in its existing row order, put X on i if the check contains q_i and Z on i if it contains tau(q_i); if both occur, put Y. This reconstructs checks.S in codes/480-12-34.json. The resulting binary symplectic matrix S = (A,B) obeys A B^T + B A^T = 0 over GF(2).

Read the stored witness from distance.P.witness in codes/480-12-34.json. An X component at i unfolds to a parent X on q_i; a Z component unfolds to a parent X on tau(q_i). Both components therefore occupy two parent sites but one folded Y site. For the submitted bound, run `uv run python verify/qldpc_verify.py codes/480-12-34.json`: it checks the witness's commutation with every generator, non-membership in the stabilizer row space, and Pauli weight (36 at filing), as well as running its local refutation pass. Rebuilding this code and checking its witness does not reproduce the entire heuristic search trajectory or prove an exact distance.
