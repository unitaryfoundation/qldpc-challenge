# [[912,234,22]] — pair-partition CPM (3,8) code at P = 114

## Direction & hypothesis

Target: the unrestricted weight-8 CSS cell. At submission preparation on
21 October 2026, codes/928-238-22.json by @MicheldeMessieres has the highest
reported kd^2/n in this cell, 124.12931. This candidate gives 124.18421 using
its submitted upper bound. It extends the Pareto frontier and dominates no
existing entry: relative to that comparator it uses fewer physical qubits
but encodes fewer logical qubits, at the same reported distance and weight.
The score comparison is separate from Pareto dominance and could change if
a lighter logical is found.

The comparator's note reports two P = 114, k = 234 draws reading 22 in a
Stern screen without further investigation. The hypothesis here was that a
longer anneal of the 8-cycle count could produce a P = 114 draw that retained
that reading under deeper searches. This is evidence about a selected
instance, not a demonstrated causal advantage of annealing.

**Inspired by:** codes/928-238-22.json and codes/976-250-22.json by
@MicheldeMessieres for the even-lift k = 2P + 6 mechanism, anneal length and
fold filter; codes/904-230-22.json by @vprusso for the matchings and 8-cycle
polishing; codes/808-206-20.json by @pandey-tushar for the girth-8 filter;
and fieldnotes/2026-09-20-screening-traps-at-n-900.md by @e-eight for the
score and lift-cap discussion.

**Technique:** the pair-partition construction and paired-difference design
system are due to Okada and Kasai ([arXiv:2607.14091v4](https://arxiv.org/abs/2607.14091v4)).
Quasi-cyclic quantum LDPC constructions using circulant permutation matrices
precede this work, including Hagiwara and Imai
([arXiv:quant-ph/0701020v4](https://arxiv.org/abs/quant-ph/0701020v4)).
The contribution is this draw, the annealing schedule with fold checkpoints,
and the distance evidence below. Literature novelty remains unverified.

## What was searched

At P = 114, draw solutions of the 36 paired-difference equations in the
Reproduction section using a 19-dimensional integer solution basis reduced
modulo 114. Require girth 8 in both Tanner graphs and compute k over GF(2).
The ordinary arms retain starting draws with k >= 234; the residue-class
arm selects a mod-3 class supporting k >= 236.

For subgroup orders m = 2, 3, 6, search the quotient lift over Z_(114/m) at
1,000 RIS trials per side. Lift a quotient word to the full code and check
its commutation and non-membership in the same-type stabilizer row space.
Discard a draw if a valid lifted logical has weight below 22. A quotient
word alone is insufficient: its lift might be a stabilizer.

For the long anneals, try 15,000 single-coefficient changes in the design
basis. Reject girth violations; accept an increase delta in the summed
8-cycle count with probability exp(-delta/T), with T decreasing geometrically
from 64 toward 4. Recheck the starting k after every accepted move and
connectivity and the fold filter every 200 accepted moves, reverting to a
validated checkpoint on failure. Return the validated state with the lowest
8-cycle count. For the submitted draw, k remains 234.

The long-anneal arms screen at 2,000 RIS trials per side, then escalate
readings of at least 22 through 10,000, 30,000 and 300,000 trials on fresh
seeds. The greedy control instead uses 2,000 and 30,000 trials, with deep
follow-up recorded separately. Counts below are completed task records,
excluding metadata, reconciled on 21 October 2026. A screened draw has a
recorded full-code RIS reading after its fold filter and climb.

## Reproduction

Set P = 114 and use these exponent arrays:

```
E_x = [[7, 36, 9, 74, 72, 80, 62, 78],
       [87, 104, 31, 0, 102, 78, 34, 74],
       [102, 26, 88, 102, 97, 50, 71, 12]]
E_z = [[113, 58, 99, 76, 64, 82, 38, 100],
       [65, 5, 67, 85, 80, 49, 70, 89],
       [101, 72, 45, 98, 96, 46, 28, 58]]
```

Start with zero 342 by 912 binary matrices. For i = 0..2, j = 0..7,
r = 0..113, set H_X[i*P+r, j*P+((r-E_x[i][j]) mod P)] = 1; use E_z
for H_Z. Qubit j*P+c is column block j, offset c. Enumerate rows in
increasing i*P+r order and sort each support to reconstruct checks.X and
checks.Z in codes/912-234-22.json.

The matchings are M0 = (0,4)(1,7)(2,6)(3,5), M1 = (0,7)(1,2)(3,4)(5,6),
M2 = (0,2)(1,5)(3,7)(4,6). For each pair (a,b) in M[(i-j) mod 3], the
arrays obey E_x[i][a]-E_x[i][b]-E_z[j][a]+E_z[j][b] = 0 modulo 114.
The two ranks are 339, so k = 912-339-339 = 234. Check weight is 8.

Run `uv run python verify/qldpc_verify.py codes/912-234-22.json` to check
structure, commutation, rank, connectivity and the stored nontrivial
weight-22 witnesses, with its local refutation pass. The exponent arrays
reconstruct the submitted matrices; they do not replay the heuristic search
trajectory. This two-file submission includes no automated constructor or
reproduction manifest. The arrays, lift rule, seeds and budgets are recorded
here. No circuit tier is included: n = 912 exceeds the tier's n <= 200 cap.
