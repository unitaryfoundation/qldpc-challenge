# [[414,136,8]] weight-9 CSS parity amplification

The submitted JSON records witness-backed bounds d_X <= 8 and d_Z <= 8.
The analytic distance argument below is separate from the board's exact
certification tier.

## Direction & hypothesis

Target: the CSS weight-9plus x unrestricted Pareto cell. The hypothesis was
that larger even-length parity amplifiers can improve the rate while retaining
bounded check weight. The September 30 amplification fieldnote dismissed the
general single-check family; its all-ones CSS presentation actually has
distance 2 for even length at least 4. This submission uses the established
CSS tensor product of arXiv:2609.37231, not a new-family claim. Literature
novelty remains unverified.

## What was searched

A parameter screen of board CSS seeds with n <= 104 and parity lengths 6, 8,
10 and 12 retained 44 predictions under n <= 700. Seven selected tensor
instances were constructed and searched with 500 NumPy RIS trials per Pauli
side, plus an 18-qubit 4-2-2 tensor control. All seven passed the trusted gate
against upstream f890a3a3b990c3f34d420553ef849a3f055d6478. The final
submission is rechecked against upstream
78051e5f32bd05397f2f3fdacfc064ce0c66a5cf. Six remain non-dominated within the
batch. For this candidate, the initial X/Z seeds were 20661001 and 20661002.
The independent gate used seed 1542883948 and reported no lighter logical in
8000 RIS trials. The subsequent accelerated search uses the unchanged
repository C++ implementation and the kit interface that returns and validates
a logical witness.

3 fresh-seed rung(s) agree at the best bound, the deepest of them at 1,000,000

Z: d <= 8 (upper_bound).

The accelerated rungs use 4 threads and pair_depth=16. Each requested budget
is per Pauli side; the returned witness is the overall minimum across both
searches. Distinct root seeds are used between rungs. The backend uses the
same thread-seed offsets for X and Z; no independence between the two sides is
asserted. NumPy and accelerated trial counts are not interchangeable. The
returned weight-8 witnesses were saved and checked with the Python verifier.
Both sides of the submitted JSON carry valid weight-8 witnesses and remain
upper_bound. No final candidate bound collapsed during this confirmation.

There is also an analytic distance argument. For the parity amplifier E_q with
G_X=G_Z=1_q, each logical class has the complementary, disjoint
representatives v and v+1_q. The existing tensor-product overlap bound (Lemma
4 of arXiv:2609.37231) gives D_P >= 2 d_P(B), and a tensor product with a
weight-2 amplifier logical gives D_P <= 2 d_P(B). This applies for even q >=
4. The repository MILP certifier proved both distances of the 64-qubit seed to
be 4, with a 3-second limit per logical constraint. Consequently this argument
supports D_X=D_Z=8. It is separate from the random-search evidence and is not
a server certificate of this product.

## Reproduction

The seed is `codes/64-34-4.json`, credited there to @MathysRennela and the
affine-Frobenius construction of arXiv:2609.24201. Use its first 15 original X
rows and first 15 original Z rows (zero-based indices 0 through 14); each
retained set is an independent basis. The second factor is the all-ones
[[6,4,2]] CSS code, also available as `codes/6-4-2.json`. The product is E_6
tensor B, with central, Q_2 tensor A_0, and Q_0 tensor A_2 qubit sectors in
that order. This recipe reconstructs the submitted matrices:

```python
import json
import numpy as np

with open("codes/64-34-4.json") as f:
    seed = json.load(f)

def matrix(side):
    h = np.zeros((15, 64), dtype=np.int8)
    for i, support in enumerate(seed["checks"][side][:15]):
        h[i, support] = 1
    return h

gx, gz = matrix("X"), matrix("Z")
q = np.ones((1, 6), dtype=np.int8)
i6 = np.eye(6, dtype=np.int8)
i15 = np.eye(15, dtype=np.int8)
i64 = np.eye(64, dtype=np.int8)
z64 = np.zeros((64, 15), dtype=np.int8)
z90 = np.zeros((90, 15), dtype=np.int8)
hx = np.block([[np.kron(q, i64), z64, gz.T],
               [np.kron(i6, gx), np.kron(q.T, i15), z90]])
hz = np.block([[np.kron(q, i64), gx.T, z64],
               [np.kron(i6, gz), z90, np.kron(q.T, i15)]])
```

Each product matrix has shape 154 by 414 and rank 139. Thus k=414-139-139=136.
The retained seed has maximum row weight 8 and maximum column weight 2, so the
product's maximum row weight is max(8+1, 6+2)=9. All arithmetic for
commutation and rank is over GF(2). The construction follows equations
(14)-(15) of arXiv:2609.37231. Its off-diagonal commutator blocks cancel in
pairs; the diagonal blocks vanish by the two factors' CSS identities.

Run `verify/qldpc_verify.py` on `codes/414-136-8.json` to check the stored
witnesses. The accelerated confirmation is reproducible through
`research/kit/surrogate.py` using backend="fast", threads=4, pair_depth=16,
100000 trials with seed 20861001 and 1000000 trials with seed 20861002. The
search returns the overall lightest logical, whose support must be saved. This
is a code-tier submission; no locality layout or circuit-distance claim is
supplied.
