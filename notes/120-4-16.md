# [[120,4,16]] — Weight-8 bivariate bicycle code on Z_10 x Z_6

## Direction & hypothesis

Targeted the `weight-8` / `unrestricted` cell using bivariate bicycle (BB) constructions on `Z_l x Z_m` with weight `(4, 4)` (`w = 8`) on rectangular grids `(l, m)` that are less explored than square/standard BB shapes, filtering strictly for codes with no Weisfeiler-Leman match on the board.

## What was searched

Random sweep of 21,000 bivariate-bicycle and small-group 2BGA codes (seed `20261125`), filtering for CSS commutation, `k >= 4`, connected Tanner graph and stabilizer group, and no exact or Weisfeiler-Leman match against the current board. Candidates were screened at 1,500 fast RIS trials (`verify/gf2_fast`), and non-dominated survivors were re-screened at 200,000 fast RIS trials.

## Evidence trail

- 1,500 RIS trials (`gf2_fast`): `d <= 16`
- 200,000 RIS trials (`gf2_fast`): `d <= 16`
- Validation gate (`verify/validate_candidate.py`): `d_X <= 16`, `d_Z <= 16` (witnessed upper bound), `no lighter logical in 7300 RIS trials`, `passed: true`, `board_advancing: true`, `exact_duplicate_of: null`, `wl_equivalent_of: null`.
- Submission accelerator pass (`./qldpc submit`): `2,000,000` RIS trials (`d_X <= 16`, `d_Z <= 16`).

Final claim: witness-backed `upper_bound` `d <= 16` (`d_X <= 16, d_Z <= 16`), `w = 8`. Literature novelty unverified.

## Dead ends

Most sampled `(4, 4)` BB instances on rectangular shapes `(l, m)` either had `k < 4`, were dominated by existing `weight-8` entries, or had `d < 16` at 200,000 RIS trials.
