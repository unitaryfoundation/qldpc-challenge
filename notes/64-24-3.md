# [[64,24,3]]: 2D-local weight-6 CSS code from a t=2 SAT search on an 8x8 grid

## Direction & hypothesis

Cell: weight-6 x local-2d-single. `codes/64-22-3.json` came from the same
encoding at G=21 checks per side in the Phase 0 triage of issue #2024, where
G=23, 22, and 21 were run and G=20 and 19 were left for Phase 1. For a
full-rank model k = n - 2G, so G=20 forces k >= 24 and G=19 forces k >= 26.
The column-count bound for weight 6 at n=64 (G >= 2n/7 = 18.3) makes G=19
the last rung that can hold a code at all.

8x8 grid, 20 checks per side anchored within radius 2.0 (interaction radius
at most 4.0 by construction), row weight at most 6, CSS commutation, nonzero
syndrome for every weight <= 2 Pauli error (266,720 variables, 998,576
clauses, 2 s to build). CaDiCaL 1.9.5 via python-sat, conflict cap

k = 24 with d_ub = 3. Model 0 is the code here. The G=19 rung (k >= 26) then
ran to its 20,000,000-conflict cap in 5,521 s with neither a model nor an
UNSAT proof.
