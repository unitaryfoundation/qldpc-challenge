# [[88,36,4]] — cyclic XYZ binary cube, L=11

## Direction & hypothesis

Target: the weight-8, unrestricted stabilizer frontier. Start within the known
XYZ framework of [Baldelli et al.](https://arxiv.org/html/2607.14988v1),
Sections III–V: three pairwise-orthogonal binary check spaces carrying pure
X, Z and Y checks. Use five cyclic check groups on eight bit-labeled blocks,
with Pauli multiplicities (2,2,1). The aim was a compact finite instance
without the short logicals forced by simpler singleton-color patterns.
Pair-partition cancellation and symplectic halving have close prior in
[Lee et al.](https://arxiv.org/html/2609.30069v1), Sections III–IV.
Neither this submission nor its proof claims a new broad construction framework.

## What was searched

Fixed construction: L=11, shifts (1,2,3), eight cyclic blocks and five check
groups. The validation scope is the two finite instances. Total historical
candidate count and search compute were not recorded reliably.

Let q=(q1,q2,q3) range over binary triples in lexicographic order and
s range modulo L. Qubit (q,s) has flat index L*(4*q1+2*q2+q3)+s.
For each i modulo L, take one site from every q block at these offsets:

| Check type | Site coordinate s |
| --- | --- |
| X | i |
| X | i+q1+2*q2+3*q3 |
| Z | i+q1 |
| Z | i+2*q2+3*q3 |
| Y | i+2*q2 |

Order the check groups as in the table, then i=0,...,L-1. All sites are
reduced modulo L. This reconstructs the ordered checks in codes/88-36-4.json.
Each row has Pauli weight eight, each data qubit has degree five, and the
55-check binary symplectic matrix has rank 52, so k=36.

outside the Lean proof. The independent computation checked no nonzero
normalizer of weight 1–3 and the weight-four logical.

There is also a full-rowspace finite non-LC-CSS certificate, independent of
the official supplied-generator test. For each generator support Q,
rank(S)-rank(S restricted outside Q)=1, retaining both symplectic halves.
In a CSS image a mixed generator would split into two independent stabilizers
inside Q, contradicting that dimension. Every qubit sees all three Pauli axes
among these minimal-support generators; local Cliffords cannot send those
three axes into only X and Z. This includes arbitrary generator rebasing and
qubit permutations. The public package provides a direct replay script.

Literature status remains unknown. The current board and targeted primary-source
and exact-parameter searches did not establish an identical published point;
absence from this limited search does not prove worldwide novelty or general
inequivalence to published codes. No priority or superiority to all CSS codes
is claimed. Distance is fixed at four here; no growing-distance claim is made.

## Dead ends

The motivating restricted singleton-color incidence pattern permits repeated
same-axis syndromes and weight-two normalizers. Simply adding a second group
of only one color leaves the analogous obstruction for the other singleton
colors. The (2,2,1) choice avoids that specific mechanism. This is a scoped
design lesson, not a no-go theorem for arbitrary degree-four stabilizer codes.
No other exploratory code or negative-result dataset is submitted in this PR.

## Reproduction

Reconstruct the five groups from the table, or use the exact ordered matrix
already in codes/88-36-4.json. At the upstream commit above:

```sh
uv sync --frozen --python 3.12 --extra research --extra certify
make fast
uv run python verify/qldpc_verify.py codes/88-36-4.json
uv run python verify/validate_candidate.py codes/88-36-4.json
uv run python verify/heuristic_distance.py codes/88-36-4.json --trials 20000 --fast-trials 2000000 --fold-trials 50000 --seed 2026101781
```

Repeat the last command with seed 2026101782. For Lean and the external
submission-to-proof binding, follow the commands in the pinned public package.
