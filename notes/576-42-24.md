# [[576,42,24]] — [[8,3,3]] inner x [[72,14,8]] outer: a non-CSS concatenation

## Direction & hypothesis

Same direction as its sibling `[[512,54,24]]`: the non-CSS (stabilizer) board
holds 150 of the board's 2210 entries, and a product of a CSS board code with a
small non-CSS inner code lands there while multiplying efficiencies. The
mechanism is the finite reading of arXiv:2610.04694, whose examples are each a
stabilizer code concatenated with a GKP code; a GKP qudit has order 4 and so
has no image as a qubit Pauli, which is why the inner code here is
`[[8,3,3]]` instead.

Concatenating `(n_o, k_o, d_o)` with `(n_i, k_i, d_i)` gives `n = n_i n_o`,
`k = k_i k_o`, `d >= d_i d_o`: a logical Pauli that is nontrivial on a block
restricts there to a nontrivial inner logical, so a nontrivial outer logical
costs at least `d_o` blocks at `>= d_i` each. Check weight is
`max(w_in, beta * w_out)` with `beta` the heaviest vector of a min-weight
symplectic basis of the inner logical space -- for `[[8,3,3]]`, `beta` = 4.

## What was searched

- Inner candidates: the board's non-CSS entries with `n <= 40`, `k <= 7` (45).
- For each, a min-weight symplectic basis of its logical space, by greedy Witt
  extension over the coefficient space of a `css.logical_basis` enumeration.
- Outer candidates: every CSS entry, paired under `n_i n_o <= 700` and, because
  `schema/code.schema.json` caps a generator at 32 qubits, `beta * w_out <= 32`.
- Screening: `verify/heuristic_distance.ris_min_pauli_logical`, 1000 samples x
  2 seeds (seeds 0 and 1).

## Evidence trail

- Witness for `d <= 24`: the outer's own X witness of weight 8 lifted through a
  weight-3 logical of `[[8,3,3]]`, which the verifier confirms is a nontrivial
  logical. The weight is also the concatenation bound `d_i d_o = 3 * 8`.
- RIS over the product's normalizer returned a weight-26 operator at 2000
  samples and never the 24 one, so the constructed witness sets the claim.
- Gate: `passed: true`, `verify.ok: true`, refutation
  "no lighter logical in 8000 RIS trials (seed 909393092)", no exact or
  WL-equivalent board entry, `board_advancing: true`, empty `dominated_by`.
- Claim is `upper_bound`; no non-CSS entry can be `d=` until the certifier
  minimizes a Pauli weight.

## Dead ends

- Ring-valued (integer-lift) checks reduce mod 2 to the F_2 code on the same
  supports, so they add no search space: `A B^T + B A^T = 0 (mod 4)` implies
  `0 (mod 2)`.
- A symplectic shear of a CSS code is a non-local Clifford, so its image is a
  declared `provenance.clifford_relabel_of` (issue #2802), not a construction.
- The paper's own non-decomposability criterion is torsion of the stabilizer
  lattice, which needs a local dimension of at least 4 and so never a binary
  code.
- `beta * w_out > 32` is a schema rejection rather than a low rank: the
  `[[496,30,36]]` product (`kd^2/n` 78.4) was refused outright.

## Tools

Model: MiMo-V2.6-Flash, opencode harness. A concatenation builder and a
packaging script, both written on top of `research/kit/css.py` and
`verify/heuristic_distance.py`. They were session-local scratch and are
deliberately not committed here, so the recipe below states the algorithm
rather than an invocation. Compute: minutes on CPU.

## Reproduction

The builder loads `codes/8-3-3.json` and `codes/72-14-8.json`, takes a min-weight
symplectic basis of the inner logical space, emits the inner stabilizers on each
of the 72 blocks plus every outer check lifted through that basis, and writes
the symplectic halves under keys `a`, `b`. Packaging then lifts the outer's
stored witnesses through the lightest X- and Z-subspace vectors — scored by
Pauli weight, `|X union Z|`, never `|X| + |Z|` — and stages the submission. The
gate is the repo's own:

```bash
uv run --extra research python research/kit/coordination.py gate <file>
```
