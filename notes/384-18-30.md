# [[384,18,30]] — weight-8 bivariate bicycle code on Z_16 x Z_12

## Direction & hypothesis

Cell `weight-8 x unrestricted`, CSS board, n between 360 and 400. Before
this campaign the weight-8 frontier there ran 360-10-28, 364-8-32,
368-2-35, 372-14-29, 378-18-27, 390-10-32 and 392-8-33: at n <= 384 every
weight-8 entry with d >= 30 had k <= 8. The hypothesis was that
four-plus-four-term bivariate bicycle (BB) codes on tori with 2lm in
300..400, prefiltered for k >= 18, could put a k = 18 point at d = 30.
[[384,18,30]] does: no board entry has n <= 384, k >= 18, d >= 30 and check
weight <= 8. It is not a d-only gain (no board entry has the same n, k and
weight). It dominates the [[384,16,30]] on Z_24 x Z_8 filed earlier in the
same campaign (two more logicals at the same n, d and weight).

## What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A and B four
monomials each, both containing 1 (no loss of generality), on every torus
Z_l x Z_m with l >= m >= 3 and 300 <= 2lm <= 400, the torus drawn uniformly
from that list and the other three monomials of each polynomial uniformly
from the torus.

Random supports rarely give k >= 18, so the sweep ran a parallel
generate-and-rank prefilter: 300,000 draws (seed 121), of which 693 had
k >= 18 and a connected Tanner graph (research/kit/prescreen.block_structure).
Those went through research/kit/search.screen with the gf2_fast backend at
400 trials; 14 advanced the board frontier at screen depth and were
confirmed at 20,000 / 200,000 / 2,000,000 fast trials
(research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a
candidate as soon as its running bound stopped advancing and skipping any
already dominated by a point staged earlier in the campaign. This was the
only one staged.

## Evidence trail

Witness-backed **upper bound** d <= 30, not an exact distance. Because the
claim is d >= 30 the ladder used 20,000,000 trials per seed.

| stage | trials per candidate | lightest logical |
|---|---|---|
| screen (gf2_fast, seed from fingerprint) | 400 | 40 |
| confirm | 20,000 | 32 |
| confirm | 200,000 | 30 |
| confirm | 2,000,000 | 30 |
| deep ladder, 3 fresh seeds (58214, 66133, 74052), gf2_fast | 20,000,000 each | 30, 30, 30 |

The bound reached 30 at 200,000 trials and then held; it is still only an
upper bound.

`verify/validate_candidate.py` (through research/kit/coordination.py's gate
wrapper) returned `passed: true`, `board_advancing: true`, `d_only_gain:
false`, label "advances the weight-8 x unrestricted board". Literature
novelty is unverified; board-relative novelty comes from
verify/validate_candidate.py (fingerprint and Weisfeiler-Leman dedup
against every board entry found nothing).

## Dead ends

- Whole-band 4 + 4 BB sweeps (222 <= n <= 400; 100,000 to 300,000
  prefiltered draws each) reached d = 30 only at k = 16 ([[384,16,30]]).
  Three more sweeps restricted to 2lm >= 300 with a k >= 18 prefilter
  (seeds 111, 112, 121; about 700 kept each) staged [[392,22,28]],
  [[340,18,26]] and this code, and nothing else.
- A 3 + 5 split (700,000 draws over two seeds) and a 2 + 6 split (200,000
  draws) of the same check weight never reached k >= 18 with an advancing
  distance.
- Cyclic generalized-bicycle codes with a designed divisor g | x^m - 1,
  weight-4 a and b (check weight 8): 4,000 draws at 300 <= n <= 400 gave
  nothing advancing even at 400 trials.
- Random-support 2BGA on non-abelian groups at check weight 8, 16,000
  serial plus 150,000 prefiltered draws: every screen-depth survivor
  collapsed by 20,000 trials.

## Reproduction

Torus Z_16 x Z_12 (x of order 16, y of order 12), terms (i, j) = x^i y^j:

A = 1 + y^7 + x^11 y^10 + x^12 y^3,
B = 1 + x^7 y^9 + x^8 y + x^9 y^7.

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from bb import build_bb
from css import compute_k
HX, HZ = build_bb(16, 12, [(0, 0), (0, 7), (11, 10), (12, 3)],
                  [(0, 0), (7, 9), (8, 1), (9, 7)])   # n = 384
assert compute_k(HX, HZ) == 18
```

Check sets match codes/384-18-30.json row for row in this order. Witness
search: `surrogate.distance_rand_witness(HX, HZ, trials=2_000_000,
seed=123000363, backend="fast", pair_depth=8)` returns a weight-30 logical.
