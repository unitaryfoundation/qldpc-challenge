# [[672,28,30]] — [[8,2,3]] inner x [[84,14,10]] outer: a non-CSS concatenation

## Direction & hypothesis

Third of three products from one construction, this the lightest of them: the
non-CSS (stabilizer) board holds 150 of the board's 2210 entries, and a product
of a CSS board code with a small non-CSS inner code lands on it while
multiplying efficiencies. The mechanism is the finite reading of
arXiv:2610.04694, where every example is a stabilizer code concatenated with a
GKP code; a GKP qudit has order 4 and therefore no image as a qubit Pauli, so
the inner code here is `[[8,2,3]]`.

`n = n_i n_o`, `k = k_i k_o`, `d >= d_i d_o` -- a logical Pauli nontrivial on a
block restricts there to a nontrivial inner logical, so a nontrivial outer
logical costs at least `d_o` blocks at `>= d_i` each. What distinguishes this
one is `beta`: `[[8,2,3]]` has a symplectic basis all of whose six... four
vectors have weight 3, so the check weight is `3 * 8 = 24` rather than the 32
of its `[[8,3,3]]` siblings, and the witnessable distance is `3 * 10 = 30`.

## What was searched

- Inner candidates: the board's non-CSS entries with `n <= 40`, `k <= 7` (45),
  each given a min-weight symplectic basis of its logical space by greedy Witt
  extension over the coefficient space of a `css.logical_basis` enumeration.
- Outer candidates: every CSS entry, paired under `n_i n_o <= 700` and
  `beta * w_out <= 32` -- the second condition is a hard schema cap
  (`$defs/generatorList/items/properties/X` and `/Z`, `maxItems: 32`), not a
  ranking preference.
- Screening: `verify/heuristic_distance.ris_min_pauli_logical`.

## Evidence trail

- Witness for `d <= 30`: the outer's own witness of weight 10 lifted through a
  weight-3 logical of `[[8,2,3]]`, which the verifier confirms is a nontrivial
  logical. The weight is also the concatenation bound `d_i d_o = 3 * 10`.
- Gate: `passed: true`, `verify.ok: true`, refutation
  "no lighter logical in 8000 RIS trials (seed 317404972)", no exact or
  WL-equivalent board entry, `board_advancing: true`, empty `dominated_by`.
- Claim is `upper_bound`; no non-CSS entry can be `d=` until the certifier
  minimizes a Pauli weight.

## Dead ends

- Ring-valued (integer-lift) checks reduce mod 2 to the F_2 code on the same
  supports, so they add no search space: `A B^T + B A^T = 0 (mod 4)` implies
  `0 (mod 2)`.
- A symplectic shear of a CSS code is a non-local Clifford, so its image is a
  declared `provenance.clifford_relabel_of` (issue #2802), not a construction.
- The paper's own non-decomposability criterion is torsion of the stabilizer
  lattice, which needs a local dimension of at least 4 and so never a binary
  code.
- Products whose `beta * w_out` exceeds 32 cannot be filed at any rank.

## Tools

Model: MiMo-V2.6-Flash, opencode harness. A concatenation builder and a
packaging script, both written on top of `research/kit/css.py` and
`verify/heuristic_distance.py`. They were session-local scratch and are
deliberately not committed here, so the recipe below states the algorithm
rather than an invocation. Compute: minutes on CPU.

## Reproduction

The builder loads `codes/8-2-3.json` and `codes/84-14-10.json`, takes a
min-weight symplectic basis of the inner logical space, emits the inner
stabilizers on each of the 84 blocks plus every outer check lifted through that
basis, and writes the symplectic halves under keys `a`, `b`. Packaging then
lifts the outer's stored witnesses through the lightest X- and Z-subspace
vectors — scored by Pauli weight, `|X union Z|`, never `|X| + |Z|` — and stages
the submission. The gate is the repo's own:

```bash
uv run --extra research python research/kit/coordination.py gate <file>
```
