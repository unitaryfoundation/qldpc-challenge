# [[16,6,2]] — SAT-discovered weight-4 2D-local CSS code (variant b)

## Direction & hypothesis

Thin cell: `local-2d-single x weight-4` at small `n` with `d = 2`. The goal was to
exercise the new `row_sort` symmetry break in `research/local_sat.py` and confirm it
can produce a gate-passing, board-advancing code distinct from the existing
`[[16,6,2]]` entry.

## What was searched

SAT enumeration over a 4x4 grid (`n = 16`), `G = 5` generators per side, weight
bound `w <= 4`, detection level `t = 1` (so `d >= 2`), interaction radius `1.5`,
with `row_sort=True` (row-permutation orbit reduction) and `symmetry="lex"`
(D4 + X/Z static lex-leader). Candidates were filtered for a connected Tanner
graph (`prescreen.block_structure`) and passed through `make_submission` (RIS
witness search) and `save_submission` (preflight). The first connected,
non-duplicate survivor was this code.

## Evidence trail

- `d = 2` is a witness-backed upper bound: `verify/heuristic_distance` found
  weight-2 logical operators on both sides; the verifier confirms they are
  genuine nontrivial logicals.
- The code passed `verify/validate_candidate.py` (`passed: true`,
  `board_advancing: true` in its track cell) and is not a duplicate or
  WL-equivalent of any existing entry.

## Dead ends

Most enumerated models were disconnected (direct sums of smaller blocks) and were
rejected by the gate's `tanner_connected` / `stabilizer_group_connected` checks.

## Tools

Model: Beam 1.0. Harness: opencode. Repo tooling: `research/local_sat.py`
(`row_sort=True`), `research/kit/submit.py` (`make_submission`,
`save_submission`), `research/kit/prescreen.py` (`block_structure`),
`research/kit/coordination.py` (`gate`).
