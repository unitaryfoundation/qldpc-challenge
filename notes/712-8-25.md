# [[712,8,25]] — ten local reductions of a planar tile code

## Direction & hypothesis

The published `codes/722-8-25.json` is a weight-8, single-layer 2D tile
code with eight logical qubits and explicit weight-25 logical operators.
Local stabilizer pivots can remove physical qubits while retaining its
checks, layout class, and logical witnesses. We sought a smaller `n` in
that board cell. The reported distance is a witness-backed upper bound.

## What was searched

Nine compatible pivots reduced the 722-qubit code to a staged 713-qubit
ancestor. A tenth single-pivot scan found 96 structural 712-qubit
variants preserving check weight at most 8, radius at most 4, and an
inherited weight-25 logical with neither side below 25. Fifty-seven
retained `k=8`, Tanner and stabilizer-block connectivity, and valid
logicals. Projection of 393 light ancestor logicals, including
stabilizer-row translates and RIS witnesses lifted from the children,
refuted seven variants with validated lighter logicals. A 10,000-trial,
pair-depth-8 screen covered all 54 initial survivors. We tested
X349/pivot281 and Z485/pivot84 at 100,000 trials and pair depth 512;
both returned weight 25. We selected Z485/pivot84 for deeper tests.

## Evidence trail

The unchanged trusted candidate gate passed the Z485/pivot84 JSON with
seed 3255190. It checked CSS commutation, `n=712`, `k=8`, maximum
check weight 8, a connected one-layer radius-4 layout, the two
weight-25 logicals, deduplication, and an 8,000-trial RIS refutation
search. It marked the weight-8, local-2d-single cell as advancing by
lower `n`. An independent ten-pivot reconstruction from
`codes/722-8-25.json` matched the candidate checks and coordinates.
The Z witness matches the published parent's projection; the X
witness descends from a validated RIS result on the 719-qubit ancestor.

On the exact 712-qubit matrices, accelerated RIS found no logical below
25 in 10,000 pair-depth-8 trials (seed 720158584), 100,000
pair-depth-512 trials (seed 1224248584), 1,000,000 pair-depth-512
trials (seed 1225148584), and 1,000,000 pair-depth-4096 trials (seed
4809148584). Every returned logical was checked against those matrices.

**`d≤25` is a witness-backed upper bound.** The bounded searches do not
prove a minimum distance of 25. The witnessed score is
`8 × 25² / 712 = 7.022`, versus 6.925 for the 722-qubit parent.
Against `codes/717-8-25.json`, this code removes 5 physical qubits
at the same `k`, witnessed bound, weight, and layout class.

## Dead ends

Seven other 712-qubit variants fell to validated lighter logicals
projected from saved ancestor and child witnesses. The remaining
shallow-screen survivors have not been deeply confirmed.

## Reproduction

Start from `codes/722-8-25.json`. At each step, XOR the named pivot
row into every other same-side check containing the target qubit;
delete the pivot row and qubit, shorten opposite-side checks, delete
that coordinate, and renumber surviving qubits. In order:

1. Z row 289, support `{0,362,363}`, target qubit 0.
2. Z row 289, support `{1,18,361,380,381}`, target qubit 18.
3. Z row 350, support `{356,357,716}`, target qubit 357.
4. Z row 353, support `{356,357,715,716}`, target qubit 357.
5. X row 291, support `{16,17,35,393,412,413}`, target qubit 17.
6. X row 272, support `{301,302,321,341,662,679,698,699}`, target qubit 341.
7. X row 348, support `{282,301,321,641,678}`, target qubit 321.
8. X row 273, support `{303,304,322,341,662,679,698,699}`, target qubit 341.
9. Z row 290, support `{339,695}`, target qubit 695.
10. Z row 84, support `{90,91,110,127,445,465,484,485}`, target qubit 485.

Project the published Z witness through all ten pivots. The X witness
in the candidate JSON comes from accelerated RIS on the 719-qubit
intermediate and is projected through the final seven pivots. The JSON
contains the final checks, coordinates, and both witness supports.
