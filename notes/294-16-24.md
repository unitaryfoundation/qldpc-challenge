# [[294,16,24]] — weight-8 bivariate bicycle code on Z_21 x Z_7 with a 3 + 5 term split

## Direction & hypothesis

Cell `weight-8 x unrestricted`, CSS board, n between 270 and 320. Before
this campaign the weight-8 frontier there ran 270-34-14, 270-10-24,
280-6-25, 288-12-24, 292-22-23, 294-24-20, 300-12-25, 306-26-19 and
310-12-26: at n <= 294 no weight-8 entry with k >= 16 reached d = 24.
Bivariate bicycle (BB) codes on the board almost always split the check
weight evenly between the two polynomials. The hypothesis was that an
uneven split, |A| = 3 and |B| = 5 (still check weight 8 and column weight
8), could reach k = 16 at d = 24 below the [[320,16,24]] (4 + 4 split)
filed from the same campaign. [[294,16,24]] does: no board entry has
n <= 294, k >= 16, d >= 24 and check weight <= 8, and the k - 2 margin
holds ([[294,14,24]] is not dominated either). It dominates that
[[320,16,24]].

## What was searched

BB codes H_X = [A | B], H_Z = [B^T | A^T] with A three monomials and B five
monomials, both containing 1 (no loss of generality), on every torus
Z_l x Z_m with l >= m >= 3 and 222 <= 2lm <= 400, the torus drawn uniformly
from that list and the other monomials uniformly from the torus.

The split costs rate: only 202 of 400,000 draws (seed 102) had k >= 16 and
a connected Tanner graph (research/kit/prescreen.block_structure). Those
went through research/kit/search.screen with the gf2_fast backend at 400
trials; 9 advanced the board frontier at screen depth and were confirmed at
20,000 / 200,000 / 2,000,000 fast trials
(research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a
candidate as soon as its running bound stopped advancing and skipping any
already dominated by a point staged earlier in the campaign. This was the
only one staged. An earlier 3 + 5 sweep (300,000 draws, seed 91) staged the
[[360,16,28]] filed separately.

## Evidence trail

Witness-backed **upper bound** d <= 24, not an exact distance. The bound
was 24 at 400 trials and never moved.

against every board entry found nothing).

## Dead ends

- Even-split 4 + 4 BB sweeps in the same band (100,000 to 300,000
  prefiltered draws each) reached k = 16, d = 24 only at n = 320.
- Cyclic generalized-bicycle codes with a designed divisor g | x^m - 1,
  weight-4 a and b (check weight 8): weight-4 multiples of g exist only for
  deg g <= ~22 at odd m from 111 to 200, and 4,000 such draws gave nothing
  advancing even at 400 trials.
- Random-support 2BGA on non-abelian groups at check weight 8, 16,000
  serial plus 150,000 prefiltered draws: every screen-depth survivor
  collapsed by 20,000 trials.

## Reproduction

Torus Z_21 x Z_7 (x of order 21, y of order 7), terms (i, j) = x^i y^j:

A = 1 + x^13 y^6 + x^14 y^6,
B = 1 + x^3 y^5 + x^6 y^5 + x^11 y^2 + x^13 y.

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from bb import build_bb
from css import compute_k
HX, HZ = build_bb(21, 7, [(0, 0), (13, 6), (14, 6)],
                  [(0, 0), (3, 5), (6, 5), (11, 2), (13, 1)])   # n = 294
assert compute_k(HX, HZ) == 16
```

Check sets match codes/294-16-24.json row for row in this order. The numpy
`surrogate.lightest_logical` at 1,500 trials with seed 103 on the Z side
(pass (HZ, HX)) returns a weight-24 logical.
