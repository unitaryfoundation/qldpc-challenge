# [[485,97,25]] — reversing fold of a masked 4x10 circulant CSS parent at P = 97, weight 8

## Direction & hypothesis

Target: the weight-8, unrestricted cell of the stabilizer board, whose best entry by kd^2/n is [[452,115,18]] (82.4).
That entry is a reversing symplectic fold of a CSS pair-partition CPM code. Folds of the ten strongest weight-8
circulant CSS parents on the board stayed near it: in our enumeration, each of their 1,052 admissible pairings had a
logical of weight at most 18. The hypothesis was that the obstruction belongs to dense full-block parents. A sparser
parent, with blocks removed from each block row, could fold without inheriting a light logical. The fold is the
reverse-fold mechanism of Lee et al. (arXiv:2609.30069) applied to a masked parent. We do not claim the folding
operation as new.

## What was searched

Parent: a CSS code on 10 circulant blocks of size P = 97 with 4 X-type and 4 Z-type block rows. Block row i omits
column blocks i and i + 5, so every check has binary weight 8. Fold: qubit (l, t) is identified with
(l + 5, -t) for l < 5. The first member supplies the X part and its partner the Z part, giving 5P = 485 qubits and
4P = 388 generators. Commutation of the folded generators was imposed as pair-partition equations on the exponents,
with one perfect matching of the differing columns chosen per pair of block rows. This code is one integer solution of
that system. The parent is a weight-8 CSS [[970,194]] code.

## Evidence trail

Board claim: **d <= 25, witnessed upper bound** (the only confidence the board records for a stabilizer code). The
witness has Pauli weight 25, with 7 Y positions.

Upper-bound searches, none of which found anything lighter than 25:

- generic GPU Pauli-weight information-set searches, 600 s each: 25, 26, 27 (one run re-reached 25);
- fresh-elimination GPU control without correlated steps: 25;
- orbit replay under the code's verified Z_97 translation group (87,494 orbit candidates from 902 banked logicals): 25;
- four-row cofactor seeds through all 97 translations (about 3e8 pairs): nothing below 29;
- parent logicals mapped through every translation: nothing below 49;
- short CPU runs of the repository's Pauli RIS (about 180 s each) returned 73 and 74, which we read as inconclusive,
  and a BP+OSD decoder search (89 s) returned no logical at all;
- The repository's own gate, run locally as CI runs it (`verify/gate_changed.py` with the base-branch verifier, seed 485097025): orbit-fold passes over 12 detected symmetries, one Python RIS seed of 83,200 trials, and the accelerated pass over 6,110,000 trials before its 90-minute cap. No logical lighter than 25.

Our first search ladder rated this upper bound weak: of three generic 600 s runs only the one that found the witness
returned 25. A later independent audit with its own seeds ran two 3600 s correlated-step searches; both re-reached 25
(28 and 24 hits) and found nothing lighter, so the bound held at 25 under deeper generic search.

Exactness (not recordable on this board, stated for the reader). We ran an exhaustive Pauli-weight branch and bound of
the Dumer-Kovalev-Pryadko irreducible-cluster type (the family of Lee et al., arXiv:2609.30069, App. B.2). On top of
the disjoint-packing bound it used three extra pruning rules. Each rule cuts only nodes with no zero-syndrome
completion within the cap, and each was reviewed independently. An earlier run without the extra rules had already
excluded weight <= 22, so d >= 23. The cap-24 run had 2,104,287 root tasks, 2.476e12 nodes, and took 86.6 h on 256
CPU threads. It found no nontrivial logical of weight <= 24, so d = 25. This was a single execution. An independent
reviewer checked its task journal for complete coverage and re-checked the weight-25 witness. The evidence is weaker
than for [[488,123,22]] (a separate entry), where two executors were compared node for node and a coverage certificate was re-executed.
This is our own unpublished tooling. The repository's certifier cannot certify a Pauli distance, so the entry stays
`upper_bound`.

The CSS double. Every generator has binary weight at most 8, so the symplectic double (H_X = (A|B), H_Z = (B|A) on
970 qubits) is a weight-8 CSS code [[970,194]] with distance at least 25. Its exact distance is open: the weight-25
witness contains Y, so it maps to a Hamming weight of 32 in the double. We make no claim of an advantage over CSS
codes.

Equivalence checks. The verifier's single-qubit Clifford test finds no CSS image. No board entry of either type has
(n, k) = (485, 97), so this cannot be a block-Clifford relabeling of a board entry. The fingerprint and WL signature
match nothing on the board. We did not test general multi-qubit Clifford equivalence to codes off the board.

## Dead ends

- Folds of full-block CSS circulant parents: every one of the 1,052 admissible pairings of the ten strongest weight-8
  parents had a logical of weight <= 18.
- Searches that work in the parent or in an embedding of this code returned bounds far above 25 (32 to 105), as did
  short generic CPU runs (73, 74). Only Pauli-weight searches on the folded code itself reached 25.

## Reproduction

P = 97, qubit l*97 + t for column block l = 0..4 and t in Z_97. Generator (i, r), i = 0..3, r in Z_97, carries X on
qubit l*97 + ((r - E[i][l]) mod 97) and Z on qubit l*97 + ((E[i][l+5] - r) mod 97), for each l in 0..4 with l != i.
A qubit hit by both carries Y. The exponents E (4 x 10):

    [ 0, 59, 78, 14, 10,  0, 70, 16, 71,  5]
    [30,  0, 25, 89, 58,  3,  0, 56, 27, 27]
    [83, 72,  0, 64, 40, 61, 30,  0, 75, 28]
    [18, 89, 80,  0, 91,  9,  7, 85,  0, 52]

(Entries at the omitted blocks, E[i][i] and E[i][i+5], are unused.) These 388 generators are exactly those in the code
file. They have rank 388, so k = 485 - 388 = 97.
