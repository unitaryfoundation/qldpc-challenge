# [[310,14,26]] — non-abelian 2BGA on the metacyclic group Z_31 x| Z_5

## Direction & hypothesis
Same pivot as the PGL(2,7) entry: away from the exhausted Z_195 GB lane, into
non-abelian 2BGA. Solvable metacyclic groups C_n x| C_k are a rich, cheap
source of structured non-abelian codes. Hypothesis: a metacyclic group of
order ~150 gives a high-distance weight-10 code advancing the board's
[[310,14,<=21]] metacyclic entry.

## What was swept, and at what depth
The continual 2BGA sweep, on Z_31 x| Z_5 (order 155, n = 310, action j: i ->
2^j i mod 31). Supports a = [71,10,56,148,67], b = [135,144,52,41,115]
(element indices in the kit enumeration), check weight 10.

## Distance confirmation ladder
Screened at 2M, laddered to 8M, confirmed at 80M x 3 fresh seeds at
pair-depth 20 — the minimum held at 26 on every seed. The Z witness is a
genuine weight-26 X-logical; the X side's lightest witnessed logical is 30,
so d = min(30, 26) = 26. Both witnesses machine-verified in the file. This
raises the board's [[310,14,<=21]] metacyclic entry to d = 26.

## Dead ends
Most metacyclic support pairs give d < 10; the productive ones cluster, and
only deep confirmation separates a real 26 from an 8M optimism artifact
(the family's shallow reads run several above the true distance).

## Model / harness
Search and confirmation by Claude Opus 4.8 driving the gf2_fast RIS engine.
Literature novelty unverified (board-only dedup).

## Reproduction
`metacyclic(31, 5, 2)` then `build_2bga(mul, a, b)` from
`research/kit/group_algebra.py` with the supports above.
