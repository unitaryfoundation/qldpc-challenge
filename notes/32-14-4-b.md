# [[32,14,4]] — genus-2 2D color code (Dyck map, two red faces removed)

## Direction & hypothesis

Target cell: `unrestricted / weight-8` (and `any weight`), family `topological`.
The paper "High-rate low-distance color codes" (Derks et al., arXiv:2611.23420)
constructs distance-4 color codes on surfaces with negative Euler characteristic
whose encoding rate exceeds the 1/4 bound that holds for non-negative chi.
Appendix F.3 gives a `[[32,14,4]]` code on a genus-2 surface with two red faces
removed from the closed m=4 Dyck map (chi = -6, k = 14, d = 4). This entry is
that code.

## What was searched

The code is taken directly from the paper's construction (Appendix F.3), not
from a fresh search: the face list is the closed 4x4 color-code lattice with two
red faces (`R0`, `R2`) removed, giving 20 faces on 32 qubits. Parity checks (X
and Z) are the face-incidence matrices. The candidate was staged through
`research/kit/submit.py` with 2,000 RIS trials per side and then validated by
`verify/validate_candidate.py` (2,000,000-trial accelerator pass), which found no
logical of weight < 4.

## Evidence trail

- `verify/qldpc_verify.py codes/32-14-4-b.json`: CSS commutation, k = 14,
  weight 8, witnesses of weight 4 on both X and Z sides.
- Gate (`verify/validate_candidate.py`): `passed: true`, `refute.refuted: false`
  (no lighter logical in the RIS / accelerator pass), `board_advancing: true`,
  `dominated_by: []`.
- Distance is a witnessed upper bound (d = 4), confidence `upper_bound`.

## Dead ends

The other color-code instances from the same paper (`[[7,1,3]]`, `[[16,4,3]]`,
`[[18,6,3]]`, `[[16,4,4]]`, `[[20,4,4]]`, `[[23,9,3]]`, `[[27,9,3]]`,
`[[32,14,3]]`) were also staged and gated; all pass the verifier but are
dominated in their track cells.
