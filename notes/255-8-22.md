# [[255,8,22]]: fold of 510-16-26 along a block-swapping twisted ZX-duality

## Direction & hypothesis

Cell: check weight at most 6, unrestricted locality (no layout submitted), stabilizer board. A CSS code on 2m qubits with a fixed-point-free ZX-duality halves to a stabilizer code on m qubits (Burton, Durso-Sabina, Brown, arXiv:2406.09951, Thm. 3.5; Lee, Okada, Maskara, Kasai, Zhou, arXiv:2609.30069, Def. 3), whose nontrivial logicals correspond to the nontrivial Z-logicals of the parent, with weight 2y + t for y Y factors and t X or Z factors. Halving a parent of large distance gives a stabilizer code of half the length whose distance is at least half the parent's. The board entry 510-16-26 (V. Russo), a weight-6 cyclic two-block code, has exact distance 26 by our computer-assisted proof (Theorem 4.1 of weight6-exact-distances/exact_distances.pdf, github.com/TimoKellerMath/quantum-error-correction @ 2be467a7bd36).

## What was searched

All affine fixed-point-free ZX-dualities of ten weight-6 abelian two-block parents with known distance, of length 144 to 756, up to translations, each fold screened by information-set searches scored by Pauli weight (1e4 trials). 510-16-26 has 260 such involutions in two classes: h -> c - h between the blocks (fold distance at most 19) and a twisted class with the multiplier 154 = -101; this code is the fold along the twisted class.

## Evidence trail

- Construction: provenance.construction; n = 255, rank 247, k = 8; 204 generators of weight 6 and 51 of weight 5 with one Y each. The translations by 5 and the multiplication by 101 map the generator set onto itself (a group of order 102).
- Not CSS under single-qubit Cliffords: 51 qubits carry X, Y and Z among the generators, so the generator-level parity system that the board's verifier solves has no solution, and each generator is the only nontrivial stabilizer supported in its support, which lifts this to the whole group (Lemma 9 of the README of the package below).
- Lower bound 16 (proved, computer-assisted): t is even because the parent's column weights are odd, so the Pauli weight y + t of a nontrivial logical is at least (26 + t)/2. An exhaustive search over all logicals with t <= 4 (non-Y supports anchored below 5, which suffices by the translations) gives the least weights 81, 59, 36 for t = 0, 2, 4 and none for t = 1, 3 (47 s). Hence d >= min(36, (26 + 6)/2) = 16.
- Upper bound 22: the witness. Three information-set runs of 1e6 trials each (seeds 101 and 303: random qubit order in a random single-qubit Clifford frame per trial; seed 202: random order of the 2n symplectic coordinates), 31 CPU-minutes in total, found nothing lighter than 22 and 102 distinct words of weight 22, forming two complete orbits of size 51; the first two runs hit them 625 times (6.1 per word).
- Exact orbit folds (the shape the gate's fold pass looks for): no nontrivial logical invariant under the rotations of order 3 has Pauli weight at most 24, none invariant under those of order 17 has weight at most 238, and none is invariant under those of order 51. The reflections were not searched exactly.
- Final claim: 16 <= d <= 22, witnessed upper bound 22; d = 22 is not proved.

## Dead ends

- The other class of dualities of 510-16-26 (h -> c - h between the blocks) gives a fold with d <= 19.
- The plain folds of the other parents give [[279,7,d]] with 16 <= d <= 23 (of 558-14-28 and two other presentations of [[558,14,28]]), [[252,6,d]] with 16 <= d <= 21 and [[378,8,d]] with d <= 30, the latter two searches not converged; none was submitted.
- Across code types, CSS entries such as 240-8-20-b ([[240,8,20]], check weight 6) would dominate this code if d <= 20; the board ranks CSS and stabilizer codes separately.

## Tools

Claude Opus 5.5 (Claude Code); Python (standard library) for the constructions and checks; C programs for the search over logicals with few non-Y factors, the meet-in-the-middle search on the orbit folds and the information-set search. About 55 CPU-minutes, including a first version of the few-non-Y search that enumerated every Pauli 2^t times and was stopped after 20 CPU-minutes.

## Reproduction

In `amplified-and-folded-codes/` of github.com/TimoKellerMath/quantum-error-correction @ c203901854da: `python3 src/rebuild.py` rebuilds this code from the parent and the involution and checks isotropy, k, the weights, the 102 words of weight 22, the automorphisms and the local Clifford test; `make quick` reruns the few-non-Y search and the orbit folds and compares them with our logs, `make long` the information-set searches (B510_c0 is the name of this code in the instance files there).
