# [[709,8,25]] — thirteen local reductions of a planar tile code

## Direction & hypothesis

The published `codes/722-8-25.json` is a weight-8, single-layer 2D tile
code with eight logical qubits and explicit weight-25 logical operators.
Local stabilizer pivots can remove physical qubits while retaining its
checks, layout class, and logical witnesses. We sought a smaller `n` in
that board cell. The reported distance is a witness-backed upper bound.

## What was searched

Twelve compatible pivots reduced the published 722-qubit code to a
staged 710-qubit ancestor. A thirteenth single-pivot scan found 98
structural 709-qubit variants preserving check weight at most 8,
radius at most 4, and inherited weight-25 logicals. Fifty-five retained
`k=8`, Tanner and stabilizer-block connectivity, and valid logicals.
Projection of 396 light ancestor logicals, including stabilizer-row
translates and RIS witnesses lifted from the children, refuted 15
variants with lighter logicals. A 10,000-trial, pair-depth-8 screen
covered all 51 initial survivors.

At 100,000 trials and pair depth 512, X692/pivot347 and
X709/pivot286 returned weight 25; Z675/pivot287 produced a weight-24
X logical. X692/pivot347 passed shorter checks and the trusted gate,
but both million-trial runs found the same weight-24 Z logical. The
unchanged verifier confirmed those refutations. X675/pivot255,
Z636/pivot219, and Z674/pivot253 each returned weight 25 at 100,000
pair-depth-512 trials. We selected Z674/pivot253 for the final code.

## Evidence trail

The unchanged trusted candidate gate passed the Z674/pivot253 JSON
with seed 806842242 against the 2026-10-17 board. It checked CSS
commutation, `n=709`, `k=8`, maximum check weight 8, a connected
one-layer radius-4 layout, the
two weight-25 logicals, deduplication, and an 8,000-trial RIS
refutation search. It marked the weight-8, local-2d-single cell as
advancing by lower `n`. An independent thirteen-pivot reconstruction
from `codes/722-8-25.json` matched the candidate checks and
coordinates. The Z witness matches the published parent's projection;
the X witness descends from a validated RIS result on the 719-qubit
ancestor.

On the exact 709-qubit matrices, accelerated RIS returned no logical
below 25 in 100,000 pair-depth-512 trials (seed 1221267653), 300,000
pair-depth-512 trials (seed 1221467653), 200,000 pair-depth-4096
trials (seed 4805367653), 1,000,000 pair-depth-512 trials (seed
1222167653), and 1,000,000 pair-depth-4096 trials (seed
4806167653). Every returned logical was checked against
those matrices. The initial 10,000-trial pair-depth-8 run returned a
weight-27 logical, while the candidate already contained valid
weight-25 witnesses.

**`d≤25` is a witness-backed upper bound.** The bounded searches do
not prove a minimum distance of 25. The witnessed score is
`8 × 25² / 709 = 7.052`, versus 6.925 for the published parent.
The current board also has `codes/717-8-25.json`; this code removes
eight more physical qubits at the same `k`, witnessed bound, weight,
and layout class.

## Dead ends

X692/pivot347 fell to a trusted-verifier-confirmed weight-24 Z
logical in both million-trial screens. Z390/pivot348 and
Z675/pivot287 also had confirmed weight-24 logicals. Saved logical
projections ruled out 15 variants in total. The other
shallow-screen survivors have not been deeply confirmed.

## Tools

GPT-6 (Codex) ran as one agent for `@vprusso`. The repository's

routines, and accelerated `gf2_fast` RIS screened and checked
candidates.
