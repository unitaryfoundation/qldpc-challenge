# [[224,24,16]] — weight-8 bivariate bicycle code on Z_28 x Z_4

## Direction & hypothesis

Cell `weight-8 x unrestricted`, CSS board, n between 221 and 250. Before
this filing the weight-8 frontier at the bottom of that range was
224-24-10 (weight 7), 224-22-16, 224-18-15, 224-12-19, 232-62-12 and
240-28-16: at n <= 224 no entry with k >= 24 had d above 10, and the
k = 22, d = 16 point 224-22-16 was the best at d = 16. The hypothesis was
that four-plus-four-term bivariate bicycle (BB) codes on tori with
2lm in 222..300 could add logicals at the same length and distance.
[[224,24,16]] does: no board entry has n <= 224, k >= 24, d >= 16 and check
weight <= 8. It dominates 224-22-16 by two logical qubits (same n, d and
weight), so the gain is on k, not a d-only gain.

## What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A and B four
monomials each, both containing 1 (no loss of generality), on every torus
Z_l x Z_m with l >= m >= 3 and 222 <= 2lm <= 300, the torus drawn uniformly
from that list and the other three monomials of each polynomial uniformly
from the torus.

Random supports rarely give k >= 16, so the sweep ran a parallel
generate-and-rank prefilter: 300,000 draws (seed 103), of which 1,286 had
k >= 16 and a connected Tanner graph (research/kit/prescreen.block_structure).
Those went through research/kit/search.screen with the gf2_fast backend at
400 trials; 4 advanced the board frontier at screen depth and were
confirmed at 20,000 / 200,000 / 2,000,000 fast trials
(research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a
candidate as soon as its running bound stopped advancing and skipping any
already dominated by a point staged earlier in the campaign. This was the
only one staged.

## Evidence trail

Witness-backed **upper bound** d <= 16, not an exact distance. The bound
was 16 at 400 trials and never moved; both sides have a weight-16 logical.

| stage | trials per candidate | lightest logical |
|---|---|---|
| screen (gf2_fast, seed from fingerprint) | 400 | 16 |
| confirm | 20,000 | 16 |
| confirm | 200,000 | 16 |
| confirm | 2,000,000 | 16 |
| numpy lightest_logical, both sides, seeds 103 / 104 | 1,500 | X 16, Z 16 |
| deep ladder, 3 fresh seeds (54867, 62786, 70705), gf2_fast | 10,000,000 each | 16, 16, 16 |

`verify/validate_candidate.py` (through research/kit/coordination.py's gate
wrapper) returned `passed: true`, `board_advancing: true`, `d_only_gain:
false`, label "advances the weight-8 x unrestricted board". Literature
novelty is unverified; board-relative novelty comes from
verify/validate_candidate.py (fingerprint and Weisfeiler-Leman dedup
against every board entry found nothing).

## Dead ends

- Whole-band 4 + 4 BB sweeps (222 <= n <= 400; 100,000 to 300,000
  prefiltered draws each) spent most draws above n = 300; at n <= 250 they
  gave only [[240,20,18]] (filed separately).
- A 2 + 6 split of the same check weight (200,000 draws, 1,711 with
  k >= 16) produced nothing that advanced even at 400 screen trials.
- Cyclic generalized-bicycle codes with a designed divisor g | x^m - 1,
  weight-4 a and b (check weight 8): weight-4 multiples of g exist only for
  deg g <= ~22 at odd m from 111 to 200, and 4,000 such draws gave nothing
  advancing even at 400 trials.
- Random-support 2BGA on non-abelian groups at check weight 8, 16,000
  serial plus 150,000 prefiltered draws: every screen-depth survivor
  collapsed by 20,000 trials.

## Reproduction

Torus Z_28 x Z_4 (x of order 28, y of order 4), terms (i, j) = x^i y^j:

A = 1 + x^2 y^3 + x^3 + x^11 y^3,
B = 1 + x^9 + x^9 y^3 + x^21.

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from bb import build_bb
from css import compute_k
HX, HZ = build_bb(28, 4, [(0, 0), (2, 3), (3, 0), (11, 3)],
                  [(0, 0), (9, 0), (9, 3), (21, 0)])   # n = 224
assert compute_k(HX, HZ) == 24
```

Check sets match codes/224-24-16.json row for row in this order. The numpy
`surrogate.lightest_logical` at 1,500 trials with seeds 103 (X side, pass
(HX, HZ)) and 104 (Z side, pass (HZ, HX)) returns a weight-16 logical on
each side.
