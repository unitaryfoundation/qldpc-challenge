## Construction

Periodic bivariate-bicycle code on Z_27 x Z_7 (n = 2*l*m = 378): x = S_27 tensor I_7, y = I_27 tensor S_7 (cyclic shifts), qubit index i*m + j in each block; A = x^0y^0 + x^1y^2 + x^25y^1, B = x^0y^0 + x^12y^5 + x^17y^1 + x^19y^2; H_X = [A|B], H_Z = [B^T|A^T] (research/kit/bb.py build_bb(27, 7, [[0, 0], [1, 2], [25, 1]], [[0, 0], [12, 5], [17, 1], [19, 2]])). gcd(27, 7) = 1, so Z_27 x Z_7 is cyclic of order 189 and the code is the cyclic generalized-bicycle code over Z_189 with a(z) = z^0 + z^106 + z^163, b(z) = z^0 + z^12 + z^71 + z^100 (CRT relabeling x^a y^b -> z^t, t = a mod 27, t = b mod 7).

Schedule: interleaved; two-block interleaved (A: 3 terms, B: 4 terms), 8 CX layers per round; terms by bb_decompose translations on Z_27 x Z_7; X-check term slots [6, 1, 7, 2, 3, 5, 4], Z-check term slots [0, 6, 1, 3, 4, 2, 5] over terms A_0..A_2, B_0..B_3; RIS screen at 2 rounds: {'Z': 227, 'X': 246}
