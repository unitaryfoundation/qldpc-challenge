# [[392,28,22]] — weight-8 bivariate bicycle code on Z_14 x Z_14

## Direction & hypothesis

Cell `weight-8 x unrestricted`, CSS board, n between 330 and 400. Before
this campaign the weight-8 frontier there ran 336-88-12, 336-28-20,
336-24-24, 376-98-8, 378-32-19, 378-18-27 and 392-102-14: no weight-8
entry with n <= 392 and k >= 28 had d above 20. The hypothesis was that
four-plus-four-term bivariate bicycle (BB) codes on square tori could add
distance at k = 28. [[392,28,22]] does: no board entry has n <= 392,
k >= 28, d >= 22 and check weight <= 8. It is a narrow step (it does not
hold at k - 2 or d - 2) and not a d-only gain (no board entry has the same
n, k and weight). It sits next to the [[378,26,26]] filed from the same
campaign (two more logicals, distance four lower, 14 more qubits).

## What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A and B four
monomials each, both containing 1 (no loss of generality), on every torus
Z_l x Z_m with l >= m >= 3 and 222 <= 2lm <= 400, the torus drawn uniformly
from that list and the other three monomials of each polynomial uniformly
from the torus.

Random supports rarely give k >= 16, so the sweep ran a parallel
generate-and-rank prefilter: 300,000 draws (seed 101), of which 1,284 had
k >= 16 and a connected Tanner graph (research/kit/prescreen.block_structure).
Those went through research/kit/search.screen with the gf2_fast backend at
400 trials; 24 advanced the board frontier at screen depth and were
confirmed at 20,000 / 200,000 / 2,000,000 fast trials
(research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a
candidate as soon as its running bound stopped advancing and skipping any
already dominated by a point staged earlier in the campaign (several were
dominated by this campaign's own [[378,26,26]], [[384,16,30]] and
[[392,18,28]]). This was the only one staged.

## Evidence trail

Witness-backed **upper bound** d <= 22, not an exact distance. The bound
was 22 at 400 trials and never moved; both sides have a weight-22 logical.

| stage | trials per candidate | lightest logical |
|---|---|---|
| screen (gf2_fast, seed from fingerprint) | 400 | 22 |
| confirm | 20,000 | 22 |
| confirm | 200,000 | 22 |
| confirm | 2,000,000 | 22 |
| numpy lightest_logical, both sides, seeds 101 / 102 | 1,500 | X 22, Z 22 |
| deep ladder, 3 fresh seeds (56213, 64132, 72051), gf2_fast | 10,000,000 each | 22, 22, 22 |

`verify/validate_candidate.py` (through research/kit/coordination.py's gate
wrapper) returned `passed: true`, `board_advancing: true`, `d_only_gain:
false`, label "advances the weight-8 x unrestricted board". Literature
novelty is unverified; board-relative novelty comes from
verify/validate_candidate.py (fingerprint and Weisfeiler-Leman dedup
against every board entry found nothing).

## Dead ends

- Other prefiltered 4 + 4 BB sweeps (100,000 to 300,000 draws each) found
  k >= 28 draws with competitive distance only rarely; above n = 340 they
  staged k = 16..26 points.
- A 3 + 5 split (700,000 draws over two seeds) and a 2 + 6 split (200,000
  draws) of the same check weight never reached k >= 20 with an advancing
  distance.
- Cyclic generalized-bicycle codes with a designed divisor g | x^m - 1,
  weight-4 a and b (check weight 8): 4,000 draws at 300 <= n <= 400 gave
  nothing advancing even at 400 trials.
- Random-support 2BGA on non-abelian groups at check weight 8, 16,000
  serial plus 150,000 prefiltered draws: every screen-depth survivor
  collapsed by 20,000 trials.

## Reproduction

Torus Z_14 x Z_14 (x and y of order 14), terms (i, j) = x^i y^j:

A = 1 + x^5 y^13 + x^8 y^7 + x^10 y^13,
B = 1 + x^7 y + x^9 y^2 + x^11 y^12.

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from bb import build_bb
from css import compute_k
HX, HZ = build_bb(14, 14, [(0, 0), (5, 13), (8, 7), (10, 13)],
                  [(0, 0), (7, 1), (9, 2), (11, 12)])   # n = 392
assert compute_k(HX, HZ) == 28
```

Check sets match codes/392-28-22.json row for row in this order. The numpy
`surrogate.lightest_logical` at 1,500 trials with seeds 101 (X side, pass
(HX, HZ)) and 102 (Z side, pass (HZ, HX)) returns a weight-22 logical on
each side.
