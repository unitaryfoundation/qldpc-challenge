# [[392,22,28]] — weight-8 bivariate bicycle code on Z_14 x Z_14

## Direction & hypothesis

Cell `weight-8 x unrestricted`, CSS board, n between 360 and 400. Before
this campaign the weight-8 frontier there ran 360-10-28, 364-8-32,
372-14-29, 378-32-19, 378-18-27, 390-10-32, 392-102-14 and 392-8-33: at
n <= 392 every weight-8 entry with d >= 28 had k <= 14, and every entry
with k >= 20 had d <= 24. The hypothesis was that four-plus-four-term
bivariate bicycle (BB) codes on tori with 2lm in 300..400, prefiltered for
k >= 18, could put a k >= 20 point at d = 28. [[392,22,28]] does: no board
entry has n <= 392, k >= 22, d >= 28 and check weight <= 8, and the k - 2
margin holds ([[392,20,28]] is not dominated either). It dominates the
[[392,18,28]] on Z_28 x Z_7 filed earlier in the same campaign (four more
logicals at the same n, d and weight).

## What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A and B four
monomials each, both containing 1 (no loss of generality), on every torus
Z_l x Z_m with l >= m >= 3 and 300 <= 2lm <= 400, the torus drawn uniformly
from that list and the other three monomials of each polynomial uniformly
from the torus.

Random supports rarely give k >= 18, so the sweep ran a parallel
generate-and-rank prefilter: 300,000 draws (seed 111), of which 710 had
k >= 18 and a connected Tanner graph (research/kit/prescreen.block_structure).
Those went through research/kit/search.screen with the gf2_fast backend at
400 trials; 8 advanced the board frontier at screen depth and were
confirmed at 20,000 / 200,000 / 2,000,000 fast trials
(research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a
candidate as soon as its running bound stopped advancing and skipping any
already dominated by a point staged earlier in the campaign.

## Evidence trail

Witness-backed **upper bound** d <= 28, not an exact distance.

| stage | trials per candidate | lightest logical |
|---|---|---|
| screen (gf2_fast, seed from fingerprint) | 400 | 44 |
| confirm | 20,000 | 28 |
| confirm | 200,000 | 28 |
| confirm | 2,000,000 | 28 |
| deep ladder, 3 fresh seeds (56847, 64766, 72685), gf2_fast | 10,000,000 each | 28, 28, 28 |

The bound reached 28 at 20,000 trials and then held; it is still only an
upper bound.

`verify/validate_candidate.py` (through research/kit/coordination.py's gate
wrapper) returned `passed: true`, `board_advancing: true`, `d_only_gain:
false`, label "advances the weight-8 x unrestricted board". Literature
novelty is unverified; board-relative novelty comes from
verify/validate_candidate.py (fingerprint and Weisfeiler-Leman dedup
against every board entry found nothing).

## Dead ends

- Whole-band 4 + 4 BB sweeps (222 <= n <= 400; 100,000 to 300,000
  prefiltered draws each) peaked at k = 18 for d = 28 ([[392,18,28]]);
  restricting the tori to 2lm >= 300 and raising the prefilter to k >= 18
  found this k = 22 point and the [[378,26,26]] filed separately.
- A 3 + 5 split (700,000 draws over two seeds) and a 2 + 6 split (200,000
  draws) of the same check weight never reached k >= 20 with an advancing
  distance.
- Cyclic generalized-bicycle codes with a designed divisor g | x^m - 1,
  weight-4 a and b (check weight 8): 4,000 draws at 300 <= n <= 400 gave
  nothing advancing even at 400 trials.
- Random-support 2BGA on non-abelian groups at check weight 8, 16,000
  serial plus 150,000 prefiltered draws: every screen-depth survivor
  collapsed by 20,000 trials.

## Reproduction

Torus Z_14 x Z_14 (x and y of order 14), terms (i, j) = x^i y^j:

A = 1 + x^3 y^9 + x^4 y^11 + x^12 y^3,
B = 1 + x y^5 + x^5 + x^5 y^12.

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from bb import build_bb
from css import compute_k
HX, HZ = build_bb(14, 14, [(0, 0), (3, 9), (4, 11), (12, 3)],
                  [(0, 0), (1, 5), (5, 0), (5, 12)])   # n = 392
assert compute_k(HX, HZ) == 22
```

Check sets match codes/392-22-28.json row for row in this order. Witness
search: `surrogate.distance_rand_witness(HX, HZ, trials=2_000_000,
seed=113000333, backend="fast", pair_depth=8)` returns a weight-28 logical.
