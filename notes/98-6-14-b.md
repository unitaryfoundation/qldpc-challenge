## What was searched

H_X = [L(a) | R(b)], H_Z = [R(b)^T | L(a)^T] over F_2[G] with G = Z_49 (|G| = 49) built as `group_algebra.cyclic_product(49)`: elements are the tuples in `itertools.product` order, index = position in that order (identity = 0). a = [0, 39, 41] and b = [0, 6, 11, 30, 37] are lists of element indices (|a| = 3, |b| = 5, check weight 8). G is abelian, so L(a) and R(b) are commuting multivariate circulants (a bivariate-bicycle-type code when G has two factors).
