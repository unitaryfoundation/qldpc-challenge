# [[768,258,6]] — girth-12 circulant CSS family (arXiv:2610.19451, Construction I) at N=128

## Direction & hypothesis

weight-6 x unrestricted, family tag `other`. This is the N=128 member of the
[[6N, 2N+2, 6]] girth-12 circulant family of arXiv:2610.19451 (Nourozi,
Smarandache, Mitchell), the exact instance the paper itself showcases in
Section V and Table I. It extends the same high-rate (R = 1/3 + 1/(3N))
corner of the weight-6 x unrestricted frontier as its smaller sibling
[[222,76,6]], which is filed as a separate PR: with the board's high-rate
d=6 entries currently at [[546,184,6]] (k = 184) and [[960,258,6]]
(k = 258, n = 960), a weight-6 code holding k = 258 at n = 768 is
undominated — same k and d as the n=960 entry, 256 fewer qubits.

## What was searched

Reproduction rather than a search: the pattern is fixed and only N varies.
All 131 admissible members (N=31 and N=37..166, n <= 996) were compared
against the full verified board on the four frontier axes; 130 are
undominated, the exception being N=91 whose parameters equal the existing
[[546,184,6]]. This PR files N=128 because it is the paper's own showcase
instance and the one that strictly beats an existing frontier entry on n.
No distance search was needed: Theorem 1 proves d = 6 exactly and exhibits
the weight-6 witness for every admissible N.

## Evidence trail

Witness-backed upper bound d <= 6, carried by analytic operators. The
Z-side witness is the paper's Eq. (12): block 0 is e_1, block 4 is
e_1 + e_{-11} + e_{-5}, block 5 is e_{-11} + e_{-5}, blocks 1-3 zero
(indices mod N, weight 6). The X-side witness is its mirror under the
incidence-graph isomorphism of the rank proof (pi = (3,2,1,0,5,4), supports
reflected t -> -t, block v rescaled by C_{-b_v}). The paper also counts the
minimum-weight logical supports at N=128: 3,840 weight-6 supports per CSS
side, against 4,864 for the comparable Komoto-Kasai girth-12 code of
arXiv:2501.13444 — a 21% reduction that motivates their lower measured frame
error rate. Both witnesses were re-checked by the submission tool's search,
the trusted verifier, and the refutation pass (8,000 RIS trials, nothing
lighter). The paper's exactness proof gives the matching lower bound: every
nonzero kernel vector of the column-weight-2 incidence matrix contains a
cycle, so d >= 6. Exact certification is out of reach at k = 258, so the
board shows d <=.

## Dead ends

- N=91 is the one non-filing: its [[546,184,6]] parameters are already on
  the board as a hyperbolic surface code.
- d cannot exceed 6 anywhere in this family: Proposition 1 caps Tanner girth
  at 2w = 12 for column-weight-2, row-weight-6 checks, and the girth-12
  members all carry the uniform weight-6 logical.
- The paper's own comparison code (Komoto-Kasai, arXiv:2501.13444,
  [[768,258,6]]) has identical parameters, so this entry claims no new
  parameter set — it advances the board by n against a different existing
  entry, not against the literature.

## Tools

MiMo-V2.6-Flash (OpenCode agent harness). NumPy builder reproducing
Eqs. (8)-(9), self-tested against the paper's Example 2 and Table I

## Reproduction

For N=128, with C_s the N x N cyclic shift P_{t -> t+s} and shifts mod N,
a = (0, 1, 3, 8, 12, 18), b = (0, -5, -5, 0, 12, 12), c = (0, 0, 2, 8, 2, 8):

    H_X = [[I, I, I, I, I, I], [C_a0, C_a1, C_a2, C_a3, C_a4, C_a5]]
    H_Z = [[C_b0, C_b1, C_b2, C_b3, C_b4, C_b5],
           [C_c0, C_c1, C_c2, C_c3, C_c4, C_c5]]

256 x 768 checks, qubit index v*128 + t (v in 0..5, t in 0..127);
orthogonality by even multiplicity of -b, -c, a-b, a-c; ranks 255 per side
(connected incidence graphs), k = 768 - 510 = 258. The checks and analytic
witnesses stored in `codes/768-258-6.json` are the direct expansion of this
pattern. The paper's Section V compares this instance against the
Komoto-Kasai reference code under BP-OSD-10 and two RL decoders.
