## Original note, with the file paths updated

# [[662,122,95]] two-qubit Clifford image of a cyclic GB code

This stabilizer code encodes 122 qubits in 662 with maximum generator weight
32 and a witnessed Pauli upper bound d <= 95. It is the image of the CSS code
[the parent code at the audited revision](https://github.com/unitaryfoundation/qldpc-challenge/blob/7ee749804110a24f42bad1015c5b302b7996ed8e/codes/662-122-80.json) under a fixed two-qubit Clifford applied on 108
disjoint qubit pairs, and it competes on the general stabilizer board
(unrestricted, weight-9plus). No exact-distance or literature-novelty claim is
made. At the witnessed bound its kd^2/n is 1663.2; the comparison snapshot,
commit 6103818d, had 82.4 ([[452,115,18]]) as its highest stabilizer value.
These are comparisons of retained upper bounds.

## Direction & hypothesis

The parent is the cyclic generalized-bicycle code on Z_331 with H_X = (A | B)
and H_Z = (B^T | A^T), n = 662, k = 122, check weight 24, and weight-80
witnesses on both sides (see [the parent note at the audited revision](https://github.com/unitaryfoundation/qldpc-challenge/blob/7ee749804110a24f42bad1015c5b302b7996ed8e/notes/662-122-80.md) for its polynomials). On
each selected pair (q, q + 331) the Clifford maps X1 to Z1 Y2, X2 to Y1 Z2,
Z1 to Z1 X2, and Z2 to X1 Z2. It preserves the symplectic form, n, and k. A
pure-X or pure-Z logical gains one unit of weight on every pair it occupies on
one qubit only, and a Y-only logical keeps its weight. The aim was to raise
the weights of the parent's short logicals while keeping every generator at
weight 32 or less.

## What was searched

An earlier mask used 112 pairs and claimed d <= 95. Weight-80 logicals of
the parent, found by outside searches, had symmetry images of weight 94 under
that mask, so the claim was withdrawn. The present mask was chosen by a
finite binary program over 331 pair variables with 12,578 inequalities
covering generator weights and the images of every saved parent logical,
including the new weight-80 ones; SciPy 1.17.1 with HiGHS returned a feasible
108-pair mask in about 8 s with a reported relative gap of about 6.4%, so
optimality is not proved. The constraints cover only the saved logicals, not
unknown ones. The frozen pair list below reproduces the code without the
optimization.

## Evidence trail

Fresh random-information-set searches on the submitted code, two threads
each, returned the following lightest logicals; every returned support was
re-checked with the repository's logical tests after transport to the
submitted labeling.

| Search | Trials per call | Pair depth | Returned weights |
| --- | ---: | ---: | --- |
| Inherited parent Y-only | 100,000 | 512 | 95 |
| Images of parent pure-X | 10,000; 10,000; 100,000 | 128; 128; 256 | 111; 106; 106 |
| Images of parent pure-Z | 10,000; 10,000; 100,000 | 128; 128; 256 | 111; 111; 104 |
| Fresh parent Y-only | 100,000 | 128 | 95 |
| Fresh unrestricted Pauli | 10,000 | 128 | 189 |

All 45 distinct saved parent logicals were transported through every cyclic
shift and the CSS duality, 29,790 images in all, with minimum weight 95 and
no refutation. This is a finite enumeration of known operators, not of all
logicals. The unchanged candidate gate passed with seed 304300000 (no exact
or WL duplicate, stabilizer-frontier advance in the fixed snapshot), and the
unchanged local submission gate passed with seed 304320000 after 2,310,000
accelerated trials, stopped by its wall-clock cap short of the 8,000,000
requested. Passing these finite searches establishes no lower bound. The
submitted code has stabilizer fingerprint `8c19ab0d585b42cd`; the withdrawn
112-pair mask had `c8938a5da21daf4c`.

## Dead ends

The fall of the old mask from 95 to 94 shows that surviving earlier searches
did not establish its distance; the repair only incorporates the failures
that were found. The parent's Y-only sector already supplies weight 95 here,
so improving on this bound requires a different transformation or parent, not
a better mask.

## Reproduction

Let C(S) be the 331 x 331 binary circulant whose row i has ones in columns
(i + s) mod 331 for s in S, and set

```
a = [0, 1, 3, 32, 70, 73, 83, 155, 157, 245, 264, 276]
b = [0, 3, 34, 87, 124, 140, 144, 160, 197, 250, 281, 284]
H_X = [C(a) | C(b)]
H_Z = [C(b)^T | C(a)^T]
```

Write each row of H_X as the X-type Pauli on its support and each row of H_Z
as the Z-type Pauli on its support. On each pair (q, q + 331) for q in

```
1 2 3 4 5 6 7 10 24 25 26 27 28 29 30 31 45 49 50 51 52 53 54 55 56 71 72 73
74 75 76 77 78 80 95 96 97 98 99 101 115 119 120 121 122 123 124 125 143 145
146 147 148 149 167 169 170 171 172 173 189 190 191 192 193 194 195 213 214
215 216 217 218 219 220 223 237 238 239 240 241 242 243 244 247 258 261 262
263 264 265 266 267 285 286 287 288 289 290 291 306 308 309 310 311 312 313
317
```

replace the two-qubit Pauli factor by its image under X1 -> Z1 Y2, X2 -> Y1
Z2, Z1 -> Z1 X2, Z2 -> X1 Z2, multiplying images and dropping phases. The 662
resulting operators are, as a set, exactly the 662 generators of
`codes/662-122-86.json`; their symplectic rank is 540, so k = 662 - 540 =
122.
