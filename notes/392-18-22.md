# [[392,18,22]] — weight-7 bivariate bicycle code on Z_14 x Z_14

## Direction & hypothesis

Cell `weight-8 x unrestricted` (maximum check weight 7), CSS board, n between 221 and 400. Before this code, the frontier (board plus this campaign's open PRs) at check weight <= 7, d >= 11 and n from 332 to 392 ran through 336-12-24, 340-16-22, 360-12-25, 360-16-23, 360-24-20, 372-12-26, 372-14-24, 378-12-27, 378-16-25 (360-16-23 and 378-16-25 are open PRs from this campaign). The hypothesis was that random 3 + 4-term bivariate bicycle (BB) codes on tori with 2lm in 300..400, prefiltered for k >= 14, still reach points there that the board does not hold.

[[392,18,22]] does: no board entry has n <= 392, k >= 18, d >= 22 and check weight <= 7. It is not a d-only gain (no board entry has the same n, k and weight with a lower d). Its maximum check weight is 7 (3 + 4 terms): weight-8 entries may reach these parameters, but no entry of check weight <= 7 does.

## What was searched

Random-support BB codes H_X = [A | B], H_Z = [B^T | A^T] with A of 3 and B of 4 monomials, both containing 1 (no loss of generality), on every torus Z_l x Z_m with l >= m >= 3 and 300 <= 2lm <= 400; the torus is drawn uniformly from that list and the other monomials uniformly from the torus.

This sweep (seed 711) drew 500,010 codes in a parallel generate-and-rank prefilter; 245 had k >= 14 and a connected Tanner graph (research/kit/prescreen.block_structure). Those went through research/kit/search.screen with the gf2_fast backend at 400 trials; 8 advanced the board frontier at screen depth and 7 were taken to 20,000 / 200,000 / 2,000,000 fast trials (research/kit/surrogate.distance_rand_witness, pair depth 8), dropping a candidate as soon as its running bound stopped advancing; 2 survived that and were staged.

## Dead ends

- In this sweep 5 of 7 screen-depth survivors collapsed below the frontier by 2,000,000 trials: 400-trial readings run several units high at this n.
- Earlier in this campaign on the same band: cyclic generalized-bicycle codes with a designed divisor at weights (3,3) and (4,4), random-support 2BGA on non-abelian groups at check weight 8, non-abelian lifted products, and weight-6 BB/2BGA at k >= 28 gave nothing that survived 20,000 trials on the frontier.
- Random 2 + 6 splits at check weight 8 never reached k >= 18 with an advancing distance.

## Reproduction

Torus Z_14 x Z_14 (x of order 14, y of order 14), terms (i, j) = x^i y^j:

A = 1 + x^8 y^7 + x^9 y^9,
B = 1 + y^4 + x^2 y^3 + x^13 y^13.

```python
import sys; sys.path[:0] = ["research/kit", "verify"]
from bb import build_bb
from css import compute_k
HX, HZ = build_bb(14, 14, [(0, 0), (8, 7), (9, 9)],
                  [(0, 0), (0, 4), (2, 3), (13, 13)])   # n = 392
assert compute_k(HX, HZ) == 18
```

Ladder: `surrogate.distance_rand_witness(HX, HZ, trials=10_000_000, seed=<s>, backend="fast", pair_depth=8)` with s in {64829, 72748, 80667} returns logicals of weight 22, 22, 22.
