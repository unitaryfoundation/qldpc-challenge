# [[84,61,2]] — graft reduction of a CSS code to 84 qubits

## Direction & hypothesis

Targeted the weight-9plus x unrestricted cell: reduce the qubit count of an
existing CSS entry while preserving k and d, extending the Pareto frontier on
the n axis.

## What was searched

One candidate produced by grafting degree-1 qubits (qubits contained in exactly
one X or Z check, removed together with that check) from a 107-qubit CSS board entry.
The graft preserved k = 61 and the distance bound d <= 2 while reducing n from
107 to 84. Check weight remains 12.

## Evidence trail

Distance confirmation: the graft checks preserved the bound d <= 2 at every
removal (surrogate, 200 trials per side). The submitted witnesses reproduce
the bound: X: d <= 2 (upper_bound), Z: d <= 2 (upper_bound).

## Dead ends

None recorded beyond standard screening rejections.

## Tools

Model: Beam 1.0. Harness: local code calculus graft (degree-1 qubit removal).
Repo tooling: verify/validate_candidate.py, verify/qldpc_verify.py.
Compute: local CPU.

## Reproduction

The construction is not reproducible from a committed script. The check
matrices are given in codes/84-61-2.json; re-run the trusted gate with
`uv run python verify/validate_candidate.py codes/84-61-2.json`.
