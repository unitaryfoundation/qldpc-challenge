# Preliminary distance observations for two n=180 CSS codes

**Research note — summary only, not an accepted certificate.**

Two public entries in `unitaryfoundation/qldpc-challenge` are `codes/180-18-14.json` and `codes/180-20-14.json`. Both contain public, checkable nontrivial logical operators of weight 14, providing an upper bound on their minimum distances.

Our internal computational investigation reported no nontrivial CSS logical operator of weight 1–13 for either entry. This suggests the distance could be exactly 14, but **the search procedure, source code, and proof of exhaustiveness are intentionally not part of this public submission**. Accordingly, this note does not provide an independently reviewable certificate for the lower bound, and no changes to the official distance confidence are requested.

The results should be treated as preliminary until the evidence can be reviewed through an agreed disclosure route. This note makes no claim to a new mathematical algorithm.

See the previous discussion in [issue #274](https://github.com/unitaryfoundation/qldpc-challenge/issues/274).
